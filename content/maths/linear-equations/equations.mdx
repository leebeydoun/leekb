Solving equations is mostly a matter of rewriting them, one step at a time, until the answer can be
read off. That only works if each step is honest: it mustn't lose an answer, and it mustn't sneak in
a false one. This page makes that precise, and then settles the simplest case completely, an
equation with a single unknown.

Throughout this guide, "number" means a rational number, as in the
[Numbers](../numbers/rational-numbers.mdx) guide. The rules proved there for integers, such as
rearranging and multiplying by zero, carry over to rational numbers, and we use them freely.
Everything here works in the same way for the [real numbers](../real-numbers/introduction.mdx),
which have the same rules of arithmetic.

## Equations and their solutions

An equation like $$3x + 5 = 11$$ is a statement with a gap in it. The letter $$x$$ is the gap, and
until a number is put in its place the statement is neither true nor false. Putting in $$x = 2$$
gives $$3 \cdot 2 + 5 = 11$$, which is true. Putting in $$x = 1$$ gives $$8 = 11$$, which is false.

:::definition[Equations and solutions]{#solution}

An **equation** is a statement that two expressions are equal, where the expressions involve one or
more letters standing for numbers, called **unknowns**. A **solution** is a choice of number for
each unknown that makes the statement true. To **solve** an equation is to find all of its
solutions.

:::

The word **all** matters. Saying "$$x = 2$$ works" is not the same as solving $$3x + 5 = 11$$:
solving also means knowing that **nothing else** works. Some equations have one solution, some have
several, some have none, and some are true for every number.

| Equation              | Solutions                                        |
| --------------------- | ------------------------------------------------ |
| $$3x + 5 = 11$$       | only $$x = 2$$                                   |
| $$x^2 = 9$$           | $$x = 3$$ and $$x = -3$$                         |
| $$x + 1 = x + 2$$     | none: no number is one more than itself plus one |
| $$2(x + 1) = 2x + 2$$ | every number                                     |

Checking a proposed solution is always easy: put it in and see whether both sides come out equal.
That is worth doing every time, because it catches arithmetic slips.

## Equivalent equations

Think of an equation as a pair of scales that balance. Putting the same weight on both pans, or
doubling what is on both pans, keeps them balanced. Solving an equation means making moves like
these, replacing it by simpler and simpler equations until the answer is obvious. For that to be
honest, each new equation must have exactly the same solutions as the one before: no answer lost,
and no false one gained.

:::definition[Equivalent equations]{#equivalent}

Two equations are **equivalent** if they have exactly the same solutions: every solution of the
first is a solution of the second, and every solution of the second is a solution of the first.

:::

For example, $$3x + 5 = 11$$ and $$3x = 6$$ are equivalent, and both are equivalent to $$x = 2$$.
The chain

```math
3x + 5 = 11 \quad\longrightarrow\quad 3x = 6 \quad\longrightarrow\quad x = 2
```

is a solution written out in full: since each equation has the same solutions as the next, the first
has exactly the solutions of the last, which is just $$x = 2$$.

The next proposition lists the steps that are always safe.

:::proposition[Safe steps for equations]{#safe-steps}

Changing an equation in any of these ways gives an equivalent equation:

1. Adding the same number, or the same expression, to both sides. The expression must have a value
   for every choice of the unknowns, so no unknown in a denominator.
2. Multiplying both sides by the same number, as long as that number is **not zero**.
3. Rewriting either side as something equal to it for every value of the unknowns, for example by
   expanding a bracket or collecting terms.

:::

:::proof{source="https://en.wikipedia.org/wiki/Equation#Properties"}

For each step we show two things: any solution of the old equation solves the new one, and any
solution of the new equation solves the old one. The second part works because each step can be
undone. We work with particular values of the unknowns: once they are chosen, both sides, and
anything added to them, are just numbers, so it is enough to reason about numbers.

**Step 1.** Write the equation as $$L = R$$, where $$L$$ and $$R$$ are the two sides, and add $$c$$
to both sides to get $$L + c = R + c$$. Here $$c$$ may be a number or an expression.

- If some values of the unknowns make $$L = R$$ true, then $$L$$ and $$R$$ are the same number, so
  adding $$c$$ to each gives the same number again: $$L + c = R + c$$ is true too.
- Going back, if $$L + c = R + c$$ is true for some values, adding $$-c$$ to both sides gives
  $$L = R$$ by :ref{#numbers/rearranging}.

So the two equations have the same solutions.

**Step 2.** Multiply both sides by a number $$c \neq 0$$, to get $$cL = cR$$.

- If $$L = R$$, then $$cL = cR$$, because equal numbers multiplied by $$c$$ give equal results.
- Going back, if $$cL = cR$$, then since $$c \neq 0$$ we may cancel it by
  :ref{#numbers/cancel-product}, giving $$L = R$$.

So again the two equations have the same solutions.

**Step 3.** If two expressions are equal for every value of the unknowns, then for any particular
values they are the same number. So replacing one by the other doesn't change either side's value,
and the equation is true for exactly the same values as before.

:::

The condition $$c \neq 0$$ is essential, and it is exactly what makes the "going back" possible.
Multiplying both sides of $$x = 2$$ by $$0$$ gives $$0 = 0$$, which is true for every $$x$$: a step
that cannot be undone has let in every number as a false solution.

### Steps that are not safe

Other common moves keep every solution but can't be undone, so they may add false ones.

- **Multiplying by an expression that can be zero.** Multiplying both sides of $$x = 3$$ by
  $$x - 1$$ gives $$x(x - 1) = 3(x - 1)$$. That is true for $$x = 3$$, but also for $$x = 1$$, where
  both sides are $$0$$. The new equation has an extra, false solution.
- **Squaring both sides.** Squaring $$x = 3$$ gives $$x^2 = 9$$, which also has the solution
  $$x = -3$$. Squaring can't be undone, because $$3$$ and $$-3$$ have the same square.
- **Cancelling an unknown from a fraction.** The equation $$\frac{x^2}{x} = 0$$ has no solution. At
  $$x = 0$$ the left side has no value, since it would divide by $$0$$; at any other $$x$$ it equals
  $$x$$, which isn't $$0$$. Yet simplifying the left side to $$x$$ gives $$x = 0$$, a false
  solution. Step 3 doesn't allow this, because $$\frac{x^2}{x}$$ and $$x$$ are only equal where
  $$x \neq 0$$.

These moves are sometimes useful, but after using them every answer must be checked in the
**original** equation, and false ones thrown away.

## Linear equations in one unknown

The simplest equations are the ones where the unknown is only multiplied by numbers and added to
numbers: no $$x^2$$, no $$x$$ in a denominator, no $$x$$ times $$x$$. They say things like "three
times a number, plus five, is eleven". However such an equation starts out, it can be tidied up into
the form "some number times $$x$$ is some other number".

:::definition[Linear equation in one unknown]{#linear-one}

A **linear equation** in one unknown $$x$$ is one that can be brought to the form

```math
ax = c
```

by safe steps, where $$a$$ and $$c$$ are numbers. The number $$a$$ is the **coefficient** of $$x$$.

:::

For example, $$5x - 7 = 2x + 8$$ is linear: subtracting $$2x$$ and adding $$7$$ to both sides gives
$$3x = 15$$. The word "linear" comes from lines; the [Equations as lines](./lines.mdx) page shows
why.

Whether such an equation has one solution, none or infinitely many depends only on whether $$a$$ is
zero. If $$3x = 12$$, dividing by $$3$$ gives the one answer $$x = 4$$. But if the number in front
of $$x$$ is $$0$$, the left side is $$0$$ whatever $$x$$ is. Then $$0 \cdot x = 5$$ can never be
true, and $$0 \cdot x = 0$$ is always true.

:::theorem[Solving ax = c]{#one-unknown}

Let $$a$$ and $$c$$ be numbers.

1. If $$a \neq 0$$, the equation $$ax = c$$ has exactly one solution, $$x = \frac{c}{a}$$.
2. If $$a = 0$$ and $$c \neq 0$$, it has no solution.
3. If $$a = 0$$ and $$c = 0$$, every number is a solution.

:::

:::proof{source="https://en.wikipedia.org/wiki/Linear_equation#One_variable"}

**Case 1: $$a \neq 0$$.** Then $$a$$ has an inverse $$a^{-1}$$, with $$a^{-1}a = 1$$
(:ref{#numbers/inverse-exists}). The inverse is not $$0$$, since $$0 \cdot a = 0$$, not $$1$$. So
multiplying both sides by $$a^{-1}$$ is a safe step, and gives the equivalent equation
$$a^{-1}(ax) = a^{-1}c$$. Regrouping, the left side is $$(a^{-1}a)x = 1 \cdot x = x$$, and the right
side is $$\frac{c}{a}$$ by :ref{#numbers/quotient}. So $$ax = c$$ is equivalent to
$$x = \frac{c}{a}$$, whose only solution is $$\frac{c}{a}$$.

**Case 2: $$a = 0$$ and $$c \neq 0$$.** Whatever $$x$$ is, the left side is $$0 \cdot x = 0$$ by
:ref{#numbers/zero-times}, and the right side is $$c$$, which is not $$0$$. So no $$x$$ makes the
equation true.

**Case 3: $$a = 0$$ and $$c = 0$$.** Now the equation says $$0 \cdot x = 0$$, which is true for
every $$x$$, again by :ref{#numbers/zero-times}.

:::

Cases 2 and 3 turn up naturally. Expanding $$2(x + 1) = 2x + 5$$ and subtracting $$2x$$ from both
sides leaves $$2 = 5$$, which is $$0 \cdot x = 3$$ in disguise: false whatever $$x$$ is, so there is
no solution. Doing the same to $$2(x + 1) = 2x + 2$$ leaves $$2 = 2$$, which is $$0 \cdot x = 0$$:
true for every $$x$$. So when the unknown seems to vanish, look at what is left. A false statement
means no solution; a true one means every number is a solution.

:::example[A linear equation with fractions]

Solve $$\frac{x}{4} - \frac{1}{3} = \frac{x}{6} + 1$$.

Fractions are easiest to get rid of first. The denominators $$4$$, $$3$$ and $$6$$ all divide
$$12$$, so multiply both sides by $$12$$, a safe step since $$12 \neq 0$$:

```math
3x - 4 = 2x + 12
```

Subtracting $$2x$$ and adding $$4$$ to both sides gives $$x = 16$$.

**Check:** $$\frac{16}{4} - \frac{1}{3} = 4 - \frac{1}{3} = \frac{11}{3}$$, and
$$\frac{16}{6} + 1 = \frac{8}{3} + 1 = \frac{11}{3}$$.

:::

## Exercises

:::::accordion[Exercises on equations and solutions, with solutions]

::::exercise{#ex-equations-check-values}

Which of $$x = -1$$, $$x = 2$$ and $$x = 3$$ are solutions of $$x^2 - x = 2$$? Does checking these
three values solve the equation?

:::solution

Put each value into the left side:

- $$x = -1$$: $$(-1)^2 - (-1) = 1 + 1 = 2$$, so it is a solution
- $$x = 2$$: $$4 - 2 = 2$$, so it is a solution
- $$x = 3$$: $$9 - 3 = 6$$, which is not $$2$$, so it is not a solution

This doesn't solve the equation. Solving means finding **all** the solutions (:ref{#solution}), and
checking a few values says nothing about the numbers that weren't tried. Some other argument is
needed to show that $$-1$$ and $$2$$ are the only ones.

:::

::::

::::exercise{#ex-equations-equivalent-pairs}

For each pair, say whether the two equations are equivalent. If they aren't, give a number that
solves one but not the other.

1. $$2x - 3 = 7$$ and $$x = 5$$
2. $$x = 4$$ and $$x^2 = 16$$
3. $$\frac{x}{2} = 3$$ and $$x = 6$$
4. $$x(x - 1) = 0$$ and $$x - 1 = 0$$

:::solution

1. Equivalent. Adding $$3$$ to both sides and then multiplying by $$\frac{1}{2}$$ are safe steps
   (:ref{#safe-steps}), and they turn the first equation into the second.
2. Not equivalent. The number $$-4$$ solves $$x^2 = 16$$, since $$(-4)^2 = 16$$, but it doesn't
   solve $$x = 4$$.
3. Equivalent. Multiplying both sides by $$2$$ is a safe step, since $$2 \neq 0$$.
4. Not equivalent. The number $$0$$ solves $$x(x - 1) = 0$$, since $$0 \cdot (-1) = 0$$, but
   $$0 - 1 = -1$$, so it doesn't solve $$x - 1 = 0$$. Dividing by $$x$$ would lose this solution.

:::

::::

::::exercise{#ex-equations-brackets}

Solve $$5(x - 2) - 3(2x + 1) = 4 - 2x$$, and check your answer.

:::solution

Expanding the left side, $$5x - 10 - 6x - 3 = -x - 13$$, so the equation is $$-x - 13 = 4 - 2x$$.
Adding $$2x$$ and $$13$$ to both sides gives $$x = 17$$.

**Check:** the left side is $$5 \cdot 15 - 3 \cdot 35 = 75 - 105 = -30$$, and the right side is
$$4 - 34 = -30$$.

:::

::::

::::exercise{#ex-equations-three-fractions}

Solve $$\frac{x - 1}{6} + \frac{x + 2}{4} = 2 - \frac{x}{3}$$.

:::solution

The denominators $$6$$, $$4$$ and $$3$$ all divide $$12$$. Multiplying both sides by $$12$$ is a
safe step, and keeping the brackets gives

```math
2(x - 1) + 3(x + 2) = 24 - 4x
```

Expanding, $$5x + 4 = 24 - 4x$$, so $$9x = 20$$ and $$x = \frac{20}{9}$$.

**Check:** the left side is
$$\frac{11}{54} + \frac{38}{36} = \frac{22}{108} + \frac{114}{108} = \frac{34}{27}$$, and the right
side is $$2 - \frac{20}{27} = \frac{34}{27}$$.

:::

::::

::::exercise{#ex-equations-divide-by-x}

To solve $$3x = 5x$$, a student divides both sides by $$x$$, gets $$3 = 5$$, and concludes that
there is no solution. What went wrong? Solve the equation correctly.

:::solution

Dividing by $$x$$ is multiplying by $$\frac{1}{x}$$, which only makes sense when $$x \neq 0$$. So
the student's step is not one of the safe steps (:ref{#safe-steps}), and it threw away the case
$$x = 0$$.

Correctly: subtracting $$3x$$ from both sides gives $$0 = 2x$$, so $$x = 0$$ by :ref{#one-unknown}.
**Check:** $$3 \cdot 0 = 0 = 5 \cdot 0$$. So the equation has exactly one solution, $$x = 0$$.

:::

::::

::::exercise{#ex-equations-squaring}

Squaring both sides of $$2x + 1 = x - 3$$ gives $$(2x + 1)^2 = (x - 3)^2$$.

1. Show that $$x = \frac{2}{3}$$ solves the squared equation but not the original one.
2. Solve the original equation.

:::solution

1. At $$x = \frac{2}{3}$$, the two sides of the original equation are
   $$\frac{4}{3} + 1 = \frac{7}{3}$$ and $$\frac{2}{3} - 3 = -\frac{7}{3}$$. These are different, so
   $$\frac{2}{3}$$ doesn't solve the original. But they are opposites, so their squares are equal,
   both $$\frac{49}{9}$$: it does solve the squared equation.
2. Subtracting $$x$$ and $$1$$ from both sides gives $$x = -4$$. **Check:** $$-8 + 1 = -7$$ and
   $$-4 - 3 = -7$$.

Squaring can't be undone, because a number and its opposite have the same square. That is how the
false solution $$\frac{2}{3}$$ got in.

:::

::::

::::exercise{#ex-equations-same-answer}

Let $$a$$ be a number. Show that if $$a \neq 3$$, the equation $$a(x + 2) = 3x + 6$$ has exactly one
solution, and that it is $$x = -2$$ whatever $$a$$ is. What happens when $$a = 3$$?

:::solution

Expanding and rearranging, $$ax + 2a = 3x + 6$$ becomes $$(a - 3)x = 6 - 2a = -2(a - 3)$$.

If $$a \neq 3$$, then $$a - 3 \neq 0$$, so by :ref{#one-unknown} there is exactly one solution,
$$x = \frac{-2(a - 3)}{a - 3} = -2$$. This makes sense: the right side is $$3(x + 2)$$, so at
$$x = -2$$ both sides are $$0$$ whatever $$a$$ is.

If $$a = 3$$, the equation is $$0 \cdot x = 0$$, so every number is a solution. Both sides are then
$$3x + 6$$.

:::

::::

::::exercise{#ex-equations-one-answer-proof}

Without using :ref{#one-unknown}, show that if $$a \neq 0$$, the equation $$ax = c$$ can't have two
different solutions.

:::solution

Suppose $$x_1$$ and $$x_2$$ are both solutions, so $$ax_1 = c$$ and $$ax_2 = c$$. Subtracting,
$$ax_1 - ax_2 = 0$$, that is, $$a(x_1 - x_2) = 0$$.

A product is zero exactly when one of its factors is zero (:ref{#numbers/zero-product}). Since
$$a \neq 0$$, this forces $$x_1 - x_2 = 0$$, so $$x_1 = x_2$$. So any two solutions are the same
number.

:::
