---
title: No solution, or infinitely many
description: When a system has no solution or infinitely many, and the test that tells in advance.
---

Suppose a shop tells you that two pens and a notebook cost £5, and then that four pens and two
notebooks cost £9. Both can't be true, because buying the first lot twice should cost £10. Two
equations can clash like this, so that no numbers satisfy both, or one can repeat the other in
disguise, so that infinitely many do. In this guide we'll see how each case shows up while solving,
and find a single number, worked out from the coefficients, that tells you in advance whether there
is exactly one solution.

## When the equations contradict each other

Two equations can ask for something impossible. If one says a coffee and two teas cost £3, and the
other says a coffee and two teas cost £5, no prices fit both. Elimination exposes this. In trying to
remove one unknown, everything with an unknown in it cancels, and what is left is a false statement
about plain numbers.

:::example[No solution]

Try to solve

```math
\begin{aligned}
x + 2y &= 3 &\quad (1) \\
x + 2y &= 5 &\quad (2)
\end{aligned}
```

Subtracting (1) from (2) eliminates $$x$$, but $$y$$ disappears too:

```math
0 = 2
```

:::

The last line is false whatever $$x$$ and $$y$$ are. Since every step gave an equivalent system
(:ref{#combining}), the original system has the same solutions as one containing the equation
$$0 = 2$$, which is none at all. Looking back, the clash was there from the start: the same quantity
$$x + 2y$$ can't be both $$3$$ and $$5$$.

:::definition[Consistent and inconsistent systems]{#consistent}

A system is **consistent** if it has at least one solution, and **inconsistent** if it has none.

:::

The contradiction isn't always visible at a glance. In

```math
\begin{aligned}
2x - 3y &= 4 \\
-6x + 9y &= 7
\end{aligned}
```

multiplying the first equation by $$3$$ and adding gives $$0 = 19$$. The second equation's left side
is $$-3$$ times the first one's, but its right side isn't $$-3 \cdot 4$$.

## When one equation repeats the other

The opposite can happen too: the second equation can be the first in disguise. If a coffee and two
teas cost £3, then three coffees and six teas must cost £9, so being told the second fact adds
nothing. Then there is in effect only one equation in two unknowns, and that leaves infinitely many
possibilities.

:::example[Infinitely many solutions]

Try to solve

```math
\begin{aligned}
x + 2y &= 3 &\quad (1) \\
3x + 6y &= 9 &\quad (2)
\end{aligned}
```

Subtracting $$3$$ times (1) from (2) gives

```math
0 = 0
```

:::

This time the last line is true whatever $$x$$ and $$y$$ are, so it puts no condition on them at
all. Equation (2) is (1) multiplied by $$3$$, so it says nothing new, and the system has the same
solutions as (1) alone. There are infinitely many: choose any number $$t$$ for $$y$$, and then
$$x = 3 - 2t$$. So the solutions are

```math
(3 - 2t,\ t) \qquad\text{for every number } t
```

For example $$t = 0$$ gives $$(3, 0)$$, $$t = 1$$ gives $$(1, 1)$$ and $$t = -2$$ gives $$(7, -2)$$.
Describing the solutions with a free letter such as $$t$$ is how "infinitely many" is written down
exactly.

## A test that tells in advance

Whether a system has exactly one solution depends only on its coefficients, not on its right-hand
sides. In both examples so far, the left side of one equation is a multiple of the other's, so
removing one unknown removes the other as well. Then the right-hand sides decide between no solution
and infinitely many.

If the left sides are not linked in this way, elimination always leaves a value for each unknown,
whatever the right-hand sides are. So one number, worked out from the coefficients, can tell in
advance whether there is exactly one solution. To find it, write a general system with letters for
the coefficients:

```math
\begin{aligned}
ax + by &= u &\quad (1) \\
cx + dy &= v &\quad (2)
\end{aligned}
```

:::definition[Determinant]{#determinant}

The **determinant** of this system is the number

```math
ad - bc
```

Write the coefficients in a grid, in the same places as in the equations. The determinant is
top-left times bottom-right, minus top-right times bottom-left:

| $$x$$ | $$y$$ |
| ----- | ----- |
| $$a$$ | $$b$$ |
| $$c$$ | $$d$$ |

:::

For the system $$3x + 2y = 7$$ and $$5x - 3y = 37$$, the determinant is
$$3 \cdot (-3) - 2 \cdot 5 = -19$$. For $$x + 2y = 3$$ and $$3x + 6y = 9$$, it is
$$1 \cdot 6 - 2 \cdot 3 = 0$$.

:::theorem[Non-zero determinant means one solution]{#determinant-test}

If $$ad - bc \neq 0$$, the system has exactly one solution, namely

```math
x = \frac{du - bv}{ad - bc}, \qquad y = \frac{av - cu}{ad - bc}
```

:::

:::proof{source="https://en.wikipedia.org/wiki/Cramer%27s_rule#Explicit_formulas_for_small_systems"}

There are two things to show: that a solution can only be this pair, and that this pair is a
solution.

**Only this pair can work.** Suppose $$(x, y)$$ is a solution. Eliminate $$y$$ by multiplying (1) by
$$d$$ and (2) by $$b$$, and subtracting:

```math
\begin{aligned}
adx + bdy &= du \\
bcx + bdy &= bv
\end{aligned}
\qquad\longrightarrow\qquad
(ad - bc)x = du - bv
```

Similarly, eliminate $$x$$ by multiplying (1) by $$c$$ and (2) by $$a$$, and subtracting the first
from the second:

```math
\begin{aligned}
acx + bcy &= cu \\
acx + ady &= av
\end{aligned}
\qquad\longrightarrow\qquad
(ad - bc)y = av - cu
```

Since $$ad - bc \neq 0$$, each of these has exactly one solution by :ref{#one-unknown}, which is the
pair in the theorem. So no other pair can solve the system.

**This pair does work.** Write $$D = ad - bc$$. Putting the pair into the left side of (1),

```math
a \cdot \frac{du - bv}{D} + b \cdot \frac{av - cu}{D}
= \frac{adu - abv + abv - bcu}{D}
= \frac{(ad - bc)u}{D}
= u
```

which is the right side of (1). In the same way, the left side of (2) is

```math
c \cdot \frac{du - bv}{D} + d \cdot \frac{av - cu}{D}
= \frac{cdu - bcv + adv - cdu}{D}
= \frac{(ad - bc)v}{D}
= v
```

So the pair solves both equations.

:::

The first half of the proof is elimination, done once and for all with letters. It doesn't finish
the job on its own, because it multiplied the equations by $$d$$, $$b$$, $$c$$ and $$a$$, and some
of these might be $$0$$. Multiplying by $$0$$ isn't a safe step, so the first half only shows that a
solution would have to be this pair. Checking the pair directly shows that it is one.

:::example[Using the formula]

For $$3x + 2y = 7$$ and $$5x - 3y = 37$$: $$a = 3$$, $$b = 2$$, $$c = 5$$, $$d = -3$$, $$u = 7$$ and
$$v = 37$$. The determinant is $$-19$$, so

```math
x = \frac{(-3) \cdot 7 - 2 \cdot 37}{-19} = \frac{-95}{-19} = 5,
\qquad
y = \frac{3 \cdot 37 - 5 \cdot 7}{-19} = \frac{76}{-19} = -4
```

which matches the answer found by elimination on the
[Two equations in two unknowns](./two-unknowns.mdx) page.

:::

The formula is worth knowing, but for particular numbers elimination usually takes fewer steps and
invites fewer slips. The formula's main value is the test: a non-zero determinant guarantees exactly
one solution.

## When the determinant is zero

A zero determinant means the two left-hand sides are tied together, one a multiple of the other.
Then the two equations make claims about the same quantity. Either the claims agree, and the second
equation adds nothing, or they disagree, and nothing works. There is no room for exactly one answer.
The proof makes the "infinitely many" case concrete: starting from one solution, you can keep moving
in a direction that leaves both left-hand sides unchanged, and every pair you reach is a solution
too.

:::theorem[Zero determinant means none or infinitely many]{#determinant-zero}

If $$ad - bc = 0$$, the system has either no solution or infinitely many. It never has exactly one.

:::

:::proof{source="https://en.wikipedia.org/wiki/Cramer%27s_rule#Inconsistent_and_indeterminate_cases"}

If the system has no solution, there is nothing to prove. So suppose it has a solution
$$(x_0, y_0)$$. The proof finds infinitely many more by moving away from it in a direction that
changes neither left-hand side.

**Finding a direction.** The aim is a pair $$(p, q)$$, not both zero, with

```math
ap + bq = 0 \qquad\text{and}\qquad cp + dq = 0
```

- If $$a$$ and $$b$$ are not both zero, take $$(p, q) = (b, -a)$$. Then $$ap + bq = ab - ba = 0$$,
  and $$cp + dq = cb - da = -(ad - bc) = 0$$.
- If $$a = b = 0$$ but $$c$$ and $$d$$ are not both zero, take $$(p, q) = (d, -c)$$. Then
  $$ap + bq = 0$$ because $$a = b = 0$$, and $$cp + dq = cd - dc = 0$$.
- If all four coefficients are zero, take $$(p, q) = (1, 0)$$.

**Moving in that direction.** For any number $$t$$, put $$x = x_0 + tp$$ and $$y = y_0 + tq$$. Then

```math
ax + by = (ax_0 + by_0) + t(ap + bq) = u + t \cdot 0 = u
```

and in the same way $$cx + dy = v + t(cp + dq) = v$$. So every such pair is a solution.

**These are all different.** Take two different numbers $$s$$ and $$t$$. The pairs they give differ
by $$(t - s)p$$ in $$x$$ and $$(t - s)q$$ in $$y$$. Since $$t - s \neq 0$$, and $$p$$ and $$q$$ are
not both zero, at least one of these differences is non-zero by :ref{#numbers/zero-product}. So
different values of $$t$$ give different pairs, and there are infinitely many of them.

:::

Putting the two theorems together:

| Determinant $$ad - bc$$ | Number of solutions | What elimination ends with            |
| ----------------------- | ------------------- | ------------------------------------- |
| not zero                | exactly one         | a value for each unknown              |
| zero                    | none                | something false, like $$0 = 2$$       |
| zero                    | infinitely many     | something always true, like $$0 = 0$$ |

In both examples on this page, one left-hand side is a multiple of the other. In the first, both are
$$x + 2y$$; in the second, $$3x + 6y = 3(x + 2y)$$. What decides between the two cases is the
right-hand sides. If they are related by the same multiple, as $$9 = 3 \cdot 3$$ is, the second
equation repeats the first and there are infinitely many solutions. If not, as with $$3$$ and $$5$$,
the equations contradict each other and there are none. The [next page](./lines.mdx) shows the
picture: a zero determinant means the two lines are parallel or the same.

## When both right-hand sides are zero

A system whose right-hand sides are both $$0$$ always has at least one solution, $$x = y = 0$$. The
test says when that is the only one.

:::corollary[Only the zero solution]{#zero-right-side}

If $$ad - bc \neq 0$$, the only solution of

```math
\begin{aligned}
ax + by &= 0 \\
cx + dy &= 0
\end{aligned}
```

is $$x = 0$$, $$y = 0$$. If $$ad - bc = 0$$, it has infinitely many solutions.

:::

:::proof{source="https://en.wikipedia.org/wiki/System_of_linear_equations#Homogeneous_solution_set"}

If $$ad - bc \neq 0$$, by :ref{#determinant-test} there is exactly one solution, and $$(0, 0)$$ is
one, so it is the only one. (The formula agrees: with $$u = v = 0$$ both numerators are $$0$$.)

If $$ad - bc = 0$$, the system has a solution, $$(0, 0)$$, so by :ref{#determinant-zero} it has
infinitely many.

:::

## Exercises

:::::accordion[Exercises on no solution or infinitely many, with solutions]

::::exercise{#ex-special-cases-two-systems}

For each system, find the determinant, say how many solutions there are, and find them if there are
any.

1. $$4x - 6y = 2$$ and $$-2x + 3y = 1$$
2. $$5x + 2y = 1$$ and $$3x + y = 4$$

:::solution

1. The determinant is $$4 \cdot 3 - (-6) \cdot (-2) = 12 - 12 = 0$$, so there is no solution or
   infinitely many (:ref{#determinant-zero}). Multiplying the second equation by $$-2$$ gives
   $$4x - 6y = -2$$, while the first says $$4x - 6y = 2$$. The same quantity can't be both, so there
   is **no solution**.
2. The determinant is $$5 \cdot 1 - 2 \cdot 3 = -1$$, which is not zero, so there is **exactly one**
   solution (:ref{#determinant-test}). The formula gives
   $$x = \frac{1 \cdot 1 - 2 \cdot 4}{-1} = 7$$ and $$y = \frac{5 \cdot 4 - 3 \cdot 1}{-1} = -17$$.
   **Check:** $$35 - 34 = 1$$ and $$21 - 17 = 4$$.

:::

::::

::::exercise{#ex-special-cases-two-descriptions}

Find all solutions of $$2x - 4y = 6$$ and $$-x + 2y = -3$$. Describe them once with a free letter
for $$y$$, and once with a free letter for $$x$$. Explain why both descriptions give the same pairs.

:::solution

Multiplying the second equation by $$-2$$ gives the first, so the system has the same solutions as
$$x - 2y = 3$$ alone.

- **With $$y = t$$ free:** $$x = 3 + 2t$$, so the solutions are $$(3 + 2t,\ t)$$ for every number
  $$t$$.
- **With $$x = s$$ free:** $$2y = s - 3$$, so the solutions are $$(s,\ \frac{s - 3}{2})$$ for every
  number $$s$$.

Both descriptions list exactly the pairs that solve $$x - 2y = 3$$. Given $$t$$, the pair from the
first description is the pair from the second with $$s = 3 + 2t$$, since then
$$\frac{s - 3}{2} = t$$. So the two lists are the same, counted differently.

:::

::::

::::exercise{#ex-special-cases-two-zero-cases}

For which numbers $$a$$ does the system $$x + ay = 2$$, $$ax + 9y = 6$$ have exactly one solution?
For each other value of $$a$$, say whether there is no solution or infinitely many.

:::solution

The determinant is $$1 \cdot 9 - a \cdot a = 9 - a^2$$. It is zero exactly when $$a^2 = 9$$, that
is, when $$a = 3$$ or $$a = -3$$. For every other $$a$$ there is exactly one solution
(:ref{#determinant-test}).

- **$$a = 3$$:** the equations are $$x + 3y = 2$$ and $$3x + 9y = 6$$. The second is $$3$$ times the
  first, so there are **infinitely many** solutions.
- **$$a = -3$$:** the equations are $$x - 3y = 2$$ and $$-3x + 9y = 6$$. Multiplying the first by
  $$-3$$ gives $$-3x + 9y = -6$$, which contradicts the second, so there is **no solution**.

:::

::::

::::exercise{#ex-special-cases-empty-left-side}

Find the determinant and all solutions of each system.

1. $$0x + 0y = 0$$ and $$x + y = 2$$
2. $$0x + 0y = 1$$ and $$x + y = 2$$

:::solution

In both, $$a = b = 0$$, so the determinant is $$0 \cdot 1 - 0 \cdot 1 = 0$$.

1. The first equation is true for every pair, so the solutions are those of $$x + y = 2$$:
   **infinitely many**, the pairs $$(2 - t,\ t)$$ for every number $$t$$.
2. The first equation is false for every pair, since $$0 \neq 1$$, so there is **no solution**.

These are the two cases :ref{#determinant-zero} allows. Its proof has a separate step for
$$a = b = 0$$, and the first system is an example of it.

:::

::::

::::exercise{#ex-special-cases-two-solutions}

Suppose a system $$ax + by = u$$, $$cx + dy = v$$ has two different solutions $$(x_1, y_1)$$ and
$$(x_2, y_2)$$. Show that $$ad - bc = 0$$, using :ref{#zero-right-side}.

:::solution

Subtract the equations for the two solutions. From $$ax_1 + by_1 = u$$ and $$ax_2 + by_2 = u$$,

```math
a(x_1 - x_2) + b(y_1 - y_2) = 0
```

and in the same way $$c(x_1 - x_2) + d(y_1 - y_2) = 0$$. So the pair $$(x_1 - x_2,\ y_1 - y_2)$$
solves the system with both right-hand sides $$0$$. It isn't $$(0, 0)$$, because the two solutions
are different.

If $$ad - bc$$ were not zero, :ref{#zero-right-side} would say $$(0, 0)$$ is the only solution of
that system. So $$ad - bc = 0$$.

:::
