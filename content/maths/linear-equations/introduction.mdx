A great many questions come down to a few unknown numbers tied together by a few facts. Four coffees
and two teas cost £14; a coffee and three teas cost £8.50; what does each cost? Each fact becomes an
equation, and the answer is the set of numbers that makes every equation true at once.

This guide is about the simplest and most common kind, **linear** equations, where the unknowns are
only multiplied by numbers and added together. It covers how to solve them, and also why the methods
work, what can go wrong, and how to tell in advance whether a system has one solution, none, or
infinitely many.

It builds on the [Numbers](../numbers/introduction.mdx) guide, especially the pages on rational
numbers and inverses, and links back to it where a result from there is used.

**Definitions**

| Term                                    | Meaning                                                              |
| --------------------------------------- | -------------------------------------------------------------------- |
| :ref[Solution]{#solution}               | Values of the unknowns that make the equation true                   |
| :ref[Equivalent equations]{#equivalent} | Equations with exactly the same solutions                            |
| :ref[Linear equation]{#linear-one}      | One that can be brought to $$ax = c$$, or $$ax + by = c$$, and so on |
| :ref[System]{#system}                   | Equations to be satisfied at the same time                           |
| :ref[Consistent]{#consistent}           | Having at least one solution; **inconsistent** means having none     |
| :ref[Determinant]{#determinant}         | $$ad - bc$$, for $$ax + by = u$$ and $$cx + dy = v$$                 |
| :ref[Graph]{#graph}                     | All points $$(x, y)$$ whose coordinates solve the equation           |
| :ref[Slope]{#slope}                     | $$m$$ in $$y = mx + k$$: how much $$y$$ changes per step right       |

**Equations and solutions**

| Rule                               | Statement                                                                     |
| ---------------------------------- | ----------------------------------------------------------------------------- |
| :ref[Safe steps]{#safe-steps}      | Add the same thing to both sides, or multiply both sides by a non-zero number |
| :ref[Solving ax = c]{#one-unknown} | $$a \neq 0$$: one solution $$\frac{c}{a}$$; $$a = 0$$: none, or every number  |

**Two unknowns**

| Rule                                           | Statement                                                                                          |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| :ref[Combining equations]{#combining}          | Adding a multiple of one equation to another gives an equivalent system                            |
| :ref[Elimination]{#elimination}                | Match one unknown's coefficients, add or subtract, solve, back-substitute                          |
| :ref[Substitution]{#substitution}              | Rearrange one equation as $$y = \ldots$$ and put it into the other                                 |
| :ref[Exactly one solution]{#determinant-test}  | $$ad - bc \neq 0$$: one solution, $$x = \frac{du - bv}{ad - bc}$$, $$y = \frac{av - cu}{ad - bc}$$ |
| :ref[Zero determinant]{#determinant-zero}      | $$ad - bc = 0$$: no solution or infinitely many                                                    |
| :ref[Only the zero solution]{#zero-right-side} | With $$u = v = 0$$: only $$(0, 0)$$ exactly when $$ad - bc \neq 0$$                                |
| :ref[Same slope]{#parallel-test}               | Non-vertical lines have the same slope exactly when $$ad - bc = 0$$                                |

**Three unknowns**

| Rule                        | Statement                                                                             |
| --------------------------- | ------------------------------------------------------------------------------------- |
| :ref[Method]{#three-method} | Eliminate the same unknown from two different pairs, then solve the two that are left |
