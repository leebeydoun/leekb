Imagine a school trip where 30 people went, children's tickets cost £3, adults' tickets cost £5, and
the bill came to £110. Nobody wrote down how many adults went, yet those facts are enough to work it
out. Each fact is an equation, and the answer is the pair of numbers that makes both equations true
at once.

Equations like these are called **linear**: the unknowns are only multiplied by numbers and added
together. In this chapter we'll learn to solve them, and see why the methods work. Along the way
we'll find out what can go wrong, and how to tell in advance whether a system has one solution,
none, or infinitely many.

This chapter builds on the [Numbers](../numbers/introduction.mdx) chapter, especially the guides on
rational numbers and inverses, and links back to it wherever a result from there is used.

**Definitions**

| Term                                    | Meaning                                                              |
| --------------------------------------- | -------------------------------------------------------------------- |
| :ref[Solution]{#solution}               | Values of the unknowns that make the equation true                   |
| :ref[Equivalent equations]{#equivalent} | Equations with exactly the same solutions                            |
| :ref[Linear equation]{#linear-one}      | One that can be brought to $$ax = c$$, or $$ax + by = c$$, and so on |
| :ref[System]{#system}                   | Equations to be satisfied at the same time                           |
| :ref[Consistent]{#consistent}           | Having at least one solution; **inconsistent** means having none     |
| :ref[Determinant]{#determinant}         | $$ad - bc$$, for $$ax + by = u$$ and $$cx + dy = v$$                 |
| :ref[Graph]{#graph}                     | All points $$(x, y)$$ whose coordinates solve the equation           |
| :ref[Slope]{#slope}                     | $$m$$ in $$y = mx + k$$: how much $$y$$ changes per step right       |

**Equations and solutions**

| Rule               | Statement                                                                     |
| ------------------ | ----------------------------------------------------------------------------- |
| :ref{#safe-steps}  | Add the same thing to both sides, or multiply both sides by a non-zero number |
| :ref{#one-unknown} | $$a \neq 0$$: one solution $$\frac{c}{a}$$; $$a = 0$$: none, or every number  |

**Two unknowns**

| Rule                    | Statement                                                                                          |
| ----------------------- | -------------------------------------------------------------------------------------------------- |
| :ref{#combining}        | Adding a multiple of one equation to another gives an equivalent system                            |
| :ref{#elimination}      | Match one unknown's coefficients, add or subtract, solve, back-substitute                          |
| :ref{#substitution}     | Rearrange one equation as $$y = \ldots$$ and put it into the other                                 |
| :ref{#determinant-test} | $$ad - bc \neq 0$$: one solution, $$x = \frac{du - bv}{ad - bc}$$, $$y = \frac{av - cu}{ad - bc}$$ |
| :ref{#determinant-zero} | $$ad - bc = 0$$: no solution or infinitely many                                                    |
| :ref{#zero-right-side}  | With $$u = v = 0$$: only $$(0, 0)$$ exactly when $$ad - bc \neq 0$$                                |
| :ref{#parallel-test}    | Non-vertical lines have the same slope exactly when $$ad - bc = 0$$                                |

**Three unknowns**

| Rule                | Statement                                                                             |
| ------------------- | ------------------------------------------------------------------------------------- |
| :ref{#three-method} | Eliminate the same unknown from two different pairs, then solve the two that are left |
