Picture a cup of tea left on the desk while you answer an email. When you come back it is cooler,
and if you had written down its temperature every few minutes, each moment would have exactly one
reading beside it. The temperature depends on the time. That is the idea of a **function**: a rule
that gives exactly one output for each input. In this chapter we'll learn to read functions, draw
them and undo them, and meet the functions that describe doubling, halving and cooling.

One idea carries the chapter: a function is a rule, and its graph is a picture of that rule which
you can read, move and flip. Reading a value means going up from the input and across to the output.
Undoing a function means flipping its graph in the line $$y = x$$, and that flip is how logarithms
arrive from exponentials.

## What this chapter builds on

The rules for fractional powers come from [Roots and powers](../real-numbers/roots-and-powers.mdx),
and they grow here into powers $$a^x$$ for every number $$x$$. Moving a graph uses
[Sliding and stretching graphs](../parabolas-ellipses-and-hyperbolas/sliding-and-stretching.mdx).
Combining and undoing functions repeat for numbers what [Isometries](../isometries/introduction.mdx)
did for moves of the plane, and [Division with remainder](../numbers/divisibility.mdx) is the model
for dividing polynomials. [Mappings and permutations](../mappings-and-permutations/introduction.mdx)
takes combining and undoing further.

Four facts are taken as given, because proving them needs ideas from a course on analysis: the rules
for powers $$a^x$$ with any exponent (:ref{#exponential-rules}), that every positive number is a
power of any base (:ref{#log-exists}), that compound interest settles towards the number $$e$$
(:ref{#e-exists}), and that at a rate $$r$$ it settles towards $$e^r$$ (:ref{#the-number-e-rate}).
Everything else is proved.

Along the way the chapter picks up two threads from earlier chapters:

- **Inverse functions**: [Trigonometry](../trigonometry/right-triangles.mdx) met $$\sin^{-1}$$ as an
  angle with a given sine. Here it becomes one case of undoing a function (:ref{#inverse-function}).
- **Counting roots**: [The discriminant](../quadratics/discriminant.mdx) showed a quadratic has at
  most two solutions. Here every polynomial of degree $$n$$ has at most $$n$$ (:ref{#root-bound}).

**Definitions**

| Term                        | Meaning                                                                                  |
| --------------------------- | ---------------------------------------------------------------------------------------- |
| :ref{#function}             | A rule giving each element $$x$$ of a set $$S$$, the domain, exactly one number $$f(x)$$ |
| :ref{#range}                | The set of all values $$f(x)$$                                                           |
| :ref{#formula-domain}       | With no domain named, all $$x$$ for which the formula makes sense                        |
| :ref{#function-equality}    | Same domain and the same value at every point                                            |
| :ref{#function-operations}  | $$(f + g)(x) = f(x) + g(x)$$ and $$(fg)(x) = f(x)g(x)$$ on the common domain             |
| :ref{#function-composite}   | $$(g \circ f)(x) = g(f(x))$$: do $$f$$ first                                             |
| :ref{#one-to-one}           | $$f(x) = f(x')$$ only when $$x = x'$$                                                    |
| :ref{#inverse-function}     | $$f^{-1}(y)$$ is the one $$x$$ with $$f(x) = y$$                                         |
| :ref{#function-graph}       | The points $$(x, f(x))$$ for $$x$$ in the domain                                         |
| :ref{#floor}                | $$\lfloor x \rfloor$$ is the largest integer $$\le x$$                                   |
| :ref{#increasing}           | $$x < y$$ gives $$f(x) < f(y)$$ (increasing) or $$f(x) > f(y)$$ (decreasing)             |
| :ref{#even-odd-function}    | Even: $$f(-x) = f(x)$$. Odd: $$f(-x) = -f(x)$$                                           |
| :ref{#polynomial}           | $$a_n x^n + \cdots + a_1 x + a_0$$, with coefficients $$a_k$$                            |
| :ref{#polynomial-root}      | A number $$c$$ with $$f(c) = 0$$                                                         |
| :ref{#degree}               | The largest $$n$$ with $$a_n \ne 0$$; the zero polynomial has no degree                  |
| :ref{#rational-function}    | $$\frac{f(x)}{g(x)}$$ for polynomials, defined where $$g(x) \ne 0$$                      |
| :ref{#exponential-function} | $$x \mapsto a^x$$ for a base $$a > 0$$                                                   |
| :ref{#growth-decay}         | $$f(t) = C \cdot a^{kt}$$: growth when $$a^k > 1$$, decay when $$a^k < 1$$               |
| :ref{#logarithm}            | $$\log_a y = x$$ exactly when $$a^x = y$$                                                |
| :ref{#natural-log}          | $$\ln x = \log_e x$$                                                                     |

**Taken as given**

| Rule                     | Statement                                                                                            |
| ------------------------ | ---------------------------------------------------------------------------------------------------- |
| :ref{#exponential-rules} | $$a^{x + y} = a^x a^y$$, $$(a^x)^y = a^{xy}$$, $$(ab)^x = a^x b^x$$, and $$a^x$$ rises for $$a > 1$$ |
| :ref{#log-exists}        | Every $$y > 0$$ is $$a^x$$ for some $$x$$, when $$a > 0$$ and $$a \ne 1$$                            |
| :ref{#e-exists}          | $$\left(1 + \frac{1}{n}\right)^n$$ increases and settles towards $$e \approx 2.71828$$               |
| :ref{#the-number-e-rate} | $$\left(1 + \frac{r}{n}\right)^n$$ settles towards $$e^r$$                                           |

**Functions and graphs**

| Result                              | Statement                                                                                       |
| ----------------------------------- | ----------------------------------------------------------------------------------------------- |
| :ref{#function-arithmetic}          | Functions add and multiply with the same rules as numbers                                       |
| :ref{#inverse-undoes}               | $$f^{-1}(f(x)) = x$$ and $$f(f^{-1}(y)) = y$$                                                   |
| :ref{#vertical-line-test}           | A set is a graph of a function exactly when no vertical line meets it twice                     |
| :ref{#graphs-floor-exists}          | Every number lies in a step $$n \le x < n + 1$$, so it has a floor                              |
| :ref{#graphs-increasing-one-to-one} | An increasing or decreasing function is one to one                                              |
| :ref{#function-graph-moves}         | $$f(x - h) + k$$ slides, $$af(x)$$ and $$f(\frac{x}{a})$$ stretch, $$-f(x)$$ and $$f(-x)$$ flip |
| :ref{#even-odd-graphs}              | Even means mirror symmetric in the $$y$$-axis; odd means unchanged by a half turn               |
| :ref{#even-odd-parts}               | Every $$f$$ is one even function plus one odd function, in exactly one way                      |
| :ref{#even-odd-arithmetic}          | Even times even and odd times odd are even; even times odd is odd                               |
| :ref{#inverse-graph}                | The graph of $$f^{-1}$$ is the graph of $$f$$ flipped in $$y = x$$                              |

**Polynomials**

| Result                                  | Statement                                                                                |
| --------------------------------------- | ---------------------------------------------------------------------------------------- |
| :ref{#polynomials-difference-of-powers} | $$x^k - c^k = (x - c)(x^{k-1} + x^{k-2}c + \cdots + c^{k-1})$$                           |
| :ref{#factor-theorem}                   | If $$f(c) = 0$$ then $$f(x) = (x - c)g(x)$$, with $$g$$ one degree lower                 |
| :ref{#root-bound}                       | A polynomial of degree $$n$$ has at most $$n$$ roots                                     |
| :ref{#coefficients-unique}              | Two formulas for the same function have the same coefficients                            |
| :ref{#degree-product}                   | $$\deg(fg) = \deg f + \deg g$$                                                           |
| :ref{#factor-by-roots}                  | With $$n$$ different roots, $$f(x) = a_n(x - c_1)\cdots(x - c_n)$$                       |
| :ref{#power-plus-minus-one}             | The real roots of $$x^n \mp 1$$ are $$\pm 1$$, depending on whether $$n$$ is even or odd |
| :ref{#integer-root}                     | With integer coefficients and leading coefficient $$1$$, an integer root divides $$a_0$$ |
| :ref{#polynomial-division}              | $$f = qg + r$$ with $$r = 0$$ or $$\deg r < \deg g$$, in exactly one way                 |
| :ref{#remainder-theorem}                | Dividing by $$x - c$$ leaves the remainder $$f(c)$$                                      |

**Exponentials and logarithms**

| Result                             | Statement                                                                                                      |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| :ref{#exponential-positive}        | $$a^0 = 1$$, $$a^{-x} = \frac{1}{a^x}$$ and $$a^x > 0$$                                                        |
| :ref{#exponential-small-base}      | For $$0 < a < 1$$, $$a^x = (\frac{1}{a})^{-x}$$, which falls                                                   |
| :ref{#exponential-one-to-one}      | For $$a \ne 1$$, $$a^x = a^y$$ only when $$x = y$$                                                             |
| :ref{#exponential-functions-bases} | For $$0 < a < b$$, $$a^x < b^x$$ when $$x > 0$$ and $$a^x > b^x$$ when $$x < 0$$                               |
| :ref{#exponential-steps}           | $$f(t + s) = f(t) \cdot a^{ks}$$: equal steps multiply by equal factors                                        |
| :ref{#log-inverse}                 | $$\log_a(a^x) = x$$ and $$a^{\log_a y} = y$$                                                                   |
| :ref{#log-laws}                    | $$\log_a(xy) = \log_a x + \log_a y$$, $$\log_a \frac{x}{y} = \log_a x - \log_a y$$, $$\log_a x^r = r\log_a x$$ |
| :ref{#log-increasing}              | For $$a > 1$$, $$x < y$$ exactly when $$\log_a x < \log_a y$$                                                  |
| :ref{#change-of-base}              | $$\log_b x = \frac{\log_a x}{\log_a b}$$                                                                       |
| :ref{#log-graph}                   | The graph of $$\log_a$$ is the graph of $$a^x$$ flipped in $$y = x$$                                           |
| :ref{#base-e}                      | $$a^x = e^{x \ln a}$$, so every growth or decay is $$Ce^{Kt}$$                                                 |
| :ref{#rate-from-two}               | $$K = \frac{\ln(f(t_2)/f(t_1))}{t_2 - t_1}$$                                                                   |
| :ref{#half-life}                   | Doubling time $$\frac{\ln 2}{K}$$ for growth, half-life $$\frac{\ln 2}{-K}$$ for decay                         |

:::
