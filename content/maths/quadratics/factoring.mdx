---
title: Solving by factoring
description:
  Splitting a quadratic into two factors, so that one quadratic equation becomes two linear ones.
---

Multiply out $$(x + 3)(x - 4)$$ and you get $$x^2 - x - 12$$. Factoring runs this the other way: it
starts from the quadratic and finds the two brackets. That's worth doing, because a quadratic
equation written as a product equal to $$0$$ is nearly solved. It splits into two linear equations,
one for each bracket.

In this guide we'll see why that split works, how to find the brackets, and when another method is
the better choice.

## Products equal to zero

Two numbers that aren't $$0$$ can never multiply to give $$0$$. So if a product is $$0$$, at least
one of the numbers in it must be $$0$$. Now suppose $$(x - 2)(x + 5) = 0$$. For each $$x$$, the two
brackets are two numbers, so one of them is $$0$$: either $$x - 2 = 0$$ or $$x + 5 = 0$$. That gives
$$x = 2$$ or $$x = -5$$, and both work, since each one makes a bracket $$0$$ and anything times
$$0$$ is $$0$$.

The rule that a zero product needs a zero factor was proved for fractions in the Numbers chapter
(:ref{#numbers/zero-product}). The proof only used inverses of non-zero numbers, so it holds for all
real numbers too.

:::proposition[Solving by factors]{#solve-by-factors}

Let $$p$$, $$q$$, $$r$$ and $$t$$ be real numbers with $$p \neq 0$$ and $$r \neq 0$$. Then

```math
(px + q)(rx + t) = 0
```

exactly when $$x = -\frac{q}{p}$$ or $$x = -\frac{t}{r}$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Zero-product_property#Application_to_finding_roots_of_polynomials"}

Suppose $$(px + q)(rx + t) = 0$$. By :ref{#numbers/zero-product}, one of the factors is $$0$$. If
$$px + q = 0$$, then $$px = -q$$, and since $$p \neq 0$$ the linear equation has the single solution
$$x = -\frac{q}{p}$$ (:ref{#linear-equations/one-unknown}). In the same way, if $$rx + t = 0$$ then
$$x = -\frac{t}{r}$$.

Conversely, if $$x = -\frac{q}{p}$$, then $$px + q = -q + q = 0$$, so the product is $$0$$ times
$$rx + t$$, which is $$0$$ (:ref{#numbers/zero-times}). The same goes for $$x = -\frac{t}{r}$$,
which makes the second factor $$0$$.

:::

The two answers may be the same number. Then the equation has only one solution: $$(x - 3)(x - 3)$$
is $$0$$ only for $$x = 3$$.

The rule needs $$0$$ on one side. From $$(x - 1)(x - 2) = 6$$ you can't conclude that $$x - 1 = 6$$
or $$x - 2 = 6$$, since many pairs of numbers multiply to $$6$$. Expand, move the $$6$$ across, and
factor again: $$x^2 - 3x - 4 = 0$$, which is $$(x + 1)(x - 4) = 0$$, so $$x = -1$$ or $$x = 4$$.

## Finding the factors

To factor $$x^2 + bx + c$$, it helps to see what multiplying two brackets does. Picture
$$(x + 2)(x + 3)$$ as the area of a rectangle with sides $$x + 2$$ and $$x + 3$$. It splits into an
$$x$$ by $$x$$ square, two strips of areas $$3x$$ and $$2x$$, and a $$2$$ by $$3$$ corner.

:::area-model{row-sizes="4 2" col-sizes="4 3"}

|     | x   | 3   |
| --- | --- | --- |
| x   | x²  | 3x  |
| 2   | 2x  | 6   |

:::

So $$(x + 2)(x + 3) = x^2 + 5x + 6$$. The two strips add up to $$5x$$, which is $$x$$ times the
**sum** of $$2$$ and $$3$$. The corner is $$6$$, their **product**. The same happens for any two
numbers $$m$$ and $$n$$:

```math
(x + m)(x + n) = x^2 + (m + n)x + mn
```

Factoring runs this backwards: find two numbers whose sum is $$b$$ and whose product is $$c$$.

:::remark[Factoring x² + bx + c]{#factoring-method}

If $$m + n = b$$ and $$mn = c$$, then

```math
x^2 + bx + c = (x + m)(x + n)
```

and the solutions of $$x^2 + bx + c = 0$$ are $$x = -m$$ and $$x = -n$$.

::see-also{src="https://en.wikipedia.org/wiki/Quadratic_equation#Factoring_by_inspection"}

:::

Start from the product, since a whole number has only a few factor pairs. The signs narrow the
search too. If $$c$$ is positive, $$m$$ and $$n$$ have the same sign, which is the sign of $$b$$. If
$$c$$ is negative, they have opposite signs.

:::example[Two numbers with a given sum and product]

Solve $$x^2 - x - 12 = 0$$.

You need a product of $$-12$$, so the two numbers have opposite signs. You also need a sum of
$$-1$$. The pairs with product $$-12$$ are $$1, -12$$, then $$2, -6$$, then $$3, -4$$, and those
with the signs the other way round. Only $$3$$ and $$-4$$ add up to $$-1$$. So

```math
x^2 - x - 12 = (x + 3)(x - 4) = 0
```

and $$x = -3$$ or $$x = 4$$. Check: $$9 + 3 - 12 = 0$$ and $$16 - 4 - 12 = 0$$.

Solve $$x^2 - 7x + 10 = 0$$.

The product $$10$$ is positive and the sum $$-7$$ is negative, so both numbers are negative. The
pair $$-2, -5$$ works, so $$(x - 2)(x - 5) = 0$$ and $$x = 2$$ or $$x = 5$$.

:::

When $$a$$ isn't $$1$$, first see whether every coefficient shares a factor. In
$$3x^2 - 6x - 9 = 0$$ they all do, and dividing by $$3$$ leaves $$x^2 - 2x - 3 = 0$$, which is
$$(x + 1)(x - 3) = 0$$. Otherwise, try brackets like $$(px + q)(rx + t)$$ where $$pr = a$$ and
$$qt = c$$, and expand each guess to see whether the middle term comes out right.

:::example[A leading coefficient other than 1]

Solve $$2x^2 + 7x + 3 = 0$$.

The $$2x^2$$ has to come from $$2x$$ times $$x$$, so try $$(2x + q)(x + t)$$ with $$qt = 3$$. The
guess $$(2x + 3)(x + 1)$$ expands to $$2x^2 + 5x + 3$$, which is wrong. The guess
$$(2x + 1)(x + 3)$$ expands to $$2x^2 + 7x + 3$$, which is right. So by :ref{#solve-by-factors},
$$x = -\frac{1}{2}$$ or $$x = -3$$.

:::

## Three special shapes

Three shapes are worth spotting on sight, because they factor in one step.

With no $$x$$ term, $$x^2 - k^2$$ is a **difference of two squares**, and it factors as
$$(x - k)(x + k)$$ (:ref{#numbers/square-formulas}). So $$x^2 - 49 = 0$$ becomes
$$(x - 7)(x + 7) = 0$$, giving $$x = 7$$ or $$x = -7$$. A sum of two squares like $$x^2 + 49$$ can't
be factored like this, and indeed $$x^2 + 49 = 0$$ has no solution, since $$x^2 + 49$$ is always at
least $$49$$.

With no constant term, $$x$$ itself is a common factor. So $$x^2 - 5x = 0$$ becomes
$$x(x - 5) = 0$$, giving $$x = 0$$ or $$x = 5$$.

A **perfect square** like $$x^2 + 6x + 9$$ is $$(x + 3)^2$$, since $$3 + 3 = 6$$ and
$$3 \cdot 3 = 9$$. Then $$x^2 + 6x + 9 = 0$$ has the single solution $$x = -3$$, as in
:ref{#shifted-square}.

The common factor $$x$$ needs care. It is tempting to solve $$x^2 = 5x$$ by dividing both sides by
$$x$$, which gives $$x = 5$$ and nothing else. That loses the solution $$x = 0$$. Dividing by a
number is a safe step only when the number is not $$0$$ (:ref{#linear-equations/safe-steps}), and
whether $$x$$ is $$0$$ is exactly what you don't know yet. Moving everything to one side and
factoring keeps both solutions.

## When to factor

Factoring suits quadratics whose coefficients are small whole numbers, where the right pair shows up
after a few tries. If a few factor pairs don't work, switch to another method. Some quadratics have
no factors with whole numbers at all. For $$x^2 + x - 1$$, the only whole-number pairs with product
$$-1$$ are $$1, -1$$, and they add up to $$0$$, not $$1$$. Yet $$x^2 + x - 1 = 0$$ does have two
solutions, which are not fractions. [Completing the square](./completing-the-square.mdx) and
[the quadratic formula](./quadratic-formula.mdx) find solutions like these, and they work every
time.

Whatever the method, an answer can always be checked by putting it back into the original equation.

## Exercises

:::::accordion[Exercises on solving by factoring, with solutions]

::::exercise{#ex-factoring-sum-product}

Factor each quadratic by finding two numbers with the right sum and product, and solve the equation
it gives when set equal to $$0$$.

1. $$x^2 + 2x - 15$$
2. $$x^2 - 11x + 24$$
3. $$x^2 + 10x + 21$$

:::solution

Use :ref{#factoring-method}: look for $$m$$ and $$n$$ with $$m + n = b$$ and $$mn = c$$.

1. The product $$-15$$ is negative, so the numbers have opposite signs, and they add to $$2$$. The
   pair $$5, -3$$ works. So $$x^2 + 2x - 15 = (x + 5)(x - 3)$$, and the solutions are $$x = -5$$ and
   $$x = 3$$.
2. The product $$24$$ is positive and the sum $$-11$$ is negative, so both numbers are negative. The
   pair $$-3, -8$$ works. So $$(x - 3)(x - 8) = 0$$, and $$x = 3$$ or $$x = 8$$.
3. Both numbers are positive, with product $$21$$ and sum $$10$$: the pair $$3, 7$$. So
   $$(x + 3)(x + 7) = 0$$, and $$x = -3$$ or $$x = -7$$.

:::

::::exercise{#ex-factoring-difference}

Solve each equation, or explain why it has no solution.

1. $$x^2 - 64 = 0$$
2. $$9x^2 - 25 = 0$$
3. $$4x^2 + 1 = 0$$

:::solution

1. This is a difference of two squares (:ref{#numbers/square-formulas}): $$(x - 8)(x + 8) = 0$$, so
   $$x = 8$$ or $$x = -8$$ (:ref{#solve-by-factors}).
2. Here $$9x^2 = (3x)^2$$ and $$25 = 5^2$$, so $$9x^2 - 25 = (3x - 5)(3x + 5)$$. The solutions are
   $$x = \frac{5}{3}$$ and $$x = -\frac{5}{3}$$.
3. This is a sum, not a difference. Since $$x^2 \ge 0$$ (:ref{#real-numbers/squares-positive}),
   $$4x^2 + 1 \ge 1$$ for every $$x$$, so it is never $$0$$ and there is no solution.

:::

::::exercise{#ex-factoring-cancel}

To solve $$x(x - 2) = 3(x - 2)$$, someone divides both sides by $$x - 2$$ and gets $$x = 3$$. Which
solution have they lost? Solve the equation by factoring instead.

:::solution

Dividing by $$x - 2$$ is a safe step only when $$x - 2$$ is not $$0$$
(:ref{#linear-equations/safe-steps}). Whether it is $$0$$ is part of what is unknown, so the step
loses the case $$x - 2 = 0$$, that is, $$x = 2$$. Indeed $$2 \cdot 0 = 3 \cdot 0$$, so $$x = 2$$ is
a solution.

Instead, subtract $$3(x - 2)$$ from both sides and take out the common factor $$x - 2$$:

```math
x(x - 2) - 3(x - 2) = (x - 2)(x - 3) = 0
```

By :ref{#solve-by-factors}, $$x = 2$$ or $$x = 3$$.

:::

::::

::::exercise{#ex-factoring-leading}

Solve $$2x^2 - 5x - 3 = 0$$ and $$6x^2 + x - 2 = 0$$ by factoring.

:::solution

**First equation.** The $$2x^2$$ must come from $$2x \cdot x$$, so try $$(2x + q)(x + t)$$ with
$$qt = -3$$. The guess $$(2x + 1)(x - 3)$$ expands to $$2x^2 - 6x + x - 3 = 2x^2 - 5x - 3$$, which
is right. So $$x = -\frac{1}{2}$$ or $$x = 3$$ (:ref{#solve-by-factors}).

**Second equation.** The $$6x^2$$ could be $$6x \cdot x$$ or $$3x \cdot 2x$$, and the constant
$$-2$$ is $$2 \cdot (-1)$$ or $$(-2) \cdot 1$$. The guess $$(3x + 2)(2x - 1)$$ expands to
$$6x^2 - 3x + 4x - 2 = 6x^2 + x - 2$$, which is right. So $$x = -\frac{2}{3}$$ or
$$x = \frac{1}{2}$$.

**Check** $$x = \frac{1}{2}$$ in the second: $$6 \cdot \frac{1}{4} = \frac{3}{2}$$, and
$$\frac{3}{2} + \frac{1}{2} - 2 = 0$$.

:::

::::

::::exercise{#ex-factoring-build}

Find an equation $$x^2 + bx + c = 0$$ whose solutions are $$4$$ and $$-7$$.

:::solution

By :ref{#solve-by-factors}, $$(x - 4)(x + 7) = 0$$ has exactly the solutions $$4$$ and $$-7$$.
Multiplying out,

```math
(x - 4)(x + 7) = x^2 + 7x - 4x - 28 = x^2 + 3x - 28
```

so $$x^2 + 3x - 28 = 0$$ works. This matches :ref{#factoring-method}: the numbers $$-4$$ and $$7$$
have sum $$b = 3$$ and product $$c = -28$$.

:::

::::

::::exercise{#ex-factoring-perfect}

Show that $$x^2 - 18x + 81 = 0$$ has exactly one solution. Then find the number $$c$$ that makes
$$x^2 + 12x + c$$ a perfect square.

:::solution

The numbers $$-9$$ and $$-9$$ have sum $$-18$$ and product $$81$$, so $$x^2 - 18x + 81 = (x - 9)^2$$
(:ref{#factoring-method}). By :ref{#solve-by-factors}, both factors give $$x = 9$$, so there is
exactly one solution.

For $$x^2 + 12x + c$$ to be $$(x + m)^2 = x^2 + 2mx + m^2$$, you need $$2m = 12$$, so $$m = 6$$, and
then $$c = m^2 = 36$$. Indeed $$(x + 6)^2 = x^2 + 12x + 36$$.

:::

::::

::::exercise{#ex-factoring-no-whole}

Show that $$x^2 + 3x + 1$$ can't be written as $$(x + m)(x + n)$$ with whole numbers $$m$$ and
$$n$$.

:::solution

Suppose it could. Expanding, $$(x + m)(x + n) = x^2 + (m + n)x + mn$$, so you would need $$mn = 1$$
and $$m + n = 3$$.

The only whole numbers with product $$1$$ are $$1, 1$$ and $$-1, -1$$, whose sums are $$2$$ and
$$-2$$. Neither is $$3$$, so no whole numbers work. The equation $$x^2 + 3x + 1 = 0$$ still has two
solutions, but they are not whole numbers. [Completing the square](./completing-the-square.mdx) and
the [quadratic formula](./quadratic-formula.mdx) find them.

:::
