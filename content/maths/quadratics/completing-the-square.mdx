---
title: Completing the square
description: Turning any quadratic into a square plus a number, so it can be solved by square roots.
---

Some quadratics come ready to solve. The equation $$(x + 3)^2 = 10$$ is a square equal to a number,
and taking square roots finishes it in one line. Now write the same equation multiplied out, as
$$x^2 + 6x = 1$$. The $$x$$ appears in two places, and factoring doesn't help either, because the
brackets don't come out with whole numbers or neat fractions.

**Completing the square** turns the second form back into the first. It rewrites the equation so
that $$x$$ appears only once, inside a square, and it works for every quadratic. There's a picture
behind it, a square with one corner missing. In this guide we'll fill in that corner, and the
[next guide](./quadratic-formula.mdx) does the same steps once with letters to get the quadratic
formula.

## The missing corner

Think of $$x^2 + 6x$$ as an area. The $$x^2$$ is a square with sides of length $$x$$. The $$6x$$ is
a rectangle $$6$$ by $$x$$. Cut that rectangle in half lengthwise, into two strips $$3$$ by $$x$$,
and lay one along the right side of the square and the other along the bottom. Together they make an
L shape that is almost a bigger square, with sides $$x + 3$$. Only the corner is missing, a small
square $$3$$ by $$3$$. So the area $$x^2 + 6x$$ is the big square $$(x + 3)^2$$ take away the corner
$$9$$.

The same works for any number in front of $$x$$: the strips are half of it wide, and the missing
corner is half of it, squared.

<CompletingSquare />

The area picture needs lengths, so it only shows positive $$x$$ and $$b$$. The algebra behind it
works for every real number.

:::proposition[Completing the square]{#complete-square}

For all real numbers $$x$$ and $$b$$,

```math
x^2 + bx = \left(x + \frac{b}{2}\right)^2 - \frac{b^2}{4}
```

So for any real $$c$$, the equation $$x^2 + bx + c = 0$$ has exactly the same solutions as

```math
\left(x + \frac{b}{2}\right)^2 = \frac{b^2}{4} - c
```

:::

:::proof{source="https://en.wikipedia.org/wiki/Completing_the_square#Formula"}

Expand the square with :ref{#numbers/square-formulas}:

```math
\left(x + \frac{b}{2}\right)^2 = x^2 + 2 \cdot \frac{b}{2} \cdot x + \frac{b^2}{4} = x^2 + bx + \frac{b^2}{4}
```

Taking $$\frac{b^2}{4}$$ from both sides gives the first statement.

For the second, replace $$x^2 + bx$$ in $$x^2 + bx + c = 0$$ by the right-hand side of the first
statement. That changes nothing, since the two are equal for every $$x$$, and gives

```math
\left(x + \frac{b}{2}\right)^2 - \frac{b^2}{4} + c = 0
```

Adding $$\frac{b^2}{4} - c$$ to both sides is a safe step (:ref{#linear-equations/safe-steps}), so
the solutions stay the same.

:::

## Solving by completing the square

Once the equation reads (a square) $$=$$ (a number), the first guide already says what to do
(:ref{#shifted-square}). If the number is positive there are two solutions, one for each square
root. If it is $$0$$ there is one. If it is negative there are none, since no square is negative. So
every quadratic with $$x^2$$ on its own comes down to the same three steps:

1. Move the number term to the right-hand side, leaving $$x^2 + bx$$ on the left.
2. Add $$\left(\frac{b}{2}\right)^2$$ to **both** sides, so the left becomes
   $$\left(x + \frac{b}{2}\right)^2$$.
3. Take square roots, remembering both signs, and solve for $$x$$.

:::example[A whole-number answer]

Solve $$x^2 + 6x - 16 = 0$$.

Move the $$16$$ across: $$x^2 + 6x = 16$$. Half of $$6$$ is $$3$$, and $$3^2 = 9$$, so add $$9$$ to
both sides:

```math
x^2 + 6x + 9 = 25, \qquad\text{that is}\qquad (x + 3)^2 = 25
```

So $$x + 3 = 5$$ or $$x + 3 = -5$$, which gives $$x = 2$$ or $$x = -8$$.

Check: $$2^2 + 6 \cdot 2 - 16 = 4 + 12 - 16 = 0$$, and
$$(-8)^2 + 6 \cdot (-8) - 16 = 64 - 48 - 16 = 0$$.

:::

The numbers don't have to work out so neatly. When the right-hand side isn't a perfect square, the
answer keeps its square root.

:::example[An answer with a square root]

Solve $$x^2 - 4x - 1 = 0$$.

Move the $$1$$ across: $$x^2 - 4x = 1$$. Half of $$-4$$ is $$-2$$, and $$(-2)^2 = 4$$, so

```math
x^2 - 4x + 4 = 5, \qquad\text{that is}\qquad (x - 2)^2 = 5
```

So $$x - 2 = \pm\sqrt{5}$$, and $$x = 2 + \sqrt{5}$$ or $$x = 2 - \sqrt{5}$$, about $$4.236$$ and
$$-0.236$$.

Check the first: $$(2 + \sqrt{5})^2 = 4 + 4\sqrt{5} + 5 = 9 + 4\sqrt{5}$$, and taking
$$4(2 + \sqrt{5}) + 1 = 9 + 4\sqrt{5}$$ from it leaves $$0$$.

:::

Completing the square also shows at once when there is no solution: the square ends up equal to a
negative number.

:::example[No solution]

Solve $$x^2 + 4x + 7 = 0$$.

Move the $$7$$ across and add $$\left(\frac{4}{2}\right)^2 = 4$$ to both sides:

```math
x^2 + 4x + 4 = -3, \qquad\text{that is}\qquad (x + 2)^2 = -3
```

A square is never negative (:ref{#real-numbers/squares-positive}), so no real number $$x$$ works.
The equation has no solution.

:::

## When x² has a number in front

The picture needs $$x^2$$ on its own, a single square. If the equation starts with $$2x^2$$ or
$$-3x^2$$, divide the whole equation by that number first. Dividing both sides by the same non-zero
number doesn't change the solutions (:ref{#linear-equations/safe-steps}), and $$a$$ is never $$0$$
in a quadratic (:ref{#quadratic}). Fractions usually appear, but the steps are the same.

:::example[Dividing through first]

Solve $$2x^2 + 5x - 3 = 0$$.

Divide by $$2$$: $$x^2 + \frac{5}{2}x - \frac{3}{2} = 0$$, so $$x^2 + \frac{5}{2}x = \frac{3}{2}$$.
Half of $$\frac{5}{2}$$ is $$\frac{5}{4}$$, and its square is $$\frac{25}{16}$$. Adding it to both
sides,

```math
\left(x + \frac{5}{4}\right)^2 = \frac{3}{2} + \frac{25}{16} = \frac{24}{16} + \frac{25}{16} = \frac{49}{16}
```

So $$x + \frac{5}{4} = \pm\frac{7}{4}$$, which gives $$x = \frac{2}{4} = \frac{1}{2}$$ or
$$x = -\frac{12}{4} = -3$$.

Check: $$2 \cdot \frac{1}{4} + \frac{5}{2} - 3 = \frac{1}{2} + \frac{5}{2} - 3 = 0$$, and
$$2 \cdot 9 - 15 - 3 = 0$$.

:::

Completing the square does more than solve equations. Written as $$(x + \frac{b}{2})^2$$ plus a
number, a quadratic shows its smallest value and where it happens, which is how the
[Parabolas](./parabolas.mdx) guide finds the lowest point of the graph.

## Exercises

:::::accordion[Exercises on completing the square, with solutions]

::::exercise{#ex-completing-corner}

What number must be added to each expression to make it a perfect square? Write the square.

1. $$x^2 + 14x$$
2. $$x^2 - 3x$$
3. $$x^2 + \frac{1}{2}x$$

:::solution

The missing corner is half the number in front of $$x$$, squared (:ref{#complete-square}).

1. Half of $$14$$ is $$7$$, so add $$49$$: $$x^2 + 14x + 49 = (x + 7)^2$$.
2. Half of $$-3$$ is $$-\frac{3}{2}$$, so add $$\frac{9}{4}$$:
   $$x^2 - 3x + \frac{9}{4} = \left(x - \frac{3}{2}\right)^2$$.
3. Half of $$\frac{1}{2}$$ is $$\frac{1}{4}$$, so add $$\frac{1}{16}$$:
   $$x^2 + \frac{1}{2}x + \frac{1}{16} = \left(x + \frac{1}{4}\right)^2$$.

:::

::::

::::exercise{#ex-completing-forgot}

Someone solving $$x^2 + 8x = 9$$ writes $$(x + 4)^2 = 9$$, and gets $$x = -1$$ or $$x = -7$$. Check
one of these answers, find the mistake, and solve the equation correctly.

:::solution

**Check** $$x = -1$$: $$(-1)^2 + 8 \cdot (-1) = 1 - 8 = -7$$, not $$9$$. So the answer is wrong.

The square $$(x + 4)^2$$ is $$x^2 + 8x + 16$$, so turning the left side into it means adding $$16$$.
They added $$16$$ to the left side only. Adding it to **both** sides keeps the solutions the same
(:ref{#linear-equations/safe-steps}):

```math
x^2 + 8x + 16 = 25, \qquad\text{that is}\qquad (x + 4)^2 = 25
```

So $$x + 4 = \pm 5$$, and $$x = 1$$ or $$x = -9$$ (:ref{#shifted-square}). Check: $$1 + 8 = 9$$, and
$$81 - 72 = 9$$.

:::

::::

::::exercise{#ex-completing-solve}

Solve by completing the square.

1. $$x^2 + 10x + 16 = 0$$
2. $$x^2 - 2x - 4 = 0$$
3. $$x^2 - 6x + 11 = 0$$

:::solution

1. Move the $$16$$ across: $$x^2 + 10x = -16$$. Add $$\left(\frac{10}{2}\right)^2 = 25$$ to both
   sides: $$(x + 5)^2 = 9$$. So $$x + 5 = \pm 3$$, and $$x = -2$$ or $$x = -8$$.
2. $$x^2 - 2x = 4$$. Add $$1$$ to both sides: $$(x - 1)^2 = 5$$. So $$x - 1 = \pm\sqrt{5}$$, and
   $$x = 1 + \sqrt{5}$$ or $$x = 1 - \sqrt{5}$$.
3. $$x^2 - 6x = -11$$. Add $$9$$ to both sides: $$(x - 3)^2 = -2$$. A square is never negative
   (:ref{#real-numbers/squares-positive}), so there is no solution.

Each part completes the square with :ref{#complete-square}, then finishes with
:ref{#shifted-square}.

:::

::::

::::exercise{#ex-completing-negative}

Solve $$-x^2 - 2x + 5 = 0$$ by completing the square. Why is it worth dividing by $$-1$$ first?

:::solution

The picture behind completing the square needs $$x^2$$ on its own, and :ref{#complete-square} is
about $$x^2 + bx$$. Here the $$x^2$$ has $$-1$$ in front. Dividing both sides by $$-1$$ is a safe
step, since $$-1 \neq 0$$ (:ref{#linear-equations/safe-steps}), and it gives

```math
x^2 + 2x - 5 = 0
```

Now $$x^2 + 2x = 5$$, and adding $$1$$ to both sides gives $$(x + 1)^2 = 6$$. So
$$x + 1 = \pm\sqrt{6}$$, and $$x = -1 + \sqrt{6}$$ or $$x = -1 - \sqrt{6}$$.

Without dividing first, you would have to complete the square on $$-(x^2 + 2x)$$ and keep track of
the minus sign through every step, which is where slips happen.

:::

::::

::::exercise{#ex-completing-fractions}

Solve $$2x^2 + 3x - 2 = 0$$ by completing the square.

:::solution

Divide by $$2$$: $$x^2 + \frac{3}{2}x - 1 = 0$$, so $$x^2 + \frac{3}{2}x = 1$$. Half of
$$\frac{3}{2}$$ is $$\frac{3}{4}$$, and its square is $$\frac{9}{16}$$. Adding it to both sides,

```math
\left(x + \frac{3}{4}\right)^2 = 1 + \frac{9}{16} = \frac{25}{16}
```

So $$x + \frac{3}{4} = \pm\frac{5}{4}$$, which gives $$x = \frac{2}{4} = \frac{1}{2}$$ or
$$x = -\frac{8}{4} = -2$$.

Check: $$2 \cdot \frac{1}{4} + \frac{3}{2} - 2 = 0$$, and $$2 \cdot 4 - 6 - 2 = 0$$.

:::

::::

::::exercise{#ex-completing-no-solution}

Show that if $$c > \frac{b^2}{4}$$, the equation $$x^2 + bx + c = 0$$ has no solution.

:::solution

By :ref{#complete-square}, the equation has exactly the same solutions as

```math
\left(x + \frac{b}{2}\right)^2 = \frac{b^2}{4} - c
```

If $$c > \frac{b^2}{4}$$, the right side is negative. The left side is a square, which is never
negative (:ref{#real-numbers/squares-positive}). So no $$x$$ makes the two sides equal, and the
equation has no solution.

For example, $$x^2 + 2x + 5 = 0$$ has $$c = 5 > \frac{4}{4} = 1$$, so it has no solution.

:::
