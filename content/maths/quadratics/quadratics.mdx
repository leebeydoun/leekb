A rectangle is $$3$$ metres longer than it is wide, and its area is $$40$$ square metres. How wide
is it? Calling the width $$x$$, the length is $$x + 3$$, so $$x(x + 3) = 40$$. Multiplying out gives
$$x^2 + 3x = 40$$, and now the unknown is multiplied by itself. None of the methods for linear
equations can deal with that $$x^2$$. This page says exactly which equations count as quadratic,
what to expect from their solutions, and solves the easiest kind, a square equal to a number. Every
other method in the guide works by turning a quadratic into that easy kind.

## What a quadratic equation is

A linear equation only ever multiplies the unknown by numbers. A quadratic equation also allows the
unknown times itself, $$x^2$$, but nothing higher, like $$x^3$$. Equations like this turn up
whenever two unknown lengths are multiplied, as in an area, and in many other places where one
quantity grows with the square of another. However the equation first looks, the terms can be
gathered on one side, leaving $$0$$ on the other. Then it says that some number of $$x^2$$'s, plus
some number of $$x$$'s, plus a constant, comes to nothing.

:::definition[Quadratic equation]{#quadratic}

A **quadratic equation** in the unknown $$x$$ is an equation that can be written as

```math
ax^2 + bx + c = 0
```

where $$a$$, $$b$$ and $$c$$ are real numbers with $$a \neq 0$$. The numbers $$a$$, $$b$$ and $$c$$
are its **coefficients**, and this way of writing it is its **standard form**. A solution is also
called a **root** of the equation.

:::

The condition $$a \neq 0$$ is what makes the equation quadratic. If $$a = 0$$ the $$x^2$$ term
disappears, leaving $$bx + c = 0$$, which is a linear equation and is solved as one
(:ref{#linear-equations/one-unknown}). The other two coefficients may be $$0$$: $$x^2 - 9 = 0$$ has
$$b = 0$$, and $$x^2 - 5x = 0$$ has $$c = 0$$, and both are quadratic.

To put an equation in standard form, use the safe steps (:ref{#linear-equations/safe-steps}): expand
any brackets, then add or subtract terms on both sides until one side is $$0$$. Safe steps give an
equivalent equation, one with exactly the same solutions, so nothing is lost.

:::example[Putting equations in standard form]

The rectangle equation $$x(x + 3) = 40$$ expands to $$x^2 + 3x = 40$$. Subtracting $$40$$ from both
sides gives

```math
x^2 + 3x - 40 = 0
```

so $$a = 1$$, $$b = 3$$ and $$c = -40$$.

The equation $$(x + 1)^2 = 2x + 5$$ expands to $$x^2 + 2x + 1 = 2x + 5$$. Subtracting $$2x + 5$$
from both sides gives $$x^2 - 4 = 0$$, so $$a = 1$$, $$b = 0$$ and $$c = -4$$.

The equation $$x^2 + 3x = x^2 + 6$$ looks quadratic, but subtracting $$x^2$$ from both sides leaves
$$3x = 6$$. The squares cancel, so it is linear, with the single solution $$x = 2$$.

:::

## How many solutions to expect

A linear equation with $$a \neq 0$$ has exactly one solution. A quadratic can have more, because a
number and its opposite have the same square. Both $$3$$ and $$-3$$ solve $$x^2 = 9$$. But it can
also have fewer, because a square is never negative: nothing solves $$x^2 = -1$$. And $$x^2 = 0$$
sits on the boundary, with $$0$$ as its only solution. These three equations already show every
possibility. A quadratic equation always has two solutions, one, or none, never more. The
[page on the discriminant](./discriminant.mdx) proves this (:ref{#root-count}) and shows how to tell
in advance which case you are in.

So solving a quadratic means finding all of its solutions, not just one. Stopping at the first
answer found is the most common way to get a quadratic wrong.

## A square equal to a number

The easiest quadratics are a square equal to a number. Take $$(x - 3)^2 = 16$$. Whatever $$x$$ is,
the number $$x - 3$$ squares to $$16$$, so it must be $$4$$ or $$-4$$. That leaves two linear
equations, $$x - 3 = 4$$ and $$x - 3 = -4$$, giving $$x = 7$$ and $$x = -1$$. On the number line,
$$x - 3$$ is how far $$x$$ is from $$3$$, counting left as negative. So the equation says that $$x$$
is $$4$$ away from $$3$$, on one side or the other.

The sign $$\pm$$, read "plus or minus", writes both solutions at once: $$x = 3 \pm 4$$ means
$$x = 3 + 4$$ or $$x = 3 - 4$$.

:::proposition[A square equal to a number]{#shifted-square}

Let $$s$$ and $$k$$ be real numbers. The equation $$(x - s)^2 = k$$

1. has exactly two solutions, $$x = s + \sqrt{k}$$ and $$x = s - \sqrt{k}$$, if $$k > 0$$;
2. has exactly one solution, $$x = s$$, if $$k = 0$$;
3. has no solution if $$k < 0$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Quadratic_equation#Completing_the_square"}

Write $$y = x - s$$. Each $$x$$ gives exactly one $$y$$, and each $$y$$ gives back exactly one
$$x$$, namely $$x = y + s$$. So $$x$$ solves $$(x - s)^2 = k$$ exactly when $$y = x - s$$ solves
$$y^2 = k$$, and the solutions for $$x$$ are the solutions for $$y$$ with $$s$$ added.

The equation $$y^2 = k$$ is solved by :ref{#real-numbers/square-root-count}. If $$k > 0$$, it has
exactly two solutions, a positive one, which is $$\sqrt{k}$$ (:ref{#real-numbers/square-root}), and
its opposite $$-\sqrt{k}$$. Adding $$s$$ gives $$x = s + \sqrt{k}$$ and $$x = s - \sqrt{k}$$. If
$$k = 0$$, the only solution is $$y = 0$$, so $$x = s$$. If $$k < 0$$, there is no $$y$$, so there
is no $$x$$.

:::

The same works for $$(x + s)^2 = k$$, since $$x + s = x - (-s)$$. The solutions are then
$$x = -s \pm \sqrt{k}$$.

:::example[Squares equal to numbers]

$$(x + 2)^2 = 5$$. Here $$x + 2 = \pm\sqrt{5}$$, so $$x = -2 + \sqrt{5}$$ or $$x = -2 - \sqrt{5}$$.

$$2(x - 1)^2 = 18$$. Dividing both sides by $$2$$ gives $$(x - 1)^2 = 9$$, so $$x - 1 = \pm 3$$, and
$$x = 4$$ or $$x = -2$$. Check: $$2 \cdot 3^2 = 18$$ and $$2 \cdot (-3)^2 = 18$$.

$$(x - 5)^2 + 3 = 0$$. Subtracting $$3$$ gives $$(x - 5)^2 = -3$$. A square can't be negative, so
there is no solution.

$$(4x - 1)^2 = 0$$. The only number that squares to $$0$$ is $$0$$, so $$4x - 1 = 0$$ and
$$x = \frac{1}{4}$$, the only solution.

:::

This case matters because every quadratic can be brought to it. [Factoring](./factoring.mdx) is a
shortcut that works when the quadratic splits neatly.
[Completing the square](./completing-the-square.mdx) rewrites any quadratic as a square equal to a
number, and [the quadratic formula](./quadratic-formula.mdx) is that rewriting done once, with
letters, so it never has to be done again.

## Exercises

:::::accordion[Exercises on quadratic equations, with solutions]

::::exercise{#ex-quadratics-standard-form}

Put each equation in standard form and read off $$a$$, $$b$$ and $$c$$. Say which ones are not
quadratic, and solve those.

1. $$(2x - 1)(x + 3) = 5$$
2. $$x(x - 4) = 3x^2 - 2$$
3. $$(x + 2)^2 = (x - 2)^2$$

:::solution

Expand, then move every term to one side with safe steps (:ref{#linear-equations/safe-steps}).

1. $$(2x - 1)(x + 3) = 2x^2 + 5x - 3$$, so the equation is $$2x^2 + 5x - 3 = 5$$. Subtracting $$5$$
   gives $$2x^2 + 5x - 8 = 0$$, with $$a = 2$$, $$b = 5$$ and $$c = -8$$.
2. The left side is $$x^2 - 4x$$. Subtracting it from both sides gives $$0 = 2x^2 + 4x - 2$$, that
   is $$2x^2 + 4x - 2 = 0$$, with $$a = 2$$, $$b = 4$$ and $$c = -2$$. Subtracting the right side
   instead gives $$-2x^2 - 4x + 2 = 0$$, which is the same equation multiplied by $$-1$$, and either
   form is fine.
3. Expanding, $$x^2 + 4x + 4 = x^2 - 4x + 4$$. Subtracting the right side leaves $$8x = 0$$. The
   squares cancel, so this is not quadratic. It is linear, with the single solution $$x = 0$$.

:::

::::

::::exercise{#ex-quadratics-which-m}

For which numbers $$m$$ is $$(m - 1)x^2 + 3x - 2 = 0$$ a quadratic equation in $$x$$? For the other
values of $$m$$, solve the equation.

:::solution

The number in front of $$x^2$$ is $$m - 1$$, and the equation is quadratic exactly when it is not
$$0$$ (:ref{#quadratic}). So it is quadratic for every $$m$$ except $$m = 1$$.

When $$m = 1$$ the $$x^2$$ term disappears, leaving $$3x - 2 = 0$$. This is linear, with the single
solution $$x = \frac{2}{3}$$ (:ref{#linear-equations/one-unknown}).

:::

::::

::::exercise{#ex-quadratics-squares}

Solve each equation, or explain why it has no solution.

1. $$(x + 1)^2 = 49$$
2. $$3(x - 2)^2 = 12$$
3. $$(2x + 3)^2 = 0$$
4. $$(x - 1)^2 + 8 = 4$$

:::solution

Each one is brought to a square equal to a number, and then :ref{#shifted-square} applies.

1. $$x + 1 = 7$$ or $$x + 1 = -7$$, so $$x = 6$$ or $$x = -8$$.
2. Dividing by $$3$$ gives $$(x - 2)^2 = 4$$, so $$x - 2 = \pm 2$$, and $$x = 4$$ or $$x = 0$$.
3. Only $$0$$ squares to $$0$$, so $$2x + 3 = 0$$ and $$x = -\frac{3}{2}$$ is the only solution.
4. Subtracting $$8$$ gives $$(x - 1)^2 = -4$$. A square is never negative
   (:ref{#real-numbers/squares-positive}), so there is no solution.

:::

::::

::::exercise{#ex-quadratics-distance}

Which numbers are exactly $$2.5$$ away from $$-1$$ on the number line? Write the question as a
square equal to a number, and solve it.

:::solution

The distance from $$x$$ to $$-1$$, counting left as negative, is $$x - (-1) = x + 1$$. Being $$2.5$$
away on either side means $$x + 1 = 2.5$$ or $$x + 1 = -2.5$$, and both are captured by squaring:

```math
(x + 1)^2 = 6.25
```

By :ref{#shifted-square}, $$x + 1 = \pm 2.5$$, so $$x = 1.5$$ or $$x = -3.5$$. Indeed $$1.5$$ is
$$2.5$$ to the right of $$-1$$, and $$-3.5$$ is $$2.5$$ to the left.

:::

::::

::::exercise{#ex-quadratics-path}

A square lawn has a path $$1$$ m wide all the way round it. The lawn and the path together cover
$$49$$ m². How long is a side of the lawn? The equation has two solutions: why is only one of them
an answer?

:::solution

Call the side of the lawn $$x$$ metres. The path adds $$1$$ m on each side, so the lawn and path
make a square of side $$x + 2$$, and

```math
(x + 2)^2 = 49
```

By :ref{#shifted-square}, $$x + 2 = 7$$ or $$x + 2 = -7$$, so $$x = 5$$ or $$x = -9$$. A length
can't be negative, so the lawn is $$5$$ m wide. Check: $$5 + 2 = 7$$ and $$7^2 = 49$$.

The equation knows nothing about lengths. It only says that $$x + 2$$ squares to $$49$$, and $$-7$$
does that as well as $$7$$. The second solution is a real solution of the equation, but it doesn't
fit the question.

:::

::::

::::exercise{#ex-quadratics-find-s-k}

Find numbers $$s$$ and $$k$$ so that $$(x - s)^2 = k$$ has the solutions $$2$$ and $$10$$. Are they
the only possible choice?

:::solution

When $$k > 0$$, the solutions are $$s + \sqrt{k}$$ and $$s - \sqrt{k}$$ (:ref{#shifted-square}).
They lie the same distance $$\sqrt{k}$$ either side of $$s$$, so $$s$$ is halfway between them:
$$s = \frac{2 + 10}{2} = 6$$. Then $$\sqrt{k} = 10 - 6 = 4$$, so $$k = 16$$.

Check: $$(x - 6)^2 = 16$$ gives $$x - 6 = \pm 4$$, so $$x = 10$$ or $$x = 2$$.

The choice is the only one. Any $$s$$ and $$k$$ that work must have $$k > 0$$, since there are two
solutions, and then the argument above forces $$s = 6$$ and $$k = 16$$.

:::

::::

::::exercise{#ex-quadratics-average}

Let $$k > 0$$. Show that the average of the two solutions of $$(x - s)^2 = k$$ is $$s$$.

:::solution

By :ref{#shifted-square}, the two solutions are $$s + \sqrt{k}$$ and $$s - \sqrt{k}$$. Their sum is

```math
(s + \sqrt{k}) + (s - \sqrt{k}) = 2s
```

since the square roots cancel. So their average is $$\frac{2s}{2} = s$$. On the number line, the two
solutions sit the same distance $$\sqrt{k}$$ on either side of $$s$$.

:::
