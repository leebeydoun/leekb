Throw a ball straight up and watch it. It climbs, slows down, stops for an instant and falls back.
Ask when it is $$5$$ metres up and there are two answers, one on the way up and one on the way down.
Ask when it is at its highest point and there is one answer, and ask about a height it never reaches
and there are none.

The formula for the ball's height has the time **squared** in it, so these questions lead to
quadratic equations, like $$x^2 - 5x + 6 = 0$$. A linear equation like $$3x - 2 = 0$$ has one
solution, and one division finds it. In this chapter we'll learn to solve every quadratic equation,
and to tell in advance whether it has two solutions, one or none.

We'll lean on three earlier chapters:

- [Numbers](../numbers/introduction.mdx): the formulas for squares, and the rule that a product is
  zero exactly when a factor is
- [Linear equations](../linear-equations/introduction.mdx): the safe steps that rearrange an
  equation without changing its solutions
- [Real numbers](../real-numbers/introduction.mdx): square roots, and the fact that no square is
  negative

One fact is taken from the picture: the graph of a quadratic is a U-shaped curve with a line of
symmetry. The
[Parabolas, ellipses and hyperbolas](../parabolas-ellipses-and-hyperbolas/introduction.mdx) chapter
proves it.

:::accordion[Summary of definitions and rules]

**Definitions**

| Term                | Meaning                                                                      |
| ------------------- | ---------------------------------------------------------------------------- |
| :ref{#quadratic}    | $$ax^2 + bx + c = 0$$ with $$a \neq 0$$; its solutions are also called roots |
| :ref{#discriminant} | $$\Delta = b^2 - 4ac$$                                                       |

**Quadratic equations**

| Rule                  | Statement                                                                                         |
| --------------------- | ------------------------------------------------------------------------------------------------- |
| :ref{#shifted-square} | $$(x - s)^2 = k$$: $$x = s \pm \sqrt{k}$$ if $$k > 0$$, $$x = s$$ if $$k = 0$$, none if $$k < 0$$ |

**Solving by factoring**

| Rule                    | Statement                                                                          |
| ----------------------- | ---------------------------------------------------------------------------------- |
| :ref{#solve-by-factors} | $$(px + q)(rx + t) = 0$$ exactly when $$x = -\frac{q}{p}$$ or $$x = -\frac{t}{r}$$ |
| :ref{#factoring-method} | If $$m + n = b$$ and $$mn = c$$, then $$x^2 + bx + c = (x + m)(x + n)$$            |

**Completing the square**

| Rule                   | Statement                                                     |
| ---------------------- | ------------------------------------------------------------- |
| :ref{#complete-square} | $$x^2 + bx = \left(x + \frac{b}{2}\right)^2 - \frac{b^2}{4}$$ |

**The quadratic formula**

| Rule                     | Statement                                                                                      |
| ------------------------ | ---------------------------------------------------------------------------------------------- |
| :ref{#quadratic-formula} | If $$b^2 - 4ac \ge 0$$: $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$; otherwise no real solution |

**The discriminant**

| Rule              | Statement                                                                                                                        |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| :ref{#root-count} | $$\Delta > 0$$: two solutions; $$\Delta = 0$$: one, $$-\frac{b}{2a}$$; $$\Delta < 0$$: none                                      |
| :ref{#vieta}      | Solutions $$x_1, x_2$$ have $$x_1 + x_2 = -\frac{b}{a}$$, $$x_1 x_2 = \frac{c}{a}$$, and $$ax^2 + bx + c = a(x - x_1)(x - x_2)$$ |

**Parabolas**

| Rule            | Statement                                                                                                           |
| --------------- | ------------------------------------------------------------------------------------------------------------------- |
| :ref{#parabola} | $$y = ax^2 + bx + c$$ opens up if $$a > 0$$, down if $$a < 0$$; solutions are where it crosses the $$x$$-axis       |
| :ref{#vertex}   | $$ax^2 + bx + c = a(x - s)^2 + k$$ with $$s = -\frac{b}{2a}$$, $$k = c - \frac{b^2}{4a}$$; the vertex is $$(s, k)$$ |

**Equations that become quadratic**

| Rule                          | Statement                                                                                           |
| ----------------------------- | --------------------------------------------------------------------------------------------------- |
| :ref{#substitution-quadratic} | $$ax^4 + bx^2 + c = 0$$: solve $$au^2 + bu + c = 0$$, then $$x = \pm\sqrt{u}$$ for each $$u \ge 0$$ |

:::
