The [Linear equations](../linear-equations/lines.mdx) guide drew every linear equation as a straight
line. A quadratic draws a curve instead, a **parabola**, and that curve explains the whole guide at
a glance. Solving $$ax^2 + bx + c = 0$$ means finding where the curve $$y = ax^2 + bx + c$$ meets
the $$x$$-axis. Completing the square finds its lowest or highest point, and the discriminant counts
how many times it crosses.

## The graph of a quadratic

Start with the simplest quadratic, $$y = x^2$$, and work out some points:

| $$x$$ | $$-3$$ | $$-2$$ | $$-1$$ | $$0$$ | $$1$$ | $$2$$ | $$3$$ |
| ----- | ------ | ------ | ------ | ----- | ----- | ----- | ----- |
| $$y$$ | $$9$$  | $$4$$  | $$1$$  | $$0$$ | $$1$$ | $$4$$ | $$9$$ |

Three things stand out. A number and its opposite have the same square, so the two halves of the
table match, and the curve is the same on both sides of the $$y$$-axis. No square is negative, so
the curve never dips below the $$x$$-axis, and its lowest point is $$(0, 0)$$. And the further $$x$$
is from $$0$$, the faster the square grows: the steps $$1$$, $$3$$, $$5$$ get bigger each time, so
the sides of the curve get steeper and steeper. Joining the points gives a U shape.

Every other quadratic has the same shape, moved, stretched, or turned over. Multiplying by $$a$$
stretches the U when $$a$$ is big, and squashes it when $$a$$ is small. A negative $$a$$ also flips
it upside down, since it makes every value negative instead of positive. Far from the middle, the
$$ax^2$$ term outgrows $$bx + c$$, so the sign of $$a$$ alone decides whether the arms point up or
down.

:::remark[The graph is a parabola]{#parabola}

Let $$a \neq 0$$. The graph of $$y = ax^2 + bx + c$$ is a U-shaped curve called a **parabola**.

1. It is the same on both sides of a vertical line, its **axis of symmetry**.
2. If $$a > 0$$, it opens upwards and has a lowest point. If $$a < 0$$, it opens downwards and has a
   highest point. This turning point, where the curve meets its axis, is the **vertex**.

::see-also{src="https://en.wikipedia.org/wiki/Quadratic_function#Graph_of_the_univariate_function"}

:::

## Solutions are crossings

A point lies on the $$x$$-axis exactly when its $$y$$ coordinate is $$0$$. So the curve
$$y = ax^2 + bx + c$$ meets the $$x$$-axis at the values of $$x$$ that make $$ax^2 + bx + c = 0$$:
the solutions of the quadratic equation. Solving the equation and finding where the curve crosses
the axis are the same question.

For example, $$x^2 - 2x - 3 = (x + 1)(x - 3)$$, so the equation $$x^2 - 2x - 3 = 0$$ has the
solutions $$-1$$ and $$3$$ (:ref{#solve-by-factors}). On the graph of $$y = x^2 - 2x - 3$$, these
are the two points where the curve passes through the axis, at $$(-1, 0)$$ and $$(3, 0)$$.

A picture is a good check on an answer, but a poor way of finding one. It shows roughly where the
crossings are, and how many there are, but not their exact values. The methods on the earlier pages
give the exact values.

## The vertex

Picture $$y = (x - 2)^2 - 2$$. The square $$(x - 2)^2$$ is never negative, and it is $$0$$ only when
$$x = 2$$. So $$y$$ is never below $$-2$$, and reaches $$-2$$ at $$x = 2$$ alone: the lowest point
is $$(2, -2)$$. The curve is $$y = x^2 - 2$$ with every point moved $$2$$ to the right, since the
value that $$y = x^2 - 2$$ takes at $$x$$, this curve takes at $$x + 2$$.

Try it: slide the curve and watch the lowest point follow.

:ref{#complete-square} turns any quadratic into this form: a number times a square, plus a number.
The rule covers $$x^2 + bx$$, with nothing in front of $$x^2$$. So for $$ax^2 + bx + c$$ it takes
three steps:

1. **Take out $$a$$**: write the first two terms as $$a$$ times a bracket that starts with $$x^2$$
2. **Complete the square**: rewrite the bracket as a square minus a number
3. **Multiply back by $$a$$**: multiply each term in the bracket by $$a$$

The proof below takes these steps for any quadratic, and the example after it takes them for one.

:::proposition[The vertex of a parabola]{#vertex}

Let $$a \neq 0$$, and let $$s = -\frac{b}{2a}$$ and $$k = c - \frac{b^2}{4a}$$. Then

```math
ax^2 + bx + c = a(x - s)^2 + k
```

for every $$x$$. So the graph of $$y = ax^2 + bx + c$$ has its vertex at $$(s, k)$$ and is the same
on both sides of the line $$x = s$$:

1. If $$a > 0$$, the smallest value of $$ax^2 + bx + c$$ is $$k$$, reached only at $$x = s$$.
2. If $$a < 0$$, the largest value of $$ax^2 + bx + c$$ is $$k$$, reached only at $$x = s$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Completing_the_square#Relation_to_the_graph"}

**Step 1: take out $$a$$.** Since $$a \neq 0$$, you can write $$bx$$ as $$a \cdot \frac{b}{a}x$$. So

```math
ax^2 + bx + c = a\left(x^2 + \frac{b}{a}x\right) + c
```

**Step 2: complete the square.** The bracket is $$x^2$$ plus a number times $$x$$, with
$$\frac{b}{a}$$ in place of $$b$$. Half of $$\frac{b}{a}$$ is $$\frac{b}{2a}$$. Squaring a fraction
squares its top and its bottom, so the square of $$\frac{b}{2a}$$ is $$\frac{b^2}{4a^2}$$. So by
:ref{#complete-square},

```math
x^2 + \frac{b}{a}x = \left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a^2}
```

**Step 3: multiply back by $$a$$.** Put this into the bracket from step 1, and multiply each of its
two terms by $$a$$:

```math
ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 - a \cdot \frac{b^2}{4a^2} + c
```

The middle term is where the $$a^2$$ goes. It has one $$a$$ on top and two on the bottom, since
$$4a^2 = 4a \cdot a$$. One $$a$$ on top cancels one on the bottom:

```math
a \cdot \frac{b^2}{4a \cdot a} = \frac{b^2}{4a}
```

So $$ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + c - \frac{b^2}{4a}$$. Since
$$x + \frac{b}{2a} = x - s$$, this is $$a(x - s)^2 + k$$.

The square $$(x - s)^2$$ is never negative (:ref{#real-numbers/squares-positive}), and it is $$0$$
only when $$x - s = 0$$ (:ref{#numbers/zero-product}), that is, when $$x = s$$.

**Part 1.** If $$a > 0$$, then $$a(x - s)^2 \ge 0$$, so $$ax^2 + bx + c \ge k$$. Equality needs
$$a(x - s)^2 = 0$$, and since $$a \neq 0$$, that happens only at $$x = s$$.

**Part 2.** If $$a < 0$$, multiplying $$(x - s)^2 \ge 0$$ by $$a$$ turns it round
(:ref{#real-numbers/inequality-rules}), so $$a(x - s)^2 \le 0$$ and $$ax^2 + bx + c \le k$$, with
equality only at $$x = s$$ as before.

For the symmetry, take any number $$t$$. At $$x = s + t$$ and $$x = s - t$$, the square is $$t^2$$
and $$(-t)^2 = t^2$$, which are equal. So the curve has the same height at the two points a distance
$$t$$ either side of the line $$x = s$$.

:::

On the [quadratic formula](./quadratic-formula.mdx) page, the equation $$ax^2 + bx + c = 0$$ is
divided by $$a$$ before the square is completed. That leaves $$\frac{b^2}{4a^2}$$ with no $$a$$ in
front to cancel. Dividing is allowed there, because $$0$$ divided by $$a$$ is still $$0$$, so the
solutions don't change. A curve is different: dividing $$y = ax^2 + bx + c$$ by $$a$$ divides every
height by $$a$$, which moves the vertex. That is why the proof takes $$a$$ out and multiplies it
back in instead.

:::example[Finding a vertex]

Find the lowest point of $$y = 2x^2 - 8x + 5$$.

Take out $$2$$, complete the square, and multiply back by $$2$$:

```math
\begin{aligned}
2x^2 - 8x + 5 &= 2(x^2 - 4x) + 5 \\
&= 2\big((x - 2)^2 - 4\big) + 5 \\
&= 2(x - 2)^2 - 8 + 5 = 2(x - 2)^2 - 3
\end{aligned}
```

So $$s = 2$$ and $$k = -3$$. The formulas give the same: with $$a = 2$$, $$b = -8$$ and $$c = 5$$,
$$s = -\frac{-8}{4} = 2$$ and $$k = 5 - \frac{64}{8} = -3$$. Since $$a = 2 > 0$$, the parabola opens
upwards, and its lowest point is $$(2, -3)$$.

:::

## The discriminant counts crossings

The vertex form shows at once how many times a parabola crosses the $$x$$-axis. Take one that opens
upwards. If its lowest point is below the axis, the curve comes down through the axis, turns, and
goes back up through it: two crossings. If the lowest point is on the axis, the curve just touches
it: one. If the lowest point is above the axis, the whole curve is above it: none. For a parabola
that opens downwards, turn the picture over: two crossings when the highest point is above the axis.

The height of the vertex is $$k = c - \frac{b^2}{4a}$$, which can be written as

```math
k = -\frac{b^2 - 4ac}{4a}.
```

So $$k$$ has the opposite sign to $$b^2 - 4ac$$ when $$a > 0$$, and the same sign when $$a < 0$$.
Either way, two crossings happen exactly when the discriminant $$b^2 - 4ac$$ (:ref{#discriminant})
is positive, one when it is $$0$$, and none when it is negative. This is the picture behind
:ref{#root-count}.

Try it: this parabola opens downwards. Move it up and down and watch the discriminant change sign as
the crossings appear and disappear.

## Lines and parabolas

Pictures also show what solving means when two graphs meet. On the
[Equations as lines](../linear-equations/lines.mdx) page, the solution of two linear equations was
the point where their lines cross. In the same way, the points where the line $$y = x + 2$$ meets
the parabola $$y = x^2$$ have the same $$y$$ on both, so their $$x$$ satisfies

```math
x^2 = x + 2, \quad\text{that is,}\quad x^2 - x - 2 = (x - 2)(x + 1) = 0.
```

So $$x = 2$$ or $$x = -1$$, and the meeting points are $$(2, 4)$$ and $$(-1, 1)$$. A line meets a
parabola twice, once, or not at all, for the same reason a quadratic has two, one or no solutions.

## Exercises

:::::accordion[Exercises on parabolas, with solutions]

::::exercise{#ex-parabolas-vertex}

For each parabola, say whether it opens upwards or downwards, and find its vertex.

1. $$y = x^2 - 8x + 12$$
2. $$y = -x^2 + 4x - 1$$

:::solution

Use :ref{#vertex}, with $$s = -\frac{b}{2a}$$ and $$k = c - \frac{b^2}{4a}$$.

1. $$a = 1 > 0$$, so it opens upwards (:ref{#parabola}). Then $$s = \frac{8}{2} = 4$$ and
   $$k = 12 - \frac{64}{4} = -4$$, so the lowest point is $$(4, -4)$$. As a check, at $$x = 4$$,
   $$16 - 32 + 12 = -4$$.
2. $$a = -1 < 0$$, so it opens downwards. Then $$s = -\frac{4}{-2} = 2$$ and
   $$k = -1 - \frac{16}{-4} = -1 + 4 = 3$$, so the highest point is $$(2, 3)$$. Check:
   $$-4 + 8 - 1 = 3$$.

:::

::::

::::exercise{#ex-parabolas-no-crossing}

How many times does $$y = 2x^2 - 4x + 5$$ cross the $$x$$-axis? Answer using the vertex, then check
with the discriminant.

:::solution

With $$a = 2$$, $$b = -4$$ and $$c = 5$$, the vertex has $$s = \frac{4}{4} = 1$$ and
$$k = 5 - \frac{16}{8} = 3$$ (:ref{#vertex}). Since $$a > 0$$, the lowest value is $$3$$, which is
above the axis. So the whole curve is above the axis, and it never crosses it.

The discriminant agrees: $$b^2 - 4ac = 16 - 40 = -24 < 0$$, so $$2x^2 - 4x + 5 = 0$$ has no solution
(:ref{#root-count}).

:::

::::

::::exercise{#ex-parabolas-largest}

Find the largest value of $$6x - x^2 - 4$$, and the $$x$$ where it happens.

:::solution

In standard order it is $$-x^2 + 6x - 4$$, with $$a = -1$$, $$b = 6$$ and $$c = -4$$. Since
$$a < 0$$, part 2 of :ref{#vertex} gives a largest value. Here $$s = -\frac{6}{-2} = 3$$ and
$$k = -4 - \frac{36}{-4} = -4 + 9 = 5$$.

So the largest value is $$5$$, reached at $$x = 3$$ only. In vertex form,
$$-x^2 + 6x - 4 = -(x - 3)^2 + 5$$, and $$-(x - 3)^2$$ is never positive.

:::

::::

::::exercise{#ex-parabolas-touch}

Find the number $$c$$ for which the vertex of $$y = x^2 - 6x + c$$ lies on the $$x$$-axis. How many
times does that parabola meet the axis?

:::solution

The vertex is at $$s = 3$$, with height $$k = c - \frac{36}{4} = c - 9$$ (:ref{#vertex}). It lies on
the axis exactly when $$k = 0$$, so $$c = 9$$.

Then $$y = x^2 - 6x + 9 = (x - 3)^2$$. Its lowest point $$(3, 0)$$ is on the axis, and every other
point is above it, so the parabola touches the axis once, at $$x = 3$$. The discriminant
$$36 - 36 = 0$$ agrees (:ref{#root-count}).

:::

::::

::::exercise{#ex-parabolas-two-points}

The parabola $$y = x^2 + bx + c$$ passes through $$(1, 5)$$ and $$(5, 5)$$. Find $$b$$, $$c$$ and
its axis of symmetry.

:::solution

Putting in the two points,

```math
1 + b + c = 5 \qquad\text{and}\qquad 25 + 5b + c = 5
```

Subtracting the first equation from the second gives $$24 + 4b = 0$$, so $$b = -6$$. Then
$$1 - 6 + c = 5$$, so $$c = 10$$.

The axis of symmetry is the line $$x = s$$ with $$s = -\frac{b}{2a} = 3$$ (:ref{#vertex}). That is
halfway between $$x = 1$$ and $$x = 5$$, as it should be, since the two points have the same height.
Check: $$25 - 30 + 10 = 5$$.

:::

::::

::::exercise{#ex-parabolas-dividing}

To find the vertex of $$y = 3x^2 - 6x + 1$$, someone divides by $$3$$ first, gets
$$y = x^2 - 2x + \frac{1}{3}$$, and says the vertex is $$\left(1, -\frac{2}{3}\right)$$. Which part
of the answer is right, and what is the vertex?

:::solution

Dividing by $$3$$ divides every height by $$3$$. It doesn't change where the lowest point is, so the
$$x$$ coordinate $$1$$ is right, but it changes how low that point is.

The correct height comes from :ref{#vertex}: $$k = 1 - \frac{36}{12} = -2$$. So the vertex is
$$(1, -2)$$. Check: at $$x = 1$$, $$3 - 6 + 1 = -2$$, which is $$3$$ times the wrong height
$$-\frac{2}{3}$$.

Dividing is fine for solving $$3x^2 - 6x + 1 = 0$$, because $$0$$ divided by $$3$$ is still $$0$$.
For the curve it is not, which is why the method takes $$3$$ out and multiplies it back in.

:::

::::

::::exercise{#ex-parabolas-below}

Show that if $$a > 0$$ and $$c < 0$$, the vertex of $$y = ax^2 + bx + c$$ is below the $$x$$-axis.
How many times does the parabola cross the axis?

:::solution

By :ref{#vertex}, the vertex has height $$k = c - \frac{b^2}{4a}$$. Here $$b^2 \ge 0$$
(:ref{#real-numbers/squares-positive}) and $$4a > 0$$, so $$\frac{b^2}{4a} \ge 0$$. Taking it from
$$c < 0$$ leaves a negative number, so $$k < 0$$.

Since $$a > 0$$, the parabola opens upwards with its lowest point below the axis, so it crosses the
axis twice. Equivalently, $$ac < 0$$ makes the discriminant $$b^2 - 4ac$$ positive
(:ref{#root-count}).

:::
