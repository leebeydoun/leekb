Say the temperature drops by $$5$$ degrees overnight. The change is $$-5$$, but if someone asks how
much it changed, you'd say $$5$$ degrees. Here only the size of the number matters, not its sign,
and that size is called the **absolute value**. In this guide we'll see that it also measures
distance on the number line, and that it settles the puzzle from [Square roots](./square-roots.mdx)
that $$\sqrt{x^2}$$ isn't always $$x$$.

## Size without the sign

The absolute value should give the size of a number, whatever its sign. For a number like $$5$$ that
is the number itself. For a negative number like $$-5$$ it is the same number with the sign flipped,
$$5$$. Flipping the sign is the same as taking the opposite, so the rule is: leave a number alone if
it is $$0$$ or more, and replace it by its opposite if it is negative.

:::definition[Absolute value]{#absolute-value}

The **absolute value** of a real number $$x$$, written $$|x|$$, is

```math
|x| = \begin{cases} x & \text{if } x \ge 0 \\ -x & \text{if } x < 0 \end{cases}
```

:::

So $$|5| = 5$$, $$|-5| = 5$$ and $$|0| = 0$$. For a negative number $$x$$, the opposite $$-x$$ is
positive, so for a number like $$-5$$ the absolute value drops the minus sign. For an expression,
work out its sign first: $$\sqrt{2} > 1$$, so $$1 - \sqrt{2}$$ is negative, and
$$\left|1 - \sqrt{2}\right| = -\left(1 - \sqrt{2}\right) = \sqrt{2} - 1$$.

:::proposition[Basic properties of absolute value]{#abs-basics}

For every real number $$x$$:

1. $$|x| \ge 0$$, and $$|x| = 0$$ exactly when $$x = 0$$.
2. $$|-x| = |x|$$.
3. $$-|x| \le x \le |x|$$.
4. $$|x|^2 = x^2$$, and $$|x| = \sqrt{x^2}$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Absolute_value#Real_numbers"}

Every part is checked by taking the two cases of the definition in turn.

**Case $$x \ge 0$$.** Then $$|x| = x$$, which is not negative, and it is $$0$$ only for $$x = 0$$.
For part 2: if $$x > 0$$, then $$-x$$ is negative, so $$|-x| = -(-x) = x$$; if $$x = 0$$, both sides
are $$0$$. Either way $$|-x| = x = |x|$$. Part 3 says $$-x \le x \le x$$, which holds because
$$-x \le 0 \le x$$. And $$|x|^2 = x^2$$ since $$|x| = x$$.

**Case $$x < 0$$.** Then $$|x| = -x$$, which is positive, so not $$0$$. Also $$-x > 0$$, so
$$|-x| = -x = |x|$$. Part 3 says $$x \le x \le -x$$, which holds because $$x < 0 < -x$$. And
$$|x|^2 = (-x)^2 = x^2$$ by :ref{#numbers/two-minus}.

For the last part: $$|x|$$ is not negative and its square is $$x^2$$, so it is the square root of
$$x^2$$ (:ref{#equal-squares}).

:::

Part 4 answers the puzzle: $$\sqrt{x^2} = |x|$$, which is $$x$$ exactly when $$x \ge 0$$. For
example, $$\sqrt{(-4)^2} = \sqrt{16} = 4 = |-4|$$.

:::proposition[Absolute value of products and quotients]{#abs-product}

For real numbers $$a$$ and $$b$$, $$|ab| = |a|\,|b|$$, and if $$b \neq 0$$, then
$$\left|\frac{a}{b}\right| = \frac{|a|}{|b|}$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Absolute_value#Real_numbers"}

Both $$|ab|$$ and $$|a|\,|b|$$ are not negative, and their squares are equal:

```math
|ab|^2 = (ab)^2 = a^2 b^2 = |a|^2 |b|^2 = \left(|a|\,|b|\right)^2
```

using part 4 of :ref{#abs-basics} and the rules for powers. Two non-negative numbers with equal
squares are equal (:ref{#equal-squares}), so $$|ab| = |a|\,|b|$$. The quotient works the same way,
since $$\left(\frac{a}{b}\right)^2 = \frac{a^2}{b^2}$$.

:::

So $$|-3x| = 3|x|$$, and $$\left|\frac{-6}{4}\right| = \frac{6}{4}$$. Sums are different:
$$|3 + (-5)| = 2$$, but $$|3| + |-5| = 8$$.

## Distance

The distance between two numbers is how far apart they are on the line, without caring about
direction. The difference $$7 - 3 = 4$$ already measures the step from $$3$$ to $$7$$. But
subtracting the other way round gives $$3 - 7 = -4$$, because the step from $$7$$ back to $$3$$ goes
to the left. Taking the absolute value throws away the direction and keeps the length, $$4$$, either
way.

:::definition[Distance]{#distance}

The **distance** between two real numbers $$a$$ and $$b$$ is $$|a - b|$$.

:::

For example, the distance between $$-2$$ and $$3$$ is $$|-2 - 3| = |-5| = 5$$, which is the number
of steps from one to the other:

::number-line{from=-3 to=4 points="-2, 3" jumps="-2>3: 5"}

The order doesn't matter: $$|b - a| = |-(a - b)| = |a - b|$$ by part 2 of :ref{#abs-basics}. And the
distance of $$a$$ from $$0$$ is $$|a - 0| = |a|$$: the absolute value of a number is its distance
from zero.

## The triangle inequality

When two numbers with the same sign are added, their sizes add up: $$3 + 5 = 8$$. When the signs are
opposite, part of one cancels part of the other, so the result is smaller: $$3 + (-5) = -2$$, which
has size $$2$$, not $$8$$. So the size of a sum is never more than the sizes added together, and it
is less exactly when some cancelling happens.

This is called the **triangle inequality**: the absolute value of a sum is at most the sum of the
absolute values. The name comes from geometry, where it says that one side of a triangle is never
longer than the other two together.

Try it: move $$a$$ and $$b$$, and watch when $$|a + b|$$ falls short of $$|a| + |b|$$.

<TriangleInequality a={3} b={-5} />

:::theorem[Triangle inequality]{#triangle-inequality}

For all real numbers $$a$$ and $$b$$,

```math
|a + b| \le |a| + |b|
```

with equality exactly when $$ab \ge 0$$, that is, when $$a$$ and $$b$$ don't have opposite signs.

:::

:::proof{source="https://en.wikipedia.org/wiki/Absolute_value#Real_numbers"}

Both sides are not negative, so it is enough to compare their squares (:ref{#power-order-converse}).
Using part 4 of :ref{#abs-basics} and :ref{#abs-product},

```math
|a + b|^2 = (a + b)^2 = a^2 + 2ab + b^2,
\qquad
\left(|a| + |b|\right)^2 = |a|^2 + 2|a|\,|b| + |b|^2 = a^2 + 2|ab| + b^2
```

These differ only in the middle terms, $$2ab$$ and $$2|ab|$$. By part 3 of :ref{#abs-basics},
$$ab \le |ab|$$, so $$|a + b|^2 \le \left(|a| + |b|\right)^2$$, and therefore
$$|a + b| \le |a| + |b|$$.

For the same reason, the two sides are equal exactly when their squares are, that is, when the
middle terms agree: $$ab = |ab|$$. By the definition of absolute value, that happens exactly when
$$ab \ge 0$$.

:::

For distances, the triangle inequality says that going from $$a$$ to $$c$$ by way of $$b$$ is never
shorter than going straight there.

:::corollary[Triangle inequality for distances]{#distance-triangle}

For all real numbers $$a$$, $$b$$ and $$c$$, $$|a - c| \le |a - b| + |b - c|$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Absolute_value#Distance"}

Since $$a - c = (a - b) + (b - c)$$, :ref{#triangle-inequality} applied to $$a - b$$ and $$b - c$$
gives $$|a - c| \le |a - b| + |b - c|$$.

:::

## Equations with absolute values

The equation $$|x| = 3$$ asks which numbers are at distance $$3$$ from $$0$$. There are two, $$3$$
and $$-3$$, one on each side of $$0$$. In the same way, an equation saying that some expression has
absolute value $$3$$ means the expression is either $$3$$ or $$-3$$. And since a size can never be
negative, an equation like $$|x| = -2$$ has no solution at all.

:::proposition[Solving |A| = c]{#abs-equation}

Let $$c$$ be a real number.

1. If $$c \ge 0$$, then $$|A| = c$$ exactly when $$A = c$$ or $$A = -c$$.
2. If $$c < 0$$, then $$|A| = c$$ has no solution.

:::

:::proof{source="https://www.mathsisfun.com/algebra/absolute-value-solving.html"}

**Part 2.** $$|A|$$ is never negative (:ref{#abs-basics}), so it can't equal a negative $$c$$.

**Part 1.** If $$A = c$$, then $$|A| = |c| = c$$ since $$c \ge 0$$. If $$A = -c$$, then
$$|A| = |-c| = |c| = c$$. Conversely, if $$|A| = c$$, then by the definition $$|A|$$ is either $$A$$
or $$-A$$. In the first case $$A = c$$, and in the second $$-A = c$$, so $$A = -c$$.

:::

On the number line, $$|x - a| = c$$ says that $$x$$ is at distance $$c$$ from $$a$$: there are two
such points, one on each side.

:::example[Distance from a point]

Solve $$|x - 4| = 3$$.

By :ref{#abs-equation}, $$x - 4 = 3$$ or $$x - 4 = -3$$, so $$x = 7$$ or $$x = 1$$: the two numbers
at distance $$3$$ from $$4$$.

::number-line{from=0 to=8 points="1, 7" jumps="4>1: 3, 4>7: 3"}

:::

:::example[A multiple of x inside]

Solve $$|3x + 2| = 8$$.

Either $$3x + 2 = 8$$, giving $$x = 2$$, or $$3x + 2 = -8$$, giving $$x = -\frac{10}{3}$$.

**Check:** $$|3 \cdot 2 + 2| = 8$$ and $$\left|-10 + 2\right| = 8$$.

:::

When the right side involves $$x$$, it must not be negative, so each answer needs checking.

:::example[The unknown on both sides]

Solve $$|x - 3| = 2x$$.

The two cases are $$x - 3 = 2x$$, giving $$x = -3$$, and $$x - 3 = -2x$$, giving $$x = 1$$. But
:ref{#abs-equation} only covers a right side that isn't negative, so each answer must be checked.
For $$x = -3$$ the right side $$2x$$ is $$-6$$, so this is not a solution: indeed $$|-3 - 3| = 6$$,
not $$-6$$. For $$x = 1$$ it is $$2$$, and $$|1 - 3| = 2$$. So the only solution is $$x = 1$$.

:::

An equation with an absolute value on each side can be solved by squaring, which is safe here
because both sides are not negative (:ref{#squaring-sides}).

:::example[Equal distances]

Solve $$|x - 1| = |x + 5|$$.

Squaring, $$(x - 1)^2 = (x + 5)^2$$, so $$x^2 - 2x + 1 = x^2 + 10x + 25$$. Then $$-12x = 24$$ and
$$x = -2$$.

This makes sense on the number line: $$|x - 1| = |x - (-5)|$$ says $$x$$ is the same distance from
$$1$$ as from $$-5$$, so it is halfway between them, at $$\frac{1 + (-5)}{2} = -2$$.

:::

## Exercises

:::::accordion[Exercises on absolute value, with solutions]

::::exercise{#ex-absolute-value-evaluate}

Write without absolute value signs: $$|-8| - |8|$$, $$\left|3 - \sqrt{10}\right|$$, and $$|-2x|$$
when $$x = -5$$.

:::solution

- $$|-8| - |8| = 8 - 8 = 0$$.
- Since $$10 > 9$$, $$\sqrt{10} > 3$$ (:ref{#root-order}), so $$3 - \sqrt{10}$$ is negative. Its
  absolute value is its opposite, $$\sqrt{10} - 3$$.
- When $$x = -5$$, $$-2x = 10$$, so $$|-2x| = 10$$. You can also use :ref{#abs-product}:
  $$|-2x| = 2|x| = 2 \cdot 5 = 10$$.

:::

::::

::::exercise{#ex-absolute-value-distances}

Find the distance between $$-4.5$$ and $$1.5$$, and between $$-\sqrt{2}$$ and $$\sqrt{2}$$. Then
find the numbers at distance $$2.5$$ from $$-1$$.

:::solution

By :ref{#distance}:

- $$|-4.5 - 1.5| = |-6| = 6$$.
- $$\left|-\sqrt{2} - \sqrt{2}\right| = \left|-2\sqrt{2}\right| = 2\sqrt{2}$$.

The numbers at distance $$2.5$$ from $$-1$$ solve $$|x + 1| = 2.5$$. By :ref{#abs-equation},
$$x + 1 = 2.5$$ or $$x + 1 = -2.5$$, so $$x = 1.5$$ or $$x = -3.5$$.

:::

::::

::::exercise{#ex-absolute-value-true-false}

Which of these are true for every real number $$x$$? Give a counterexample for each one that isn't.

1. $$|x| = x$$
2. $$|-x| = x$$
3. $$\left|x^2\right| = x^2$$
4. $$|x|^3 = \left|x^3\right|$$

:::solution

1. False: $$|-1| = 1$$, not $$-1$$.
2. False: for $$x = -1$$, $$|-x| = |1| = 1$$, not $$-1$$. In fact $$|-x| = |x|$$
   (:ref{#abs-basics}).
3. True: $$x^2$$ is never negative (:ref{#squares-positive}), so it is its own absolute value.
4. True: by :ref{#abs-product} used twice, $$\left|x^3\right| = |x|\,|x|\,|x| = |x|^3$$.

:::

::::

::::exercise{#ex-absolute-value-equations}

Solve $$|5 - 2x| = 7$$, $$|4x + 1| = 0$$ and $$|x - 2| + 3 = 1$$.

:::solution

By :ref{#abs-equation}:

- $$5 - 2x = 7$$ gives $$x = -1$$, and $$5 - 2x = -7$$ gives $$x = 6$$.
- $$4x + 1 = 0$$, so $$x = -\frac{1}{4}$$.
- The equation says $$|x - 2| = -2$$. An absolute value is never negative, so there is no solution.

:::

::::

::::exercise{#ex-absolute-value-both-sides}

Solve $$|x + 2| = 3x$$.

:::solution

The two cases are $$x + 2 = 3x$$, giving $$x = 1$$, and $$x + 2 = -3x$$, giving
$$x = -\frac{1}{2}$$. The right side $$3x$$ involves $$x$$, so each answer must make it not
negative.

- $$x = 1$$: the right side is $$3$$, and $$|1 + 2| = 3$$. A solution.
- $$x = -\frac{1}{2}$$: the right side is $$-\frac{3}{2}$$, which is negative, so this is not a
  solution. Indeed $$\left|\frac{3}{2}\right| = \frac{3}{2}$$, not $$-\frac{3}{2}$$.

So the only solution is $$x = 1$$.

:::

::::

::::exercise{#ex-absolute-value-bounds}

Suppose $$|a| \le 2$$ and $$|b| \le 5$$. Show that $$|a - b| \le 7$$ and $$|3a + b| \le 11$$.

:::solution

By :ref{#triangle-inequality} applied to $$a$$ and $$-b$$, and $$|-b| = |b|$$:

```math
|a - b| \le |a| + |-b| = |a| + |b| \le 2 + 5 = 7
```

In the same way, using :ref{#abs-product} for $$|3a| = 3|a|$$:

```math
|3a + b| \le |3a| + |b| = 3|a| + |b| \le 6 + 5 = 11
```

:::

::::

::::exercise{#ex-absolute-value-zero-distance}

Prove that the distance between $$a$$ and $$b$$ is $$0$$ exactly when $$a = b$$.

:::solution

The distance is $$|a - b|$$ (:ref{#distance}). By part 1 of :ref{#abs-basics}, $$|a - b| = 0$$
exactly when $$a - b = 0$$, that is, when $$a = b$$.

:::

::::

::::exercise{#ex-absolute-value-two-steps}

Numbers $$a$$, $$b$$ and $$c$$ have $$|a - b| = 3$$ and $$|b - c| = 5$$. What can $$|a - c|$$ be?

:::solution

Write $$a - c = (a - b) + (b - c)$$. By :ref{#abs-equation}, $$a - b$$ is $$3$$ or $$-3$$, and
$$b - c$$ is $$5$$ or $$-5$$. So $$a - c$$ is one of $$8$$, $$-2$$, $$2$$ and $$-8$$, and
$$|a - c|$$ is $$8$$ or $$2$$.

Both happen. With $$a = 0$$, $$b = 3$$ and $$c = 8$$, the distance is $$8$$: the two steps go the
same way, and :ref{#distance-triangle} holds with equality. With $$a = 0$$, $$b = 3$$ and
$$c = -2$$, the steps go opposite ways and the distance is $$2$$.

:::
