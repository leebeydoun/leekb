A square garden has an area of $$10$$ square metres, so its side is a number that squares to $$10$$.
No fraction does, but among the real numbers every positive number has a square root. This is the
first thing the real numbers give you that the fractions can't. In this guide we'll show that a
positive number has exactly two square roots and settle which one $$\sqrt{\ }$$ means, and then work
out the rules for calculating with it.

## Every positive number has a square root

Picture a square whose side starts at $$0$$ and slowly grows. Its area starts at $$0$$ and grows
too, steadily and without jumping, so it should pass through every positive value on the way. With
only fractions for the side, it would skip over some areas, such as $$2$$. The real numbers have no
gaps, so nothing is skipped.

<GrowingSquare />

The first page found the number whose square is $$2$$ one decimal digit at a time, and the same
digit-by-digit search works for any positive number. The result is taken as given.

:::remark[Square roots exist]{#square-roots-exist}

For every positive real number $$a$$, there is a real number $$b$$ with $$b^2 = a$$.

::see-also{src="https://en.wikipedia.org/wiki/Square_root#Properties_and_uses"}

:::

Square roots come in pairs, because a number and its opposite have the same square: $$3^2$$ and
$$(-3)^2$$ are both $$9$$. The theorem below says there are no others. A positive number has exactly
two, $$0$$ has only itself, and a negative number has none, since no square is negative.

:::theorem[Solving x² = a]{#square-root-count}

Let $$a$$ be a real number.

1. If $$a > 0$$, the equation $$x^2 = a$$ has exactly two solutions. They are opposites, $$b$$ and
   $$-b$$, and exactly one of them is positive.
2. If $$a = 0$$, its only solution is $$x = 0$$.
3. If $$a < 0$$, it has no solution.

:::

:::proof{source="https://en.wikipedia.org/wiki/Square_root"}

**Part 1.** By :ref{#square-roots-exist}, there is a number $$b$$ with $$b^2 = a$$. It isn't $$0$$,
since $$0^2 = 0$$ and $$a \neq 0$$. Its opposite works too, since $$(-b)^2 = b^2 = a$$ by
:ref{#numbers/two-minus}.

There are no other solutions. If $$x^2 = a$$, then $$x^2 = b^2$$, so $$x^2 - b^2 = 0$$. Factoring
the difference of two squares (:ref{#numbers/square-formulas}),

```math
(x - b)(x + b) = 0
```

A product is $$0$$ only when a factor is (:ref{#numbers/zero-product}), so $$x = b$$ or $$x = -b$$.

The two solutions are different: if $$b = -b$$, then $$2b = 0$$ and $$b = 0$$, which it isn't. And
since $$b \neq 0$$, rule 2 of :ref{#positivity} says that exactly one of $$b$$ and $$-b$$ is
positive.

**Part 2.** If $$x^2 = 0$$, then $$x \cdot x = 0$$, so $$x = 0$$ by :ref{#numbers/zero-product}.

**Part 3.** A square is never negative (:ref{#squares-positive}), so it can't equal a negative
number.

:::

## The square root sign

Since a positive number has two square roots, the symbol for "the" square root has to choose one. By
a convention used throughout mathematics, it chooses the positive one.

:::definition[Square root]{#square-root}

For a real number $$a \ge 0$$, the **square root** $$\sqrt{a}$$ is the number $$x \ge 0$$ with
$$x^2 = a$$.

:::

By :ref{#square-root-count}, there is exactly one such number. So $$\sqrt{9} = 3$$, not $$-3$$,
$$\sqrt{0} = 0$$, and $$\sqrt{a}$$ is never negative. The two solutions of $$x^2 = a$$, for
$$a > 0$$, are

```math
x = \sqrt{a} \qquad \text{and} \qquad x = -\sqrt{a}
```

often written together as $$x = \pm\sqrt{a}$$, read "plus or minus root $$a$$". For example,
$$x^2 = 7$$ has the solutions $$\pm\sqrt{7}$$, and $$(x - 1)^2 = 16$$ gives $$x - 1 = \pm 4$$, so
$$x = 5$$ or $$x = -3$$.

The same factoring gives a rule that this chapter uses again and again.

:::corollary[Equal squares]{#equal-squares}

If $$x^2 = y^2$$, then $$x = y$$ or $$x = -y$$. If also $$x \ge 0$$ and $$y \ge 0$$, then $$x = y$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Square_root"}

If $$x^2 = y^2$$, then $$(x - y)(x + y) = x^2 - y^2 = 0$$ by :ref{#numbers/square-formulas}, so
$$x = y$$ or $$x = -y$$ by :ref{#numbers/zero-product}.

If both are non-negative and $$x = -y$$, then $$x \ge 0$$ and $$x = -y \le 0$$, so $$x = 0$$, and
then $$y = 0$$ too. So $$x = y$$ in either case.

:::

The second part gives a test for a square root: to show that $$c = \sqrt{a}$$, it is enough to check
that $$c \ge 0$$ and $$c^2 = a$$. The proofs below use this test again and again.

## Rules for square roots

Taking a square root undoes squaring, so its rules mirror the rules for squares. Squaring splits
over products: $$(2 \cdot 3)^2 = 4 \cdot 9$$. Read backwards, the square root of $$4 \cdot 9$$ is
$$2 \cdot 3$$, the product of the square roots of $$4$$ and $$9$$. The same goes for quotients. And
since a bigger square has a longer side, a bigger number has a bigger square root.

:::proposition[Square roots of products and quotients]{#root-product}

For $$a \ge 0$$ and $$b \ge 0$$,

```math
\sqrt{ab} = \sqrt{a}\,\sqrt{b}
```

and if also $$b > 0$$, then $$\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Square_root#Properties_and_uses"}

The number $$\sqrt{a}\sqrt{b}$$ is a product of two numbers that are not negative, so it is not
negative. Its square is

```math
\left(\sqrt{a}\,\sqrt{b}\right)^2 = \left(\sqrt{a}\right)^2 \left(\sqrt{b}\right)^2 = ab
```

by :ref{#numbers/power-rules}. So it is the square root of $$ab$$, by :ref{#equal-squares}.

For the quotient, $$\frac{\sqrt{a}}{\sqrt{b}}$$ is not negative, since $$\sqrt{b} > 0$$, and its
square is $$\frac{a}{b}$$. So it is $$\sqrt{\frac{a}{b}}$$ in the same way.

:::

This is how square roots are **simplified**: pull out any square factor.

```math
\sqrt{12} = \sqrt{4 \cdot 3} = \sqrt{4}\,\sqrt{3} = 2\sqrt{3},
\qquad
\sqrt{72} = \sqrt{36 \cdot 2} = 6\sqrt{2},
\qquad
\sqrt{\tfrac{5}{9}} = \frac{\sqrt{5}}{3}
```

Once simplified, multiples of the same root can be collected, in the same way as $$2x + 3x = 5x$$.
For example, $$\sqrt{8} + \sqrt{18} = 2\sqrt{2} + 3\sqrt{2} = 5\sqrt{2}$$. But
$$\sqrt{2} + \sqrt{3}$$ can't be collected into a single root.

Square roots don't split over sums, though: $$\sqrt{9 + 16} = \sqrt{25} = 5$$, while
$$\sqrt{9} + \sqrt{16} = 3 + 4 = 7$$. In fact, for positive $$a$$ and $$b$$, $$\sqrt{a} + \sqrt{b}$$
is always the bigger of the two. Both are positive, so it is enough to compare their squares
(:ref{#power-order-converse}), and $$\left(\sqrt{a} + \sqrt{b}\right)^2 = a + b + 2\sqrt{ab}$$,
which is more than $$a + b$$.

:::proposition[Square roots keep order]{#root-order}

If $$0 \le a < b$$, then $$\sqrt{a} < \sqrt{b}$$.

:::

:::proof{source="https://proofwiki.org/wiki/Power_Function_is_Strictly_Increasing_over_Positive_Reals/Natural_Exponent"}

The numbers $$\sqrt{a}$$ and $$\sqrt{b}$$ are not negative, and their squares are $$a$$ and $$b$$,
with $$a < b$$. By :ref{#power-order-converse} with $$n = 2$$, $$\sqrt{a} < \sqrt{b}$$.

:::

So, for example, $$\sqrt{10}$$ lies between $$\sqrt{9} = 3$$ and $$\sqrt{16} = 4$$.

## Rational and irrational

The Numbers chapter proved that $$\sqrt{2}$$ and $$\sqrt{3}$$ are irrational
(:ref{#numbers/sqrt-two}, :ref{#numbers/sqrt-three}). Infinitely many more irrational numbers can be
built from them.

The idea is that adding a fraction, or multiplying by a fraction other than $$0$$, can always be
undone with another fraction. If adding $$1$$ to some number gave a fraction, then taking $$1$$ away
again would show that the number was a fraction all along. So shifting or scaling an irrational
number in this way can't make it rational.

:::theorem[Rational and irrational combined]{#rational-irrational}

Let $$r$$ be rational and $$x$$ irrational. Then $$r + x$$ is irrational, and if $$r \neq 0$$, so is
$$rx$$.

:::

:::proof{source="https://proofwiki.org/wiki/Rational_Number_plus_Irrational_Number_is_Irrational"}

Both parts are by contradiction (:ref{#basic-proofs/contradiction}). They rest on one fact: adding,
subtracting, multiplying or dividing rational numbers always gives a rational number (by
:ref{#numbers/fraction-addition}, :ref{#numbers/fraction-multiplication} and
:ref{#numbers/inverse-exists}). So if $$x$$ could be got from rational numbers that way, it would be
rational.

**Sum.** Suppose $$r + x = s$$ with $$s$$ rational. Then $$x = s - r$$ is a difference of rational
numbers, so it is rational. But $$x$$ is irrational, a contradiction.

**Product.** Suppose $$rx = s$$ with $$s$$ rational, and $$r \neq 0$$. Then $$x = \frac{s}{r}$$ is a
quotient of rational numbers, so it is rational, again a contradiction.

:::

So $$1 + \sqrt{2}$$, $$5\sqrt{3}$$ and $$\frac{\sqrt{2}}{2}$$ are all irrational, and so is
$$\sqrt{8} = 2\sqrt{2}$$. But two irrational numbers can combine to give a rational one:
$$\sqrt{2} + (1 - \sqrt{2}) = 1$$ and $$\sqrt{2} \cdot \sqrt{2} = 2$$.

## Averages and the AM–GM inequality

For two numbers $$a$$ and $$b$$, the ordinary average $$\frac{a + b}{2}$$ is called their
**arithmetic mean**. When they are not negative, $$\sqrt{ab}$$ is called their **geometric mean**:
it is the side of a square with the same area as an $$a$$ by $$b$$ rectangle.

Try a few pairs. For $$4$$ and $$4$$, both means are $$4$$. For $$2$$ and $$8$$, the average is
$$5$$ but the geometric mean is $$\sqrt{16} = 4$$. For $$1$$ and $$16$$, the average is $$8.5$$ and
the geometric mean is still $$4$$. Keeping the product the same while moving the numbers further
apart makes the average pull further ahead, and the two means agree only when the numbers are equal.
In terms of shapes, a square encloses a given area with less fence than any other rectangle.

Try it: every rectangle below has area $$16$$. Change its width and compare the two means.

<RectangleFence />

:::theorem[AM–GM inequality]{#am-gm}

For all real numbers $$a \ge 0$$ and $$b \ge 0$$,

```math
\frac{a + b}{2} \ge \sqrt{ab}
```

with equality exactly when $$a = b$$.

:::

:::proof{source="https://brilliant.org/wiki/arithmetic-mean-geometric-mean/"}

Apply :ref{#two-squares} to the numbers $$\sqrt{a}$$ and $$\sqrt{b}$$:

```math
\left(\sqrt{a}\right)^2 + \left(\sqrt{b}\right)^2 \ge 2\sqrt{a}\,\sqrt{b},
\qquad \text{that is,} \qquad a + b \ge 2\sqrt{ab}
```

using :ref{#root-product}. Multiplying by $$\frac{1}{2}$$ gives the inequality. Equality holds
exactly when $$\sqrt{a} = \sqrt{b}$$, which by :ref{#equal-squares} happens exactly when $$a = b$$.

:::

:::example[The cheapest fence]

A rectangular pen must have area $$36$$ square metres. Find the shortest fence that can go round it.

If the sides are $$x$$ and $$y$$ metres, then $$xy = 36$$ and the fence is $$2(x + y)$$ metres long.
By :ref{#am-gm},

```math
x + y \ge 2\sqrt{xy} = 2\sqrt{36} = 12
```

so the fence is at least $$24$$ metres, with equality only when $$x = y$$, that is, a $$6$$ by $$6$$
square. Any other shape needs more fence: a $$4$$ by $$9$$ pen needs $$26$$ metres.

:::

Another consequence: for $$x > 0$$, applying the inequality to $$x$$ and $$\frac{1}{x}$$ gives
$$x + \frac{1}{x} \ge 2\sqrt{x \cdot \frac{1}{x}} = 2$$. A positive number plus its reciprocal is
always at least $$2$$.

## Exercises

:::::accordion[Exercises on square roots, with solutions]

::::exercise{#ex-square-roots-evaluate}

Work out $$\sqrt{0.09}$$, $$\sqrt{\frac{49}{64}}$$, $$\sqrt{1.44}$$ and $$\sqrt{(-5)^2}$$, checking
each answer with the test after :ref{#equal-squares}.

:::solution

To show $$c = \sqrt{a}$$, check that $$c \ge 0$$ and $$c^2 = a$$:

- $$\sqrt{0.09} = 0.3$$, since $$0.3 \ge 0$$ and $$0.3^2 = 0.09$$.
- $$\sqrt{\frac{49}{64}} = \frac{7}{8}$$, since $$\left(\frac{7}{8}\right)^2 = \frac{49}{64}$$.
- $$\sqrt{1.44} = 1.2$$, since $$1.2^2 = 1.44$$.
- $$(-5)^2 = 25$$, so $$\sqrt{(-5)^2} = \sqrt{25} = 5$$, not $$-5$$: the square root is never
  negative.

:::

::::

::::exercise{#ex-square-roots-solve}

Solve $$(x + 3)^2 = 50$$, $$9x^2 = 2$$ and $$x^2 + 7 = 7$$.

:::solution

By :ref{#square-root-count}:

- $$x + 3 = \pm\sqrt{50} = \pm 5\sqrt{2}$$, so $$x = -3 + 5\sqrt{2}$$ or $$x = -3 - 5\sqrt{2}$$.
- $$x^2 = \frac{2}{9}$$, so $$x = \pm\sqrt{\frac{2}{9}} = \pm\frac{\sqrt{2}}{3}$$.
- $$x^2 = 0$$, so the only solution is $$x = 0$$.

:::

::::

::::exercise{#ex-square-roots-simplify}

Simplify $$\sqrt{98} - \sqrt{8}$$, $$\sqrt{\frac{3}{4}}\,\sqrt{12}$$ and
$$\frac{\sqrt{200}}{\sqrt{2}}$$.

:::solution

By :ref{#root-product}:

- $$\sqrt{98} = \sqrt{49 \cdot 2} = 7\sqrt{2}$$ and $$\sqrt{8} = 2\sqrt{2}$$, so the difference is
  $$5\sqrt{2}$$.
- $$\sqrt{\frac{3}{4}}\,\sqrt{12} = \sqrt{\frac{3}{4} \cdot 12} = \sqrt{9} = 3$$.
- $$\frac{\sqrt{200}}{\sqrt{2}} = \sqrt{\frac{200}{2}} = \sqrt{100} = 10$$.

:::

::::

::::exercise{#ex-square-roots-not-x}

Is $$\sqrt{x^2} = x$$ true for every real number $$x$$? If not, say exactly when it is true, and
what $$\sqrt{x^2}$$ is otherwise.

:::solution

No. For $$x = -3$$, $$\sqrt{x^2} = \sqrt{9} = 3$$, which is not $$-3$$.

By :ref{#square-root}, $$\sqrt{x^2}$$ is the number that is at least $$0$$ and squares to $$x^2$$.
If $$x \ge 0$$, that number is $$x$$ itself, so $$\sqrt{x^2} = x$$ exactly when $$x \ge 0$$. If
$$x < 0$$, then $$-x$$ is positive and $$(-x)^2 = x^2$$, so $$\sqrt{x^2} = -x$$. The
[Absolute value](./absolute-value.mdx) page gives this a name: $$\sqrt{x^2} = |x|$$.

:::

::::

::::exercise{#ex-square-roots-between}

Find the two whole numbers next to each other that $$\sqrt{50}$$ lies between. Then show that
$$0.7 < \sqrt{0.5} < 0.8$$.

:::solution

Since $$49 < 50 < 64$$, :ref{#root-order} gives $$\sqrt{49} < \sqrt{50} < \sqrt{64}$$, that is,
$$7 < \sqrt{50} < 8$$.

In the same way, $$0.49 < 0.5 < 0.64$$, so $$\sqrt{0.49} < \sqrt{0.5} < \sqrt{0.64}$$, that is,
$$0.7 < \sqrt{0.5} < 0.8$$.

:::

::::

::::exercise{#ex-square-roots-irrational}

Prove that $$5 - 3\sqrt{2}$$ and $$\sqrt{8} + \sqrt{2}$$ are irrational.

:::solution

The number $$\sqrt{2}$$ is irrational (:ref{#numbers/sqrt-two}). By :ref{#rational-irrational},
$$-3\sqrt{2}$$ is irrational, as a non-zero rational number times an irrational one. Adding the
rational number $$5$$ keeps it irrational, by the same theorem. So $$5 - 3\sqrt{2}$$ is irrational.

For the second, $$\sqrt{8} = 2\sqrt{2}$$, so $$\sqrt{8} + \sqrt{2} = 3\sqrt{2}$$. This is a non-zero
rational number times $$\sqrt{2}$$, so it is irrational.

:::

::::

::::exercise{#ex-square-roots-am-gm-product}

Prove that $$(a + b)\left(\frac{1}{a} + \frac{1}{b}\right) \ge 4$$ for all positive $$a$$ and $$b$$,
and find when equality holds.

:::solution

Expanding,

```math
(a + b)\left(\frac{1}{a} + \frac{1}{b}\right) = 1 + \frac{a}{b} + \frac{b}{a} + 1
= 2 + \left(x + \frac{1}{x}\right), \qquad \text{where } x = \frac{a}{b}
```

The number $$x$$ is positive and $$\frac{b}{a} = \frac{1}{x}$$. By :ref{#am-gm} applied to $$x$$ and
$$\frac{1}{x}$$, $$x + \frac{1}{x} \ge 2$$, so the whole expression is at least $$4$$.

Equality holds exactly when $$x = \frac{1}{x}$$, that is, $$x^2 = 1$$. Since $$x > 0$$, that means
$$x = 1$$, so $$a = b$$.

:::
