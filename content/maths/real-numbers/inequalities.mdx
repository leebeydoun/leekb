An equation usually has a few solutions; an inequality like $$2x + 1 < 7$$ usually has infinitely
many, filling a whole stretch of the number line. Solving it means describing that stretch exactly.
This page introduces the notation for such stretches, the **intervals**, shows which steps are safe
when solving an inequality, and then deals with products, quotients, squares and absolute values.

## Intervals

The solutions of an inequality usually fill an unbroken stretch of the number line, or a few of
them: all the numbers between $$1$$ and $$5$$, say, or all the numbers bigger than $$3$$. Intervals
are short names for these stretches. The only subtle point is the ends. A stretch may or may not
include its endpoints, since $$x < 5$$ leaves out $$5$$ but $$x \le 5$$ lets it in, so the notation
has to record that.

:::definition[Intervals]{#interval}

For real numbers $$a < b$$, the **intervals** with endpoints $$a$$ and $$b$$ are

| Notation   | The numbers $$x$$ with | Name      |
| ---------- | ---------------------- | --------- |
| $$(a, b)$$ | $$a < x < b$$          | open      |
| $$[a, b]$$ | $$a \le x \le b$$      | closed    |
| $$[a, b)$$ | $$a \le x < b$$        | half-open |
| $$(a, b]$$ | $$a < x \le b$$        | half-open |

and the **infinite intervals** $$(a, \infty)$$, $$[a, \infty)$$, $$(-\infty, b)$$ and
$$(-\infty, b]$$ are the numbers with $$x > a$$, $$x \ge a$$, $$x < b$$ and $$x \le b$$. All the
real numbers together are written $$(-\infty, \infty)$$.

:::

A square bracket includes the endpoint and a round one leaves it out. In pictures, an included
endpoint is a filled dot and a left-out one is a hollow dot. Here are $$(-2, 3]$$ and
$$[5, \infty)$$:

::number-line{from=-4 to=8 intervals="(-2, 3]; [5, oo)"}

The symbol $$\infty$$, read "infinity", is not a number. In $$[5, \infty)$$ it just says that the
interval goes on forever to the right, which is why that end always has a round bracket.

A solution can be made of several intervals. The word **or** joins them, or the symbol $$\cup$$,
read "union": $$(-\infty, -1) \cup (2, \infty)$$ means the numbers that are less than $$-1$$ or
greater than $$2$$.

## Safe steps for inequalities

As with equations, an inequality is solved by replacing it with simpler and simpler ones that have
exactly the same solutions. A safe step must neither lose a solution nor add one.

:ref{#inequality-rules} say which moves keep the order of two numbers. Sliding both sides by the
same amount keeps it, and so does stretching both by the same positive amount. Multiplying by a
negative number flips the order, so the inequality sign has to be turned round to match. Each of
these moves can also be undone by another move of the same kind, which is why nothing is gained or
lost. These steps are safe.

<InequalityScale a={-1} b={2} />

:::proposition[Safe steps for inequalities]{#inequality-steps}

Changing an inequality in any of these ways gives one with exactly the same solutions:

1. Adding the same number or expression to both sides.
2. Multiplying both sides by the same **positive** number.
3. Multiplying both sides by the same **negative** number and **reversing** the inequality.
4. Rewriting either side as something equal to it.

:::

:::proof{source="https://www.mathsisfun.com/algebra/inequality-solving.html"}

As for equations, we check that each step keeps every solution and can be undone. For particular
values of the unknowns, both sides are numbers, so :ref{#inequality-rules} apply.

1. Adding $$c$$ keeps the inequality, by rule 3. Adding $$-c$$ undoes it.
2. Multiplying by $$c > 0$$ keeps the inequality, by rule 4. Multiplying by $$\frac{1}{c}$$, which
   is also positive (:ref{#inverse-sign}), undoes it.
3. Multiplying by $$c < 0$$ and reversing keeps it true, by rule 5. Multiplying by $$\frac{1}{c}$$,
   which is also negative, and reversing again, undoes it.
4. Replacing a side by something equal to it doesn't change its value.

The same holds for $$\le$$ and $$\ge$$, since each is "$$<$$ or $$=$$", and equations already obey
these steps.

:::

Dividing by a number is multiplying by its reciprocal, so the same rules apply: dividing by a
negative number reverses the inequality.

## Linear inequalities

An inequality where the unknown is only multiplied by numbers and added to things is solved just
like a linear equation: get the unknown on its own. The one difference is that dividing by a
negative number turns the inequality round. For example, $$-x < 2$$ means $$x > -2$$. To see that
this is right, try $$x = -1$$: then $$-x$$ is $$1$$, which is less than $$2$$, and $$-1$$ is indeed
bigger than $$-2$$.

:::example[A first inequality]

Solve $$4x - 7 > 5$$.

Adding $$7$$ to both sides gives $$4x > 12$$. Multiplying by $$\frac{1}{4}$$, which is positive,
gives $$x > 3$$. The solutions are the interval $$(3, \infty)$$.

:::

:::example[Dividing by a negative number]

Solve $$2 - 3x \le 11$$.

Subtracting $$2$$ gives $$-3x \le 9$$. Dividing by $$-3$$ reverses the inequality: $$x \ge -3$$. The
solutions are $$[-3, \infty)$$.

**Check** with a number on each side of $$-3$$: $$x = 0$$ gives $$2 \le 11$$, which is true, and
$$x = -4$$ gives $$14 \le 11$$, which is false.

:::

When $$x$$ appears on both sides, collect it on one side, as with equations. For example,
$$2x + 9 < 5x - 3$$ becomes $$12 < 3x$$, so $$4 < x$$, that is, $$x > 4$$.

A **double inequality** like $$-5 \le 3x + 1 < 7$$ says two things at once, and the same step can be
applied to all three parts. Subtracting $$1$$ gives $$-6 \le 3x < 6$$, and dividing by $$3$$ gives
$$-2 \le x < 2$$, the interval $$[-2, 2)$$:

::number-line{from=-4 to=4 intervals="[-2, 2)"}

## Products and sign tables

To solve an inequality like $$(x - 2)(x + 3) < 0$$, it is enough to know when each factor is
positive or negative, because of the sign rules. A product of two numbers is negative exactly when
their signs differ: $$2 \cdot (-3)$$ is negative, but $$(-2) \cdot (-3)$$ is positive. So the sizes
of the factors don't matter, only their signs.

:::proposition[When a product is positive or negative]{#product-sign}

For real numbers $$a$$ and $$b$$:

1. $$ab > 0$$ exactly when $$a$$ and $$b$$ are both positive or both negative.
2. $$ab < 0$$ exactly when one is positive and the other negative.

The same holds for $$\frac{a}{b}$$, when $$b \neq 0$$.

:::

:::proof{source="https://www.mathsisfun.com/algebra/inequality-quadratic-solving.html"}

Each of $$a$$ and $$b$$ is positive, negative or zero. If either is zero, $$ab = 0$$
(:ref{#numbers/zero-times}), which is neither positive nor negative. Otherwise, rule 1 for
positivity and :ref{#sign-rules} say that $$ab$$ is positive when the signs match and negative when
they differ. Going through the cases, $$ab > 0$$ happens exactly when the signs match, and
$$ab < 0$$ exactly when they differ. For quotients, use :ref{#quotient-sign} in the same way.

:::

A factor like $$x - 2$$ is negative for $$x < 2$$, zero at $$x = 2$$, and positive for $$x > 2$$. So
the points where the factors are zero split the line into pieces, and on each piece every factor
keeps the same sign. A **sign table** records them.

Try it: move $$x$$ along the line and watch the signs of the two factors change at $$-3$$ and $$2$$.

<SolutionScanner kind="product" roots={[2, -3]} sense="<" />

:::example[A sign table]

Solve $$(x - 2)(x + 3) < 0$$.

The factors are zero at $$x = 2$$ and $$x = -3$$. These split the line into three pieces:

|                    | $$x < -3$$ | $$-3 < x < 2$$ | $$x > 2$$ |
| ------------------ | ---------- | -------------- | --------- |
| $$x + 3$$          | $$-$$      | $$+$$          | $$+$$     |
| $$x - 2$$          | $$-$$      | $$-$$          | $$+$$     |
| $$(x - 2)(x + 3)$$ | $$+$$      | $$-$$          | $$+$$     |

The product is negative only in the middle, and at $$x = -3$$ and $$x = 2$$ it is $$0$$, which is
not less than $$0$$. So the solutions are $$(-3, 2)$$.

:::

For $$(x - 2)(x + 3) \ge 0$$ instead, the same table gives the outer pieces, now with their
endpoints, since $$0 \ge 0$$: the solutions are $$(-\infty, -3] \cup [2, \infty)$$.

## Quotients

An inequality with $$x$$ on the bottom of a fraction needs care. Multiplying both sides by the
bottom is only safe if its sign is known, and it changes with $$x$$. With $$x + 2$$ on the bottom,
say, multiplying by it keeps the inequality when $$x$$ is above $$-2$$, but reverses it when $$x$$
is below $$-2$$. The safest route is to get $$0$$ on one side, combine into a single fraction, and
use a sign table.

:::example[x on the bottom]

Solve $$\frac{3x - 1}{x + 2} \ge 2$$.

The left side doesn't exist at $$x = -2$$, so that value is never a solution. Subtracting $$2$$ and
putting everything over the same denominator,

```math
\frac{3x - 1}{x + 2} - \frac{2(x + 2)}{x + 2} = \frac{x - 5}{x + 2} \ge 0
```

The top is zero at $$x = 5$$ and the bottom at $$x = -2$$:

|                         | $$x < -2$$ | $$-2 < x < 5$$ | $$x > 5$$ |
| ----------------------- | ---------- | -------------- | --------- |
| $$x + 2$$               | $$-$$      | $$+$$          | $$+$$     |
| $$x - 5$$               | $$-$$      | $$-$$          | $$+$$     |
| $$\frac{x - 5}{x + 2}$$ | $$+$$      | $$-$$          | $$+$$     |

The quotient is positive on the outer pieces and $$0$$ at $$x = 5$$. So the solutions are
$$(-\infty, -2) \cup [5, \infty)$$, with $$-2$$ left out and $$5$$ included.

:::

Multiplying through by $$x + 2$$ without care would have given $$3x - 1 \ge 2x + 4$$, so
$$x \ge 5$$, which misses every solution below $$-2$$. Splitting into the cases $$x + 2 > 0$$ and
$$x + 2 < 0$$ also works, but the sign table keeps track of everything at once.

## Squares

Squaring ignores the sign of a number, and the further a number is from $$0$$, the bigger its
square. Both $$3$$ and $$-3$$ square to $$9$$. So $$x^2 < 9$$ says that $$x$$ is less than $$3$$
away from $$0$$, on either side, which means $$x$$ lies between $$-3$$ and $$3$$. And $$x^2 > 9$$
says that $$x$$ is more than $$3$$ away from $$0$$, so it is either below $$-3$$ or above $$3$$.

<SolutionScanner kind="square" bound={9} sense="<" />

:::proposition[Comparing a square with a number]{#square-inequality}

Let $$c > 0$$. Then

1. $$x^2 < c$$ exactly when $$-\sqrt{c} < x < \sqrt{c}$$.
2. $$x^2 > c$$ exactly when $$x < -\sqrt{c}$$ or $$x > \sqrt{c}$$.

:::

:::proof{source="https://www.mathsisfun.com/algebra/inequality-quadratic-solving.html"}

Write $$s = \sqrt{c}$$, which is positive, so $$c = s^2$$. Then by the difference of two squares
(:ref{#numbers/square-formulas}),

```math
x^2 - c = (x - s)(x + s)
```

Since $$-s < s$$, the factor $$x + s$$ is negative for $$x < -s$$ and positive for $$x > -s$$, and
$$x - s$$ is negative for $$x < s$$ and positive for $$x > s$$. So the sign table is the same as in
the example above: the product is negative exactly when $$-s < x < s$$, and positive exactly when
$$x < -s$$ or $$x > s$$. By :ref{#product-sign}, these are the solutions of $$x^2 - c < 0$$ and
$$x^2 - c > 0$$.

:::

For example, $$x^2 \le 9$$ gives $$[-3, 3]$$, and $$x^2 > 5$$ gives
$$\left(-\infty, -\sqrt{5}\right) \cup \left(\sqrt{5}, \infty\right)$$. The cases with $$c \le 0$$
need no work: $$x^2 < -1$$ has no solutions and $$x^2 \ge 0$$ is true for every $$x$$, because
squares are never negative.

A common slip is to "take square roots" of $$x^2 < 9$$ and write $$x < 3$$. That keeps $$x = -10$$,
whose square is $$100$$.

## Absolute values

The inequality $$|x - a| < r$$ says that the distance from $$x$$ to $$a$$ is less than $$r$$, so
$$x$$ lies within $$r$$ of $$a$$ on either side. That is a single stretch centred on $$a$$. In the
same way, $$|x - a| > r$$ says that $$x$$ is further than $$r$$ from $$a$$, so it lies outside that
stretch, off one end or the other.

<SolutionScanner kind="abs" centre={1} radius={3} sense=">" />

:::proposition[Absolute value inequalities]{#abs-inequality}

Let $$r > 0$$. Then

1. $$|x - a| < r$$ exactly when $$a - r < x < a + r$$.
2. $$|x - a| > r$$ exactly when $$x < a - r$$ or $$x > a + r$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Absolute_value#Real_numbers"}

Write $$y = x - a$$. Both $$|y|$$ and $$r$$ are not negative, so $$|y| < r$$ exactly when
$$|y|^2 < r^2$$, by :ref{#power-order} and :ref{#power-order-converse}. And $$|y|^2 = y^2$$
(:ref{#abs-basics}). So $$|y| < r$$ exactly when $$y^2 < r^2$$, which by :ref{#square-inequality}
(with $$c = r^2$$ and $$\sqrt{c} = r$$) happens exactly when $$-r < y < r$$. Adding $$a$$ throughout
gives $$a - r < x < a + r$$.

Part 2 works the same way, with the second part of :ref{#square-inequality}.

:::

:::example[Within a distance]

Solve $$|x - 3| < 2$$: the numbers within $$2$$ of $$3$$. By :ref{#abs-inequality}, $$1 < x < 5$$,
the interval $$(1, 5)$$.

::number-line{from=0 to=6 points="3" intervals="(1, 5)"}

:::

:::example[Further than a distance]

Solve $$|2x + 1| \ge 5$$.

The same reasoning works for $$\ge$$, with the endpoints now included: $$2x + 1 \le -5$$ or
$$2x + 1 \ge 5$$. The first gives $$x \le -3$$ and the second $$x \ge 2$$. So the solutions are
$$(-\infty, -3] \cup [2, \infty)$$.

:::

## Exercises

:::::accordion[Exercises on solving inequalities, with solutions]

::::exercise{#ex-inequalities-intervals}

Write each set as an interval or a union of intervals: the $$x$$ with $$-1 \le x < 4$$, the $$x$$
with $$x > 2$$, and the $$x$$ with $$x \le 0$$ or $$x > 3$$. Is $$4$$ in the first one?

:::solution

By :ref{#interval}: $$[-1, 4)$$, $$(2, \infty)$$ and $$(-\infty, 0] \cup (3, \infty)$$.

The number $$4$$ is not in $$[-1, 4)$$: the round bracket at $$4$$ leaves it out, matching the
strict inequality $$x < 4$$.

:::

::::

::::exercise{#ex-inequalities-linear}

Solve $$3 - 4x < 15$$, $$2(x - 1) \ge 5x + 7$$ and $$1 \le 3 - 2x < 9$$, writing each answer as an
interval.

:::solution

Using :ref{#inequality-steps}:

- Subtracting $$3$$, $$-4x < 12$$. Dividing by $$-4$$ reverses it: $$x > -3$$, the interval
  $$(-3, \infty)$$.
- Expanding, $$2x - 2 \ge 5x + 7$$. Subtracting $$2x$$ and $$7$$, $$-9 \ge 3x$$, so $$x \le -3$$:
  $$(-\infty, -3]$$.
- Subtracting $$3$$ from all three parts, $$-2 \le -2x < 6$$. Dividing by $$-2$$ reverses both
  inequalities: $$1 \ge x > -3$$, that is, $$-3 < x \le 1$$: $$(-3, 1]$$.

:::

::::

::::exercise{#ex-inequalities-lost-half}

To solve $$x(x + 5) \ge 0$$, someone argues: "both factors must be at least $$0$$, so $$x \ge 0$$."
Which solutions does this miss? Solve the inequality properly.

:::solution

A product can also be positive when both factors are negative (:ref{#product-sign}). The argument
misses those $$x$$.

The factors are zero at $$x = 0$$ and $$x = -5$$:

|              | $$x < -5$$ | $$-5 < x < 0$$ | $$x > 0$$ |
| ------------ | ---------- | -------------- | --------- |
| $$x$$        | $$-$$      | $$-$$          | $$+$$     |
| $$x + 5$$    | $$-$$      | $$+$$          | $$+$$     |
| $$x(x + 5)$$ | $$+$$      | $$-$$          | $$+$$     |

The product is positive on the outer pieces and $$0$$ at $$-5$$ and $$0$$. So the solutions are
$$(-\infty, -5] \cup [0, \infty)$$. The argument missed $$(-\infty, -5]$$; for example $$x = -6$$
gives $$(-6)(-1) = 6 \ge 0$$.

:::

::::

::::exercise{#ex-inequalities-quotients}

Solve $$\frac{x - 4}{x + 1} \le 0$$ and $$\frac{3}{x - 2} > 1$$.

:::solution

- The top is zero at $$4$$ and the bottom at $$-1$$. The quotient is negative when they have
  opposite signs (:ref{#product-sign}), which happens for $$-1 < x < 4$$. It is $$0$$ at $$x = 4$$
  and undefined at $$x = -1$$. So the solutions are $$(-1, 4]$$.
- Subtracting $$1$$ and combining, $$\frac{3 - (x - 2)}{x - 2} = \frac{5 - x}{x - 2} > 0$$. The top
  is positive for $$x < 5$$ and the bottom for $$x > 2$$. They have the same sign exactly when
  $$2 < x < 5$$, and for $$x < 2$$ or $$x > 5$$ the signs differ. So the solutions are $$(2, 5)$$.

**Check** the second with $$x = 3$$: $$\frac{3}{1} = 3 > 1$$, true. With $$x = 6$$:
$$\frac{3}{4} > 1$$, false.

:::

::::

::::exercise{#ex-inequalities-squares}

Solve $$4x^2 \le 25$$ and $$(x + 3)^2 > 1$$.

:::solution

- Dividing by $$4$$, $$x^2 \le \frac{25}{4}$$. By :ref{#square-inequality}, with the endpoints now
  included, $$-\frac{5}{2} \le x \le \frac{5}{2}$$: the interval
  $$\left[-\frac{5}{2}, \frac{5}{2}\right]$$.
- By :ref{#square-inequality} with $$x + 3$$ in place of $$x$$: $$x + 3 < -1$$ or $$x + 3 > 1$$. So
  $$x < -4$$ or $$x > -2$$: $$(-\infty, -4) \cup (-2, \infty)$$.

:::

::::

::::exercise{#ex-inequalities-abs}

Solve $$|x - 4| \le 0.5$$, $$|x + 1| > 3$$ and $$|x| < -1$$.

:::solution

By :ref{#abs-inequality}:

- The numbers within $$0.5$$ of $$4$$, endpoints included: $$[3.5, 4.5]$$.
- The numbers further than $$3$$ from $$-1$$: $$x < -4$$ or $$x > 2$$, that is,
  $$(-\infty, -4) \cup (2, \infty)$$.
- An absolute value is never negative, so it is never less than $$-1$$. There is no solution.

:::

::::

::::exercise{#ex-inequalities-near-two}

Prove that if $$|x - 2| < 1$$, then $$\left|x^2 - 4\right| < 5$$.

:::solution

By :ref{#abs-inequality}, $$|x - 2| < 1$$ means $$1 < x < 3$$. Adding $$2$$, $$3 < x + 2 < 5$$, so
$$x + 2$$ is positive and $$|x + 2| < 5$$.

Now factor: $$x^2 - 4 = (x - 2)(x + 2)$$, so $$\left|x^2 - 4\right| = |x - 2|\,|x + 2|$$
(:ref{#abs-product}). Both absolute values are at least $$0$$, with $$|x - 2| < 1$$ and
$$|x + 2| < 5$$. Multiplying these (part 2 of :ref{#combine-inequalities}),

```math
\left|x^2 - 4\right| < 1 \cdot 5 = 5
```

:::
