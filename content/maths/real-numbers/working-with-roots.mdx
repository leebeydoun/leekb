Work out $$\frac{1}{\sqrt{2}}$$ by hand and you'll be dividing $$1$$ by $$1.41421\ldots$$, which is
slow and fiddly. Write it as $$\frac{\sqrt{2}}{2}$$ instead and it's half of $$1.41421\ldots$$,
which you can do in your head. One identity does almost all the work in rewrites like this:
$$(x + y)(x - y) = x^2 - y^2$$. In this guide we'll use it to move square roots out of fractions and
to divide numbers like $$3 + 2\sqrt{2}$$. Then we'll turn to equations with an unknown under a
square root, where squaring both sides can add false solutions.

## Conjugates

A sum like $$3 + \sqrt{2}$$ is awkward, because the root is stuck to the $$3$$. Squaring doesn't get
rid of it: $$\left(3 + \sqrt{2}\right)^2 = 11 + 6\sqrt{2}$$. The trick is to multiply by the same
sum with the sign in the middle flipped. The two cross terms, $$+3\sqrt{2}$$ and $$-3\sqrt{2}$$,
then cancel, and all that is left is $$3^2$$ minus $$\left(\sqrt{2}\right)^2$$, which is $$9 - 2$$,
with no root in sight.

The numbers $$p + \sqrt{q}$$ and $$p - \sqrt{q}$$ are called **conjugates** of each other. Their
product has no square root left in it, by the difference of two squares
(:ref{#numbers/square-formulas}):

```math
\left(p + \sqrt{q}\right)\left(p - \sqrt{q}\right) = p^2 - \left(\sqrt{q}\right)^2 = p^2 - q
```

For example, $$\left(3 + \sqrt{2}\right)\left(3 - \sqrt{2}\right) = 9 - 2 = 7$$. The same works with
two roots: $$\left(\sqrt{a} + \sqrt{b}\right)\left(\sqrt{a} - \sqrt{b}\right) = a - b$$.

## Rationalising the denominator

Dividing by a number like $$\sqrt{3}$$, which is about $$1.732$$, is awkward, while dividing by
$$3$$ is not. A fraction keeps its value when its top and bottom are multiplied by the same non-zero
number (:ref{#numbers/cancel-product}). So you can pick a multiplier that turns the bottom into a
rational number and moves the root up to the top, where it does no harm.

Rewriting a fraction in this way, so that its bottom is a rational number, is called **rationalising
the denominator**.

When the bottom is a single root, multiply by that root:

```math
\frac{1}{\sqrt{3}} = \frac{1 \cdot \sqrt{3}}{\sqrt{3} \cdot \sqrt{3}} = \frac{\sqrt{3}}{3},
\qquad
\frac{10}{\sqrt{5}} = \frac{10\sqrt{5}}{5} = 2\sqrt{5}
```

When the bottom is a sum or difference, multiply by its conjugate.

:::example[A conjugate on the bottom]

Rationalise the denominator of $$\frac{7}{3 - \sqrt{2}}$$.

Multiply the top and the bottom by the conjugate $$3 + \sqrt{2}$$:

```math
\frac{7}{3 - \sqrt{2}}
= \frac{7\left(3 + \sqrt{2}\right)}{\left(3 - \sqrt{2}\right)\left(3 + \sqrt{2}\right)}
= \frac{7\left(3 + \sqrt{2}\right)}{9 - 2}
= 3 + \sqrt{2}
```

**Check:** $$\left(3 + \sqrt{2}\right)\left(3 - \sqrt{2}\right) = 7$$, so $$3 + \sqrt{2}$$ is $$7$$
divided by $$3 - \sqrt{2}$$.

:::

:::example[Two roots on the bottom]

Rationalise the denominator of $$\frac{1}{\sqrt{6} - \sqrt{2}}$$. Its conjugate is
$$\sqrt{6} + \sqrt{2}$$:

```math
\frac{1}{\sqrt{6} - \sqrt{2}}
= \frac{\sqrt{6} + \sqrt{2}}{\left(\sqrt{6} - \sqrt{2}\right)\left(\sqrt{6} + \sqrt{2}\right)}
= \frac{\sqrt{6} + \sqrt{2}}{6 - 2}
= \frac{\sqrt{6} + \sqrt{2}}{4}
```

:::

Rationalising is not always an improvement. It is useful when the result is simpler, or easier to
compare or estimate, but a root on the bottom is not an error.

## Rationalising the numerator

The same trick can move a root from the top to the bottom, which is called **rationalising the
numerator**. That is useful when the top is a difference of two nearly equal roots. Such a
difference is hard to judge, because both roots are close to the same number and almost all of each
cancels. After the trick the roots are added on the bottom instead, and a sum of positive numbers is
at least as big as each of its parts, which gives a clear bound.

:::example[How far apart are √101 and √100?]

Multiply the difference by $$\frac{\sqrt{101} + \sqrt{100}}{\sqrt{101} + \sqrt{100}}$$, which is
$$1$$, so the value doesn't change. The top then becomes a difference of two squares:

```math
\sqrt{101} - \sqrt{100}
= \frac{\left(\sqrt{101} - \sqrt{100}\right)\left(\sqrt{101} + \sqrt{100}\right)}
       {\sqrt{101} + \sqrt{100}}
= \frac{101 - 100}{\sqrt{101} + 10}
= \frac{1}{\sqrt{101} + 10}
```

Since $$\sqrt{101} > 10$$, the bottom is more than $$20$$, so the difference is less than
$$\frac{1}{20} = 0.05$$. The original form, a difference of two numbers near $$10$$, hides how small
it is.

:::

In the same way, $$\sqrt{n + 1} - \sqrt{n} = \frac{1}{\sqrt{n + 1} + \sqrt{n}}$$ for every
$$n \ge 0$$, which shows that the gaps between the square roots of consecutive whole numbers shrink
as the numbers grow.

## Numbers of the form a + b√2

Think of $$\sqrt{2}$$ as one new ingredient added to the rational numbers. A number like
$$3 + 2\sqrt{2}$$ has a rational part, $$3$$, and a rational amount of $$\sqrt{2}$$, here $$2$$.
Adding or subtracting two such numbers combines the matching parts. Multiplying works too, because
$$\sqrt{2}$$ times $$\sqrt{2}$$ is $$2$$, which falls back into the rational part. Dividing is
harder, and conjugates are what make it work.

The two parts of such a number are fixed. Since $$\sqrt{2}$$ is irrational, no non-zero rational
amount of it is a rational number, so the rational part and the amount of $$\sqrt{2}$$ can't be
traded for each other.

Adding, subtracting and multiplying numbers like $$3 + 2\sqrt{2}$$ gives numbers of the same kind:

```math
\left(3 + 2\sqrt{2}\right)\left(1 - \sqrt{2}\right)
= 3 - 3\sqrt{2} + 2\sqrt{2} - 2 \cdot 2
= -1 - \sqrt{2}
```

Conjugates show that dividing does too.

:::proposition[Numbers of the form a + b√2]{#root-two-form}

Let $$a$$, $$b$$, $$c$$ and $$d$$ be rational numbers.

1. The sum, difference and product of $$a + b\sqrt{2}$$ and $$c + d\sqrt{2}$$ can each be written as
   $$e + f\sqrt{2}$$ with $$e$$ and $$f$$ rational.
2. If $$a + b\sqrt{2} \neq 0$$, its inverse can also be written in this form:

   ```math
   \frac{1}{a + b\sqrt{2}} = \frac{a}{a^2 - 2b^2} - \frac{b}{a^2 - 2b^2}\sqrt{2}
   ```

3. A number can be written in this form in only one way: if $$a + b\sqrt{2} = c + d\sqrt{2}$$, then
   $$a = c$$ and $$b = d$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Conjugate_(square_roots)#Properties"}

**Part 1.** Collecting terms, the sum is $$(a + c) + (b + d)\sqrt{2}$$ and the difference is
$$(a - c) + (b - d)\sqrt{2}$$. Expanding the product, using $$\sqrt{2}\sqrt{2} = 2$$,

```math
\left(a + b\sqrt{2}\right)\left(c + d\sqrt{2}\right) = (ac + 2bd) + (ad + bc)\sqrt{2}
```

In each case the numbers in front are rational, because sums and products of rational numbers are
rational.

**Part 2.** First, $$a^2 - 2b^2 \neq 0$$. If $$b = 0$$, then $$a \neq 0$$, since the number isn't
$$0$$, so $$a^2 - 2b^2 = a^2$$ is not $$0$$. If $$b \neq 0$$ and $$a^2 = 2b^2$$, then
$$\left(\frac{a}{b}\right)^2 = 2$$, so a rational number would square to $$2$$, which is impossible
(:ref{#numbers/sqrt-two}).

Now multiply top and bottom by the conjugate $$a - b\sqrt{2}$$. It is not $$0$$, since its product
with $$a + b\sqrt{2}$$ is $$a^2 - 2b^2$$, which is not $$0$$. So

```math
\frac{1}{a + b\sqrt{2}}
= \frac{a - b\sqrt{2}}{\left(a + b\sqrt{2}\right)\left(a - b\sqrt{2}\right)}
= \frac{a - b\sqrt{2}}{a^2 - 2b^2}
```

which is the form claimed, with rational numbers in front.

**Part 3.** Suppose $$a + b\sqrt{2} = c + d\sqrt{2}$$ but $$b \neq d$$. Rearranging,
$$\sqrt{2} = \frac{a - c}{d - b}$$, a quotient of rational numbers, so $$\sqrt{2}$$ would be
rational. That is impossible, so $$b = d$$, and then $$a = c$$ too.

:::

For example, with $$a = 3$$ and $$b = 2$$, $$a^2 - 2b^2 = 1$$, so
$$\frac{1}{3 + 2\sqrt{2}} = 3 - 2\sqrt{2}$$. The same holds with $$\sqrt{2}$$ replaced by
$$\sqrt{3}$$, or by any other square root of a rational number that is itself irrational, and is
proved the same way.

## Equations with square roots

To solve an equation with the unknown under a square root, the usual move is to get the root on its
own and square both sides. But squaring forgets signs: $$3$$ and $$-3$$ both square to $$9$$. So
squaring can let in false solutions, values that make the two sides opposites rather than equal. The
[Linear equations](../linear-equations/equations.mdx) chapter made the same point. The proposition
below says exactly what squaring does and doesn't do.

:::proposition[Squaring both sides]{#squaring-sides}

If $$A = B$$, then $$A^2 = B^2$$. If $$A \ge 0$$ and $$B \ge 0$$, the reverse holds too:
$$A^2 = B^2$$ gives $$A = B$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Extraneous_and_missing_solutions#Other_operations"}

If $$A = B$$, then $$A^2 = A \cdot A = B \cdot B = B^2$$. For the reverse, if $$A^2 = B^2$$ and both
are not negative, then $$A = B$$ by :ref{#equal-squares}.

:::

So squaring never loses a solution, but it can gain some: any value that makes the two sides
opposites, $$A = -B$$, also makes the squares equal. The fix is to **check every answer in the
original equation**.

:::example[A false solution]

Solve $$\sqrt{x + 7} = x + 1$$.

Squaring both sides, $$x + 7 = (x + 1)^2 = x^2 + 2x + 1$$, so $$x^2 + x - 6 = 0$$. This factors as
$$(x + 3)(x - 2) = 0$$, so by :ref{#numbers/zero-product}, $$x = -3$$ or $$x = 2$$.

**Check** each in the original equation:

- $$x = 2$$: the left side is $$\sqrt{9} = 3$$ and the right side is $$2 + 1 = 3$$. A solution.
- $$x = -3$$: the left side is $$\sqrt{4} = 2$$, but the right side is $$-3 + 1 = -2$$. Not a
  solution: it solves $$\sqrt{x + 7} = -(x + 1)$$ instead, which squares to the same thing.

So the only solution is $$x = 2$$.

:::

:::example[Two roots]

Solve $$\sqrt{x + 5} - \sqrt{x} = 1$$.

Get one root on its own first: $$\sqrt{x + 5} = 1 + \sqrt{x}$$. Squaring,
$$x + 5 = 1 + 2\sqrt{x} + x$$, so $$2\sqrt{x} = 4$$ and $$\sqrt{x} = 2$$. Squaring again, $$x = 4$$.

**Check:** $$\sqrt{9} - \sqrt{4} = 3 - 2 = 1$$. So $$x = 4$$.

:::

Sometimes there is no solution at all, and it can be seen without squaring. The equation
$$\sqrt{x} + 3 = 1$$ would need $$\sqrt{x} = -2$$, but a square root is never negative.

## Exercises

:::::accordion[Exercises on working with square roots, with solutions]

::::exercise{#ex-working-roots-conjugates}

Work out $$\left(5 + \sqrt{3}\right)\left(5 - \sqrt{3}\right)$$,
$$\left(\sqrt{11} - \sqrt{7}\right)\left(\sqrt{11} + \sqrt{7}\right)$$ and
$$\left(2\sqrt{5} + 3\right)\left(2\sqrt{5} - 3\right)$$.

:::solution

Each is a difference of two squares (:ref{#numbers/square-formulas}):

- $$5^2 - 3 = 25 - 3 = 22$$.
- $$11 - 7 = 4$$.
- $$\left(2\sqrt{5}\right)^2 - 3^2 = 20 - 9 = 11$$.

:::

::::

::::exercise{#ex-working-roots-rationalise}

Rationalise the denominators of $$\frac{3}{\sqrt{6}}$$, $$\frac{2}{\sqrt{5} - 1}$$ and
$$\frac{\sqrt{2}}{\sqrt{2} + 1}$$.

:::solution

- Multiply top and bottom by $$\sqrt{6}$$: $$\frac{3\sqrt{6}}{6} = \frac{\sqrt{6}}{2}$$.
- Multiply by the conjugate $$\sqrt{5} + 1$$. The bottom becomes $$5 - 1 = 4$$, so the fraction is
  $$\frac{2\left(\sqrt{5} + 1\right)}{4} = \frac{\sqrt{5} + 1}{2}$$.
- Multiply by the conjugate $$\sqrt{2} - 1$$. The bottom becomes $$2 - 1 = 1$$, so the fraction is
  $$\sqrt{2}\left(\sqrt{2} - 1\right) = 2 - \sqrt{2}$$.

:::

::::

::::exercise{#ex-working-roots-numerator}

Without a calculator, show that $$\sqrt{50} - 7$$ is less than $$\frac{1}{14}$$.

:::solution

Since $$7 = \sqrt{49}$$, rationalise the numerator:

```math
\sqrt{50} - \sqrt{49} = \frac{50 - 49}{\sqrt{50} + \sqrt{49}} = \frac{1}{\sqrt{50} + 7}
```

Since $$\sqrt{50} > \sqrt{49} = 7$$ (:ref{#root-order}), the bottom is more than $$14$$. By
:ref{#reciprocal-order}, the fraction is less than $$\frac{1}{14}$$.

:::

::::

::::exercise{#ex-working-roots-form}

Write $$\left(3 - \sqrt{2}\right)^2$$, $$\left(1 + \sqrt{2}\right)^3$$ and
$$\frac{1}{5 - 3\sqrt{2}}$$ in the form $$a + b\sqrt{2}$$ with $$a$$ and $$b$$ rational.

:::solution

- $$\left(3 - \sqrt{2}\right)^2 = 9 - 6\sqrt{2} + 2 = 11 - 6\sqrt{2}$$.
- $$\left(1 + \sqrt{2}\right)^2 = 3 + 2\sqrt{2}$$, so
  $$\left(1 + \sqrt{2}\right)^3 = \left(3 + 2\sqrt{2}\right)\left(1 + \sqrt{2}\right) = 3 + 3\sqrt{2} + 2\sqrt{2} + 4 = 7 + 5\sqrt{2}$$.
- By part 2 of :ref{#root-two-form} with $$a = 5$$ and $$b = -3$$, $$a^2 - 2b^2 = 25 - 18 = 7$$, so
  $$\frac{1}{5 - 3\sqrt{2}} = \frac{5}{7} + \frac{3}{7}\sqrt{2}$$.

:::

::::

::::exercise{#ex-working-roots-unknown-factor}

Find rational numbers $$a$$ and $$b$$ with
$$\left(a + b\sqrt{2}\right)\left(1 + \sqrt{2}\right) = 5 + 3\sqrt{2}$$. Why is there only one
answer?

:::solution

Divide both sides by $$1 + \sqrt{2}$$, which means multiplying by its inverse. By
:ref{#root-two-form}, $$\frac{1}{1 + \sqrt{2}} = \frac{1 - \sqrt{2}}{1 - 2} = -1 + \sqrt{2}$$. So

```math
a + b\sqrt{2} = \left(5 + 3\sqrt{2}\right)\left(-1 + \sqrt{2}\right) = -5 + 5\sqrt{2} - 3\sqrt{2} + 6
= 1 + 2\sqrt{2}
```

So $$a = 1$$ and $$b = 2$$. **Check:**
$$\left(1 + 2\sqrt{2}\right)\left(1 + \sqrt{2}\right) = 1 + \sqrt{2} + 2\sqrt{2} + 4 = 5 + 3\sqrt{2}$$.

There is only one answer because the number $$a + b\sqrt{2}$$ is fixed: it must equal
$$\frac{5 + 3\sqrt{2}}{1 + \sqrt{2}}$$. By part 3 of :ref{#root-two-form}, a number can be written
in this form in only one way.

:::

::::

::::exercise{#ex-working-roots-equation}

Solve $$\sqrt{2x + 3} = x$$.

:::solution

Squaring both sides, $$2x + 3 = x^2$$, so $$x^2 - 2x - 3 = 0$$, which factors as
$$(x - 3)(x + 1) = 0$$. So $$x = 3$$ or $$x = -1$$.

Squaring can add false solutions (:ref{#squaring-sides}), so **check** each one:

- $$x = 3$$: $$\sqrt{9} = 3$$. A solution.
- $$x = -1$$: $$\sqrt{1} = 1$$, but the right side is $$-1$$. Not a solution.

So the only solution is $$x = 3$$.

:::

::::

::::exercise{#ex-working-roots-two-roots}

Solve $$\sqrt{x + 3} + \sqrt{x} = 3$$.

:::solution

Get one root on its own: $$\sqrt{x + 3} = 3 - \sqrt{x}$$. Squaring, $$x + 3 = 9 - 6\sqrt{x} + x$$,
so $$6\sqrt{x} = 6$$ and $$\sqrt{x} = 1$$. Squaring again, $$x = 1$$.

**Check:** $$\sqrt{4} + \sqrt{1} = 2 + 1 = 3$$. So $$x = 1$$.

:::
