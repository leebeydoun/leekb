The rational numbers are enough for counting, sharing and measuring with a ruler, but not for
geometry: the diagonal of a $$1$$ by $$1$$ square has a length whose square is $$2$$, and no
fraction squares to $$2$$. The **real numbers** fill in every gap in the number line, so that
lengths like this, and roots and powers of every kind, have a number to name them.

This guide sets out what real numbers are and the rules they obey, then puts those rules to work.
The two rules for positive numbers turn into the rules for inequalities; the existence of square
roots leads to the rules for $$\sqrt{\ }$$ and the inequality between the average of two numbers and
their geometric mean; and roots give a meaning to powers like $$8^{2/3}$$. Along the way it
introduces absolute value and distance, and shows how to solve inequalities.

It builds on the [Numbers](../numbers/introduction.mdx) guide, whose results carry over to the real
numbers unchanged, and links back to it throughout.

**Definitions**

| Term                                    | Meaning                                                                     |
| --------------------------------------- | --------------------------------------------------------------------------- |
| :ref[Real numbers]{#real}               | The numbers marking every point of the number line; every decimal names one |
| :ref[Negative]{#negative}               | $$a < 0$$ when $$-a$$ is positive                                           |
| :ref[Order]{#real-order}                | $$a < b$$ when $$b - a$$ is positive                                        |
| :ref[Square root]{#square-root}         | For $$a \ge 0$$, $$\sqrt{a}$$ is the $$x \ge 0$$ with $$x^2 = a$$           |
| :ref[Absolute value]{#absolute-value}   | $$\lvert x \rvert = x$$ for $$x \ge 0$$, and $$-x$$ for $$x < 0$$           |
| :ref[Distance]{#distance}               | The distance between $$a$$ and $$b$$ is $$\lvert a - b \rvert$$             |
| :ref[nth root]{#nth-root}               | For $$a \ge 0$$, $$\sqrt[n]{a}$$ is the $$r \ge 0$$ with $$r^n = a$$        |
| :ref[Fractional power]{#rational-power} | For $$a > 0$$, $$a^{m/n} = \left(\sqrt[n]{a}\right)^m$$                     |
| :ref[Intervals]{#interval}              | $$(a, b)$$, $$[a, b]$$, $$[a, \infty)$$ and so on: stretches of the line    |

**Signs and order**

| Rule                                                   | Statement                                                                              |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| :ref[One is positive]{#one-positive}                   | $$1 > 0$$                                                                              |
| :ref[Signs of products]{#sign-rules}                   | Same signs give a positive product, opposite signs a negative one                      |
| :ref[Squares]{#squares-positive}                       | $$a^2 \ge 0$$, and $$a^2 + b^2 = 0$$ only when $$a = b = 0$$                           |
| :ref[Signs of inverses]{#inverse-sign}                 | $$\frac{1}{a}$$ has the same sign as $$a$$, and so do quotients (:ref{#quotient-sign}) |
| :ref[Rules for inequalities]{#inequality-rules}        | Chain, add to both sides; multiplying by a negative number reverses                    |
| :ref[Combining inequalities]{#combine-inequalities}    | Add inequalities; multiply them when everything is non-negative                        |
| :ref[Reciprocals]{#reciprocal-order}                   | $$0 < a < b$$ gives $$\frac{1}{b} < \frac{1}{a}$$                                      |
| :ref[Powers]{#power-order}                             | $$0 \le a < b$$ gives $$a^n < b^n$$, and backwards (:ref{#power-order-converse})       |
| :ref[Cross-multiplying]{#cross-multiplying-inequality} | With $$b, d > 0$$: $$\frac{a}{b} < \frac{c}{d}$$ exactly when $$ad < bc$$              |
| :ref[Mediant]{#mediant}                                | $$\frac{a + c}{b + d}$$ lies between $$\frac{a}{b}$$ and $$\frac{c}{d}$$               |
| :ref[Average]{#between}                                | $$\frac{a + b}{2}$$ lies between $$a$$ and $$b$$                                       |
| :ref[0.999… is 1]{#point-nine}                         | The decimal $$0.999\ldots$$ stands for $$1$$                                           |
| :ref[Two squares]{#two-squares}                        | $$a^2 + b^2 \ge 2ab$$, with equality only when $$a = b$$                               |

**Square roots**

| Rule                                                 | Statement                                                                                             |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| :ref[Solving x² = a]{#square-root-count}             | Two solutions $$\pm\sqrt{a}$$ for $$a > 0$$; one for $$a = 0$$; none for $$a < 0$$                    |
| :ref[Equal squares]{#equal-squares}                  | $$x^2 = y^2$$ means $$x = \pm y$$; for $$x, y \ge 0$$ it means $$x = y$$                              |
| :ref[Products and quotients]{#root-product}          | $$\sqrt{ab} = \sqrt{a}\sqrt{b}$$ and $$\sqrt{a/b} = \sqrt{a}/\sqrt{b}$$                               |
| :ref[Roots keep order]{#root-order}                  | $$0 \le a < b$$ gives $$\sqrt{a} < \sqrt{b}$$                                                         |
| :ref[Rational plus irrational]{#rational-irrational} | $$r + x$$ and (for $$r \neq 0$$) $$rx$$ are irrational                                                |
| :ref[AM–GM]{#am-gm}                                  | $$\frac{a + b}{2} \ge \sqrt{ab}$$ for $$a, b \ge 0$$, equal only when $$a = b$$                       |
| :ref[Numbers a + b√2]{#root-two-form}                | Closed under the four operations, with $$\frac{1}{a + b\sqrt{2}} = \frac{a - b\sqrt{2}}{a^2 - 2b^2}$$ |
| :ref[Squaring both sides]{#squaring-sides}           | Keeps every solution but can add false ones; safe when both sides are $$\ge 0$$                       |

**Absolute value**

| Rule                                            | Statement                                                                                           |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| :ref[Basic properties]{#abs-basics}             | $$\lvert x \rvert \ge 0$$, $$\lvert -x \rvert = \lvert x \rvert$$, $$\lvert x \rvert = \sqrt{x^2}$$ |
| :ref[Products]{#abs-product}                    | $$\lvert ab \rvert = \lvert a \rvert\,\lvert b \rvert$$                                             |
| :ref[Triangle inequality]{#triangle-inequality} | $$\lvert a + b \rvert \le \lvert a \rvert + \lvert b \rvert$$                                       |
| :ref[Distances]{#distance-triangle}             | $$\lvert a - c \rvert \le \lvert a - b \rvert + \lvert b - c \rvert$$                               |
| :ref[Absolute value equations]{#abs-equation}   | For $$c \ge 0$$: $$A = c$$ or $$A = -c$$; for $$c < 0$$: none                                       |

**Roots and powers**

| Rule                                             | Statement                                                                   |
| ------------------------------------------------ | --------------------------------------------------------------------------- |
| :ref[Only one positive root]{#nth-root-unique}   | A positive number has exactly one positive $$n$$-th root                    |
| :ref[Roots of products]{#nth-root-product}       | $$\sqrt[n]{ab} = \sqrt[n]{a}\sqrt[n]{b}$$                                   |
| :ref[Solving xⁿ = a]{#power-equation}            | Odd $$n$$: one solution. Even $$n$$: two, one or none, by the sign of $$a$$ |
| :ref[Well defined]{#rational-power-well-defined} | $$a^{m/n}$$ doesn't depend on how $$\frac{m}{n}$$ is written                |
| :ref[Rules for powers]{#rational-power-laws}     | $$a^p a^q = a^{p+q}$$, $$(a^p)^q = a^{pq}$$, $$(ab)^p = a^p b^p$$           |

**Solving inequalities**

| Rule                                   | Statement                                                                       |
| -------------------------------------- | ------------------------------------------------------------------------------- |
| :ref[Safe steps]{#inequality-steps}    | Add to both sides; multiply by a positive number, or a negative one and reverse |
| :ref[Signs of products]{#product-sign} | $$ab > 0$$ when the signs match, $$ab < 0$$ when they differ                    |
| :ref[Squares]{#square-inequality}      | For $$c > 0$$: $$x^2 < c$$ exactly when $$-\sqrt{c} < x < \sqrt{c}$$            |
| :ref[Absolute values]{#abs-inequality} | For $$r > 0$$: $$\lvert x - a \rvert < r$$ exactly when $$a - r < x < a + r$$   |
