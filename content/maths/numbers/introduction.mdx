Most people learn that a negative times a negative is positive long before anyone tells them why.
The same goes for the rule that you can't divide by zero, and for dividing by a fraction by flipping
it over. In this chapter we'll find out why rules like these hold, by building up the numbers one
step at a time.

Each new kind of number fills a gap left by the one before:

- The counting numbers $$1, 2, 3, \dots$$ can always be added, but not always subtracted: $$3 - 5$$
  has no answer among them. Adding zero and the negative numbers gives the
  [integers](./integers.mdx), where subtraction always works.
- The integers can always be multiplied, but not always divided: $$3 \div 5$$ has no answer among
  them. Adding fractions gives the [rational numbers](./rational-numbers.mdx), where every division
  works, except division by zero.
- Even the rational numbers have gaps.
  [No fraction squares to exactly $$2$$](./irrational-numbers.mdx), which is a first hint that more
  numbers are still to come.

Along the way the approach stays the same. Each page takes a few basic rules as given, such as
$$a + b = b + a$$, and shows that everything else follows from them. Once a rule has been proved, it
holds in every case, not only in the examples you happened to check.

These proofs use arguments such as proof by contradiction and proof by induction. The
[Basic proofs](../basic-proofs/introduction.mdx) chapter explains them, and is worth reading first.

**Addition** (for any integers $$a$$, $$b$$, $$c$$; the first five are assumed)

| Rule                                        | Statement                                              |
| ------------------------------------------- | ------------------------------------------------------ |
| :ref[Commutativity]{#addition-rules}        | $$a + b = b + a$$                                      |
| :ref[Associativity]{#addition-rules}        | $$(a + b) + c = a + (b + c)$$                          |
| :ref[Adding zero]{#addition-rules}          | $$a + 0 = 0 + a = a$$                                  |
| :ref[Adding an opposite]{#addition-rules}   | $$a + (-a) = -a + a = 0$$                              |
| :ref[Positive sums]{#addition-rules}        | positive + positive is positive                        |
| :ref{#opposite-unique}                      | if $$a + b = 0$$, then $$b = -a$$ and $$a = -b$$       |
| :ref[Double opposite]{#double-opposite}     | $$-(-a) = a$$                                          |
| :ref[Opposite of a sum]{#opposite-sum}      | $$-(a + b) = -a - b$$, and $$-(a - b) = b - a$$        |
| :ref[Negative sums]{#negative-sum}          | negative + negative is negative                        |
| :ref[Rearranging]{#rearranging}             | if $$a + b = c$$, then $$a = c - b$$ and $$b = c - a$$ |
| :ref[Order]{#order-rules}                   | exactly one of $$a < b$$, $$a = b$$, $$a > b$$         |
| :ref[Chaining]{#order-rules}                | if $$a < b$$ and $$b < c$$, then $$a < c$$             |
| :ref[Adding to an inequality]{#order-rules} | if $$a < b$$, then $$a + c < b + c$$                   |

**Multiplication** (for any integers $$a$$, $$b$$, $$c$$; the first five are assumed)

| Rule                                            | Statement                                                          |
| ----------------------------------------------- | ------------------------------------------------------------------ |
| :ref[Commutativity]{#multiplication-rules}      | $$ab = ba$$                                                        |
| :ref[Associativity]{#multiplication-rules}      | $$(ab)c = a(bc)$$                                                  |
| :ref[Multiplying by one]{#multiplication-rules} | $$1 \cdot a = a$$                                                  |
| :ref[Distributivity]{#multiplication-rules}     | $$a(b + c) = ab + ac$$ and $$(b + c)a = ba + ca$$                  |
| :ref[Positive products]{#multiplication-rules}  | positive × positive is positive                                    |
| :ref{#zero-times}                               | $$0 \cdot a = 0$$                                                  |
| :ref{#minus-one}                                | $$(-1)a = -a$$                                                     |
| :ref{#minus-in-product}                         | $$-(ab) = (-a)b = a(-b)$$                                          |
| :ref{#two-minus}                                | $$(-a)(-b) = ab$$                                                  |
| Signs of products                               | an even number of minus signs gives a positive product             |
| :ref{#order-multiply}                           | if $$a < b$$: $$ac < bc$$ for $$c > 0$$, $$ac > bc$$ for $$c < 0$$ |
| :ref[Powers]{#power-rules}                      | $$a^m a^n = a^{m+n}$$, $$(a^m)^n = a^{mn}$$, $$(ab)^n = a^n b^n$$  |

**Algebraic identities**

| Rule                                           | Statement                                             |
| ---------------------------------------------- | ----------------------------------------------------- |
| :ref[Square of a sum]{#square-formulas}        | $$(a + b)^2 = a^2 + 2ab + b^2$$                       |
| :ref[Square of a difference]{#square-formulas} | $$(a - b)^2 = a^2 - 2ab + b^2$$                       |
| :ref[Difference of squares]{#square-formulas}  | $$(a + b)(a - b) = a^2 - b^2$$                        |
| Square of three terms                          | $$(a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2bc + 2ca$$ |
| :ref[Cube of a sum]{#cube-formulas}            | $$(a + b)^3 = a^3 + 3a^2 b + 3ab^2 + b^3$$            |
| :ref[Cube of a difference]{#cube-formulas}     | $$(a - b)^3 = a^3 - 3a^2 b + 3ab^2 - b^3$$            |
| :ref[Difference of cubes]{#cube-formulas}      | $$a^3 - b^3 = (a - b)(a^2 + ab + b^2)$$               |
| :ref[Sum of cubes]{#cube-formulas}             | $$a^3 + b^3 = (a + b)(a^2 - ab + b^2)$$               |

**Divisibility**

| Rule                             | Statement                                                                   |
| -------------------------------- | --------------------------------------------------------------------------- |
| :ref[Sums]{#parity-sums}         | even + even = even, even + odd = odd, odd + odd = even                      |
| :ref[Products]{#parity-products} | even × anything = even, odd × odd = odd                                     |
| :ref[Squares]{#squares-parity}   | $$a^2$$ is even exactly when $$a$$ is (:ref{#squares-parity-converse})      |
| Powers of −1                     | $$(-1)^n = 1$$ if $$n$$ is even, $$-1$$ if $$n$$ is odd                     |
| Always divides                   | $$1 \mid n$$, $$n \mid n$$ and $$d \mid 0$$                                 |
| :ref{#multiples}                 | if $$d \mid m$$ and $$d \mid n$$, then $$d \mid m \pm n$$ and $$d \mid mc$$ |
| :ref{#division-remainder}        | $$n = dq + r$$ with $$0 \le r < d$$, in exactly one way                     |
| :ref[Even or odd]{#even-or-odd}  | every integer is exactly one of the two                                     |

**Congruence** (with $$a \equiv b$$ and $$x \equiv y \pmod{d}$$)

| Rule                                     | Statement                                                           |
| ---------------------------------------- | ------------------------------------------------------------------- |
| :ref[Same remainder]{#same-remainder}    | $$a \equiv b$$ exactly when $$a$$ and $$b$$ have the same remainder |
| :ref[Reflexive]{#congruence-equality}    | $$a \equiv a \pmod{d}$$                                             |
| :ref[Symmetric]{#congruence-equality}    | if $$a \equiv b$$, then $$b \equiv a \pmod{d}$$                     |
| :ref[Transitive]{#congruence-equality}   | if $$a \equiv b$$ and $$b \equiv c$$, then $$a \equiv c \pmod{d}$$  |
| Divisible means $$\equiv 0$$             | $$n \equiv 0 \pmod{d}$$ exactly when $$d \mid n$$                   |
| :ref[Arithmetic]{#congruence-arithmetic} | $$a \pm x \equiv b \pm y$$ and $$ax \equiv by \pmod{d}$$            |
| :ref[Powers]{#congruence-powers}         | $$a^n \equiv b^n \pmod{d}$$                                         |
| :ref[No cancelling]{#no-cancel}          | $$ca \equiv cb$$ does not always give $$a \equiv b$$                |
| :ref[Squares and 3]{#squares-three}      | if $$3 \mid a^2$$, then $$3 \mid a$$                                |
| :ref[Digit sums]{#digit-sum-test}        | a number is congruent to its digit sum modulo $$9$$ and $$3$$       |

**Rational numbers** (for integers, with every denominator non-zero)

| Rule                                          | Statement                                                                          |
| --------------------------------------------- | ---------------------------------------------------------------------------------- |
| :ref[Cancelling]{#fraction-cancel}            | $$\frac{am}{an} = \frac{m}{n}$$ for $$a \neq 0$$                                   |
| :ref[Minus signs]{#fraction-signs}            | $$-\frac{m}{n} = \frac{-m}{n} = \frac{m}{-n}$$ and $$\frac{-m}{-n} = \frac{m}{n}$$ |
| Same denominator                              | $$\frac{m}{n} + \frac{r}{n} = \frac{m + r}{n}$$                                    |
| :ref[Lowest form exists]{#lowest-form-exists} | every positive rational number has a lowest form                                   |
| :ref[Positive + positive]{#positive-sum}      | is positive                                                                        |
| :ref[Powers]{#fraction-powers}                | $$\left(\frac{m}{n}\right)^k = \frac{m^k}{n^k}$$                                   |
| :ref[Comparing]{#compare-fractions}           | for $$n, s > 0$$: $$\frac{m}{n} < \frac{r}{s}$$ exactly when $$ms < rn$$           |
| Integer rules carry over                      | every rule for adding and multiplying integers holds for rational numbers          |
| Decimals                                      | rational numbers are exactly the decimals that stop or repeat                      |

**Inverses and division** (for rational numbers, with every denominator non-zero)

| Rule                                                 | Statement                                                                              |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------- |
| :ref[Inverse of a fraction]{#inverse-exists}         | $$\left(\frac{m}{n}\right)^{-1} = \frac{n}{m}$$ for $$m \neq 0$$; $$0$$ has no inverse |
| :ref{#inverse-unique}                                | if $$ab = 1$$, then $$b = a^{-1}$$                                                     |
| :ref[Zero product]{#zero-product}                    | if $$ab = 0$$, then $$a = 0$$ or $$b = 0$$                                             |
| Dividing by a fraction                               | $$\frac{a}{c/d} = a \cdot \frac{d}{c}$$                                                |
| :ref[Cross-multiplying]{#cross-multiplying-rational} | $$\frac{a}{b} = \frac{c}{d}$$ exactly when $$ad = bc$$                                 |
| :ref[Cancelling]{#cancel-product}                    | if $$ab = ac$$ and $$a \neq 0$$, then $$b = c$$; and $$\frac{ab}{ac} = \frac{b}{c}$$   |
| :ref{#adding-quotients}                              | $$\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}$$                                     |
| :ref[Sum of powers]{#sum-of-powers}                  | $$\frac{x^n - 1}{x - 1} = x^{n-1} + \cdots + x + 1$$                                   |
