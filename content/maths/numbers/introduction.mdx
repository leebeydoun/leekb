Everyone learns to add, multiply and work with fractions long before asking _why_ the rules are what
they are. Why is a negative times a negative positive? Why can't we divide by zero? Why do we flip a
fraction to divide by it? This guide answers questions like these by building up the numbers one
step at a time.

Each new kind of number fills a gap left by the one before:

- The counting numbers $$1, 2, 3, \dots$$ can always be added, but not always subtracted: $$3 - 5$$
  has no answer among them. Adding zero and the negative numbers gives the
  [integers](./integers.mdx), where subtraction always works.
- The integers can always be multiplied, but not always divided: $$3 \div 5$$ has no answer among
  them. Adding fractions gives the [rational numbers](./rational-numbers.mdx), where every division
  works, except division by zero.
- Even the rational numbers have gaps.
  [No fraction squares to exactly $$2$$](./irrational-numbers.mdx), which is a first hint that more
  numbers are still to come.

Along the way the approach stays the same. We take a few basic rules as given, such as
$$a + b = b + a$$, and show that everything else follows from them. Once a rule has been proved, it
can be trusted in every case, not just the examples we happened to check.

## How to read this guide

- **Definitions** say exactly what a word means. Everything later depends on them, so they are worth
  reading slowly.
- **Theorems** are the central results. **Propositions** are smaller results, a **lemma** is a tool
  for proving something else, and a **corollary** is a quick consequence of what came just before.
  Each is followed by its **proof**, which ends with ∎.
- **Examples** and **remarks** show the ideas at work or point out something worth noticing.
- Every statement is numbered by its page, so Definition 3.2 is the second statement on page 3.
  Hover over a link to one, like :ref{#even-odd}, to see it without leaving the page.
- Each page ends with the most common mistakes and a short summary. The exercises for the whole
  guide are on the [Exercises](./exercises.mdx) page.

| Rule                                         | Statement                                              |
| -------------------------------------------- | ------------------------------------------------------ |

| :ref[Associativity]{#addition-rules}         | $$(a + b) + c = a + (b + c)$$                          |
| :ref[Adding zero]{#addition-rules}           | $$a + 0 = 0 + a = a$$                                  |
| :ref[Adding an opposite]{#addition-rules}    | $$a + (-a) = -a + a = 0$$                              |
| :ref[Positive sums]{#addition-rules}         | positive + positive is positive                        |
| :ref[Opposites are unique]{#opposite-unique} | if $$a + b = 0$$, then $$b = -a$$ and $$a = -b$$       |
| :ref[Double opposite]{#double-opposite}      | $$-(-a) = a$$                                          |
| :ref[Opposite of a sum]{#opposite-sum}       | $$-(a + b) = -a - b$$, and $$-(a - b) = b - a$$        |
| :ref[Negative sums]{#negative-sum}           | negative + negative is negative                        |
| :ref[Rearranging]{#rearranging}              | if $$a + b = c$$, then $$a = c - b$$ and $$b = c - a$$ |
| :ref[Order]{#order-rules}                    | exactly one of $$a < b$$, $$a = b$$, $$a > b$$         |
| :ref[Chaining]{#order-rules}                 | if $$a < b$$ and $$b < c$$, then $$a < c$$             |
| :ref[Adding to an inequality]{#order-rules}  | if $$a < b$$, then $$a + c < b + c$$                   |

| Rule                                     | Statement                                                           |
| ---------------------------------------- | ------------------------------------------------------------------- |
| :ref[Same remainder]{#same-remainder}    | $$a \equiv b$$ exactly when $$a$$ and $$b$$ have the same remainder |
| :ref[Reflexive]{#congruence-equality}    | $$a \equiv a \pmod{d}$$                                             |
| :ref[Symmetric]{#congruence-equality}    | if $$a \equiv b$$, then $$b \equiv a \pmod{d}$$                     |

| Rule                                          | Statement                                                                          |
| --------------------------------------------- | ---------------------------------------------------------------------------------- |
| :ref[Cancelling]{#fraction-cancel}            | $$\frac{am}{an} = \frac{m}{n}$$ for $$a \neq 0$$                                   |
| :ref[Minus signs]{#fraction-signs}            | $$-\frac{m}{n} = \frac{-m}{n} = \frac{m}{-n}$$ and $$\frac{-m}{-n} = \frac{m}{n}$$ |
| Same denominator                              | $$\frac{m}{n} + \frac{r}{n} = \frac{m + r}{n}$$                                    |
| :ref[Lowest form exists]{#lowest-form-exists} | every positive rational number has a lowest form                                   |
| :ref[Positive + positive]{#positive-sum}      | is positive                                                                        |
| :ref[Powers]{#fraction-powers}                | $$\left(\frac{m}{n}\right)^k = \frac{m^k}{n^k}$$                                   |

| Decimals                                      | rational numbers are exactly the decimals that stop or repeat                      |

**Inverses and division** (for rational numbers, with every denominator non-zero)

| Rule                                                 | Statement                                                                              |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------- |
| :ref[Inverse of a fraction]{#inverse-exists}         | $$\left(\frac{m}{n}\right)^{-1} = \frac{n}{m}$$ for $$m \neq 0$$; $$0$$ has no inverse |
| :ref[Inverses are unique]{#inverse-unique}           | if $$ab = 1$$, then $$b = a^{-1}$$                                                     |
| :ref[Zero product]{#zero-product}                    | if $$ab = 0$$, then $$a = 0$$ or $$b = 0$$                                             |
| Dividing by a fraction                               | $$\frac{a}{c/d} = a \cdot \frac{d}{c}$$                                                |
| :ref[Cross-multiplying]{#cross-multiplying-rational} | $$\frac{a}{b} = \frac{c}{d}$$ exactly when $$ad = bc$$                                 |
| :ref[Cancelling]{#cancel-product}                    | if $$ab = ac$$ and $$a \neq 0$$, then $$b = c$$; and $$\frac{ab}{ac} = \frac{b}{c}$$   |
| :ref[Adding quotients]{#adding-quotients}            | $$\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}$$                                     |
| :ref[Sum of powers]{#sum-of-powers}                  | $$\frac{x^n - 1}{x - 1} = x^{n-1} + \cdots + x + 1$$                                   |
