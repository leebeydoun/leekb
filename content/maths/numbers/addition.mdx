You've added integers for years, and you know that $$-(-5)$$ is $$5$$ and that two negatives add to
a negative. You probably learned these as facts to remember. In fact they all follow from five basic
rules of addition, so once you accept those, the rest can be worked out.

In this guide we'll set out the five rules and build the familiar facts from them. The same
reasoning carries over unchanged to fractions later on.

## The rules taken as given

Every argument has to start somewhere. Rather than taking every fact about adding on trust, this
page picks out a few that are so basic nobody would doubt them, and accepts only those. You can see
each one on the number line: $$3 + 5$$ and $$5 + 3$$ both land on $$8$$, taking no steps leaves you
where you were, and walking some steps one way then the same number back undoes the walk. The rest
of the page then works out everything else from this short list.

:::remark[Rules for addition]{#addition-rules}

For any integers $$a$$, $$b$$ and $$c$$:

1. **Order doesn't matter:** $$a + b = b + a$$.
2. **Grouping doesn't matter:** $$(a + b) + c = a + (b + c)$$.
3. **Adding zero:** $$a + 0 = a$$.
4. **Adding an opposite:** $$a + (-a) = 0$$.
5. **Positive sums:** if $$a$$ and $$b$$ are positive, so is $$a + b$$.

These are taken as given. Everything else on this page is proved from them.

:::

The first two have names. Rule 1 is called **commutativity** and rule 2 **associativity**. Rules 3
and 4 are the facts about zero and opposites from the [Integers](./integers.mdx) page.

On the number line, commutativity says that two walks taking different routes finish in the same
place. For example, $$6 + (-9) = -3$$ and $$(-9) + 6 = -3$$:

::number-line{from=-4 to=7 points="0, -3" jumps="0>6, 6>-3"}

::number-line{from=-10 to=1 points="0, -3" jumps="0>-9, -9>-3"}

Associativity says that when adding three numbers, it doesn't matter which pair is added first. For
example, with $$4$$, $$-6$$ and $$10$$:

```math
\begin{aligned}
(4 + (-6)) + 10 &= -2 + 10 = 8 \\
4 + ((-6) + 10) &= 4 + 4 = 8
\end{aligned}
```

Since the grouping never changes the result, the brackets are usually left out, and you write
$$4 + (-6) + 10$$. Using both rules over and over, you can add any list of integers **in any order
and in any grouping**. This lets you pair up numbers that cancel or make a round number:

```math
17 + (-8) + 3 + 8 = (17 + 3) + ((-8) + 8) = 20 + 0 = 20
```

Because order doesn't matter, rules 3 and 4 also hold the other way round: $$0 + a = a$$ and
$$-a + a = 0$$.

## Subtraction

Taking away $$5$$ means walking $$5$$ steps to the left. That is exactly what adding $$-5$$ does, so
$$9 - 5$$ and $$9 + (-5)$$ both land on $$4$$. So taking away needs no separate set of rules: you
can treat it as adding the opposite. The definition below gives a shorter way to write $$a + (-b)$$.

<NumberLineWalk start={3} amount={5} op="-" />

:::definition[Subtraction]{#subtraction}

For integers $$a$$ and $$b$$, $$a - b$$ means $$a + (-b)$$.

:::

So subtraction is not a new operation, only a way of adding an opposite. That means the rules for
addition apply to subtraction too, as long as each minus sign stays attached to the number after it:

```math
a - b + c = a + c - b
```

For example, $$9 - 12 + 5 = 9 + 5 - 12 = 14 - 12 = 2$$.

## Opposites

On the number line, there is only one walk that takes you from $$4$$ back to $$0$$: four steps to
the left. So only one number, $$-4$$, adds to $$4$$ to give $$0$$. The first result says that the
opposite of a number is the **only** number that adds to it to give $$0$$. It is used constantly,
because it gives a direct test for an opposite: check that the two numbers add to $$0$$.

:::proposition[Opposites are unique]{#opposite-unique}

For integers $$a$$ and $$b$$, if $$a + b = 0$$, then $$b = -a$$ and $$a = -b$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Group_(mathematics)#Uniqueness_of_inverses"}

The idea is to get $$b$$ on its own by adding $$-a$$ to both sides of $$a + b = 0$$. Two things that
are equal stay equal when the same number is added to both.

The left side becomes

```math
-a + (a + b) = (-a + a) + b = 0 + b = b
```

The first step regroups (rule 2). The next two use $$-a + a = 0$$ and $$0 + b = b$$, which are rules
4 and 3 the other way round; that is allowed because order doesn't matter (rule 1).

The right side becomes $$-a + 0 = -a$$ (rule 3). The two sides are still equal, so $$b = -a$$.

For $$a = -b$$, add $$-b$$ to both sides instead. In the same way, the left side becomes
$$(a + b) + (-b) = a + (b + (-b)) = a + 0 = a$$ and the right side becomes $$0 + (-b) = -b$$, so
$$a = -b$$.

:::

:::corollary[Double opposites]{#double-opposite}

For every integer $$a$$, $$-(-a) = a$$.

:::

:::proof{source="https://math.libretexts.org/Bookshelves/Analysis/Introduction_to_Mathematical_Analysis_I_(Lafferriere_Lafferriere_and_Nguyen)/01%3A_Tools_for_Analysis/1.4%3A_Ordered_Field_Axioms"}

By rule 4 the other way round, $$-a + a = 0$$. So $$-a$$ and $$a$$ are two numbers that add to
$$0$$. By :ref{#opposite-unique}, with $$-a$$ in place of $$a$$ and $$a$$ in place of $$b$$, the
second is the opposite of the first: $$a = -(-a)$$.

:::

Each extra minus sign flips the result between $$a$$ and $$-a$$. An even number of minus signs gives
back $$a$$, and an odd number gives $$-a$$:

```math
-(-(-(-6))) = 6, \qquad -(-(-6)) = -6
```

:::proposition[The opposite of a sum]{#opposite-sum}

For integers $$a$$ and $$b$$,

```math
-(a + b) = -a - b
```

:::

:::proof{source="https://proofwiki.org/wiki/Negative_of_Sum_of_Real_Numbers"}

By :ref{#opposite-unique}, anything that adds to $$a + b$$ to give $$0$$ must be $$-(a + b)$$. So it
is enough to check that $$-a - b$$, which means $$-a + (-b)$$, adds to $$a + b$$ to give $$0$$.

Because order and grouping don't matter, you can rearrange the four numbers to pair each one with
its opposite, then use rule 4 twice:

```math
(a + b) + (-a + (-b)) = (a + (-a)) + (b + (-b)) = 0 + 0 = 0
```

For example, with $$a = 2$$ and $$b = 9$$: $$11 + (-2 - 9) = 11 + (-11) = 0$$, so
$$-(2 + 9) = -2 - 9$$.

:::

Take care when the parts are already negative, because the minus signs combine:

```math
\begin{aligned}
-(2 + 9) &= -2 - 9 = -11 \\
-(-6 + 1) &= -(-6) - 1 = 6 - 1 = 5 \\
-(8 - 13) &= -8 - (-13) = -8 + 13 = 5
\end{aligned}
```

The last line is a special case worth remembering: $$-(a - b) = b - a$$. Swapping the two numbers in
a subtraction gives the opposite answer.

## Signs of sums

Adding a negative number is a walk to the left. Start at $$0$$, walk left once, then walk left
again, and you must end up somewhere to the left of $$0$$. So two negatives should add to a
negative, as two positives add to a positive.

Rule 5 says that two positive integers add to a positive integer. The matching fact for negative
integers doesn't need to be assumed.

:::proposition[Sums of negative integers]{#negative-sum}

If $$a$$ and $$b$$ are negative integers, then $$a + b$$ is negative.

:::

:::proof{source="https://en.wikipedia.org/wiki/Negative_number#Addition"}

The plan is to rewrite $$a + b$$ as the opposite of a sum of two positive integers.

By :ref{#integers}, each negative integer is the opposite of a positive one, so you can write
$$a = -m$$ and $$b = -n$$ with $$m$$ and $$n$$ positive. Then, reading :ref{#opposite-sum} from
right to left,

```math
a + b = -m + (-n) = -m - n = -(m + n)
```

By rule 5, $$m + n$$ is positive. So $$a + b$$ is the opposite of a positive integer, which means it
is negative.

:::

For example, $$-5 + (-11) = -(5 + 11) = -16$$. When the signs are mixed, the result can go either
way: $$-5 + 11 = 6$$ but $$5 + (-11) = -6$$.

## Solving equations

If some number plus $$8$$ gives $$3$$, you can find the number by undoing the $$+8$$: walk $$8$$
steps back from $$3$$ and you reach $$-5$$. An equation is a statement that two things are the same
number, so doing the same thing to both sides keeps it true. Undoing an addition on one side means
subtracting on the other.

So the rules let you move numbers from one side of an equation to the other.

:::proposition[Rearranging a sum]{#rearranging}

For integers $$a$$, $$b$$ and $$c$$, if $$a + b = c$$, then $$a = c - b$$ and $$b = c - a$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Group_(mathematics)#Division"}

To get $$a$$ on its own, add $$-b$$ to both sides of $$a + b = c$$. The left side becomes

```math
(a + b) + (-b) = a + (b + (-b)) = a + 0 = a
```

by regrouping, then rules 4 and 3. The right side becomes $$c + (-b)$$, which is $$c - b$$ by
:ref{#subtraction}. So $$a = c - b$$.

To get $$b$$ on its own, add $$-a$$ instead. Swapping the order first (rule 1),

```math
(a + b) + (-a) = (b + a) + (-a) = b + (a + (-a)) = b + 0 = b
```

and the right side becomes $$c + (-a) = c - a$$. So $$b = c - a$$.

:::

So a number added on one side can be **subtracted from the other side**. This is how you solve
equations with one unknown:

- $$x + 8 = 3$$: subtract $$8$$ from both sides, so $$x = 3 - 8 = -5$$.
- $$6 - y = 10$$: add $$y$$ to both sides to get $$6 = 10 + y$$, then subtract $$10$$ from both
  sides, so $$y = -4$$.
- $$-3 - z = -1$$: add $$z$$ to both sides to get $$-3 = -1 + z$$, then add $$1$$ to both sides, so
  $$z = -2$$.

To check an answer, put it back into the equation. For the last one, $$-3 - (-2) = -3 + 2 = -1$$.

## Order and inequalities

On the number line, $$b$$ is bigger than $$a$$ when it sits further right, that is, when getting
from $$a$$ to $$b$$ means walking right. The walk from $$a$$ to $$b$$ is $$b - a$$ steps, which
turns the picture into a definition.

:::definition[Order of integers]{#order}

For integers $$a$$ and $$b$$, $$a$$ is **less than** $$b$$, written $$a < b$$, if $$b - a$$ is
positive. The same fact is also written $$b > a$$ ("$$b$$ is greater than $$a$$"). Also, $$a \le b$$
means $$a < b$$ or $$a = b$$.

:::

For example, $$-10 < -7$$, because $$-7 - (-10) = 3$$ is positive. And $$a > 0$$ says $$a - 0 = a$$
is positive, so "$$a > 0$$" and "$$a$$ is positive" mean the same thing.

:::proposition[Rules for less than]{#order-rules}

For integers $$a$$, $$b$$ and $$c$$:

1. Exactly one of $$a < b$$, $$a = b$$ and $$a > b$$ is true.
2. If $$a < b$$ and $$b < c$$, then $$a < c$$.
3. If $$a < b$$, then $$a + c < b + c$$.

:::

:::proof{source="https://proofwiki.org/wiki/Strict_Positivity_Property_induces_Total_Ordering"}

All three parts work the same way: turn each inequality into a statement that some difference is
positive, using :ref{#order}, and then work with the differences.

**Part 1.** Write $$d = b - a$$. The idea is that each of the three statements is a statement about
the sign of $$d$$:

- **$$a < b$$ exactly when $$d$$ is positive.** This is the definition of $$<$$.
- **$$a = b$$ exactly when $$d = 0$$.** If $$a = b$$, then $$d = a + (-a) = 0$$ by rule 4.
  Conversely, if $$b + (-a) = 0$$, then $$b = -(-a)$$ by :ref{#opposite-unique}, and this is $$a$$
  by :ref{#double-opposite}.
- **$$a > b$$ exactly when $$d$$ is negative.** By definition, $$a > b$$ means $$a - b$$ is
  positive, and $$a - b$$ equals $$-d$$: by :ref{#opposite-sum} and :ref{#double-opposite},
  $$-d = -(b + (-a)) = -b + a = a - b$$. So it remains to show that $$-d$$ is positive exactly when
  $$d$$ is negative. If $$d$$ is negative, it is $$-p$$ for some positive $$p$$ (:ref{#integers}),
  so $$-d = -(-p) = p$$ is positive. If $$-d$$ is positive, then $$d = -(-d)$$ is the opposite of a
  positive integer, so it is negative.

By :ref{#integers}, the integer $$d$$ is exactly one of positive, zero and negative. So exactly one
of the three statements is true. For example, with $$a = 3$$ and $$b = 7$$, $$d = 4$$ is positive,
so $$3 < 7$$, and $$3 = 7$$ and $$3 > 7$$ are both false.

**Part 2.** You know $$b - a$$ and $$c - b$$ are positive, and want $$c - a$$ to be positive. The
two known differences add up to the one you want, because the $$b$$s cancel:

```math
(c - b) + (b - a) = c + (-b + b) + (-a) = c + 0 + (-a) = c - a
```

A sum of two positive integers is positive by rule 5, so $$c - a$$ is positive, that is, $$a < c$$.

**Part 3.** You know $$b - a$$ is positive, and want $$(b + c) - (a + c)$$ to be positive. Using
:ref{#opposite-sum} to take the opposite of $$a + c$$, then letting $$c$$ and $$-c$$ cancel,

```math
(b + c) - (a + c) = b + c + (-a) + (-c) = b + (-a) + (c + (-c)) = b - a
```

which is positive. So $$a + c < b + c$$.

:::

Part 2 says that inequalities can be chained, so $$-3 < 0 < 5$$ means $$-3 < 5$$. Part 3 says that
adding the same number to both sides keeps an inequality true, as it does for an equation. The rules
for multiplying an inequality need the rules for multiplication, and appear on the next page.

## Exercises

:::::accordion[Exercises on addition, with solutions]

::::exercise{#ex-addition-which-rule}

Which of the :ref{#addition-rules} does each line use?

1. $$7 + (-7) = 0$$
2. $$(5 + 2) + 8 = 5 + (2 + 8)$$
3. $$-3 + 0 = -3$$
4. $$4 + (-9) = (-9) + 4$$

:::solution

1. Rule 4, adding an opposite, with $$a = 7$$.
2. Rule 2, grouping doesn't matter.
3. Rule 3, adding zero, with $$a = -3$$.
4. Rule 1, order doesn't matter.

:::

::::

::::exercise{#ex-addition-as-sums}

Write each subtraction as a sum, using :ref{#subtraction}, and work it out:

1. $$6 - (-4)$$
2. $$-2 - 7$$
3. $$3 - 10 + 7$$

:::solution

1. $$6 - (-4) = 6 + (-(-4))$$, and $$-(-4) = 4$$ by :ref{#double-opposite}. So the answer is
   $$6 + 4 = 10$$.
2. $$-2 - 7 = -2 + (-7)$$. This is a sum of two negative integers, and by :ref{#opposite-sum} it is
   $$-(2 + 7) = -9$$.
3. $$3 - 10 + 7 = 3 + (-10) + 7$$. Order doesn't matter, so this is $$3 + 7 + (-10) = 10 - 10 = 0$$.

:::

::::

::::exercise{#ex-addition-cancel}

Prove that for integers $$a$$, $$b$$ and $$c$$, if $$a + c = b + c$$, then $$a = b$$.

:::solution

Write $$s$$ for the common value, so $$a + c = s$$ and $$b + c = s$$. By :ref{#rearranging}, the
first gives $$a = s - c$$ and the second gives $$b = s - c$$. Both equal $$s - c$$, so $$a = b$$.

In words: the same number added to both sides can be taken away from both sides again.

:::

::::

::::exercise{#ex-addition-three-opposites}

Prove that $$-(a + b + c) = -a - b - c$$ for all integers $$a$$, $$b$$ and $$c$$.

:::solution

By :ref{#opposite-unique}, it is enough to check that $$-a - b - c$$ adds to $$a + b + c$$ to give
$$0$$. Order and grouping don't matter (:ref{#addition-rules}), so you can pair each number with its
opposite:

```math
(a + b + c) + (-a + (-b) + (-c)) = (a + (-a)) + (b + (-b)) + (c + (-c)) = 0 + 0 + 0 = 0
```

So $$-a - b - c$$ is the opposite of $$a + b + c$$.

:::

::::

::::exercise{#ex-addition-mixed-signs}

The sum of two negative integers is negative. Is the sum of a negative integer and a positive
integer always negative? Give a reason or a counterexample, and then work out $$-17 + (-28)$$.

:::solution

No. For example, $$-3 + 10 = 7$$ is positive, and $$-3 + 3 = 0$$ is neither. With mixed signs the
result depends on which number is further from $$0$$.

For $$-17 + (-28)$$, both numbers are negative, so the sum is negative by :ref{#negative-sum}. Using
:ref{#opposite-sum}, it is $$-(17 + 28) = -45$$.

:::

::::

::::exercise{#ex-addition-flip-order}

Prove that if $$a < b$$, then $$-b < -a$$. What does this say about $$-5$$ and $$-2$$?

:::solution

By :ref{#order}, $$a < b$$ means $$b - a$$ is positive, and $$-b < -a$$ means $$(-a) - (-b)$$ is
positive. Using :ref{#subtraction} and :ref{#double-opposite},

```math
(-a) - (-b) = -a + b = b - a
```

which is positive. So $$-b < -a$$.

Since $$2 < 5$$, this gives $$-5 < -2$$: taking opposites reverses the order.

:::

::::

::::exercise{#ex-addition-add-inequalities}

Prove that if $$a < b$$ and $$c < d$$, then $$a + c < b + d$$.

:::solution

Use part 3 of :ref{#order-rules} twice, then chain the results with part 2.

Adding $$c$$ to both sides of $$a < b$$ gives $$a + c < b + c$$. Adding $$b$$ to both sides of
$$c < d$$ gives $$c + b < d + b$$, which is $$b + c < b + d$$ since order doesn't matter in a sum.

So $$a + c < b + c$$ and $$b + c < b + d$$, and by part 2, $$a + c < b + d$$.

:::
