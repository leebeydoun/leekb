Imagine sharing a bag of sweets equally between two friends. Whether that works with none left over
depends on one thing about the number of sweets: whether it's even. Plenty of questions about whole
numbers come down to a fact like this. You can tell that $$37 \cdot 41 + 12$$ is odd, for example,
without multiplying anything, because an odd number times an odd number is odd and adding $$12$$
keeps it odd.

In this guide we'll turn observations like these into precise tests. The language we build will let
us tell when one number divides another and describe what is left when it does not.

The next guide, [Congruence](./congruence.mdx), turns that language into a way of calculating.

## Even and odd

Counting up from $$1$$, the integers alternate between two kinds:

- The **even** integers $$2, 4, 6, 8, 10, \dots$$ are the ones that can be split into pairs with
  nothing left over.
- The **odd** integers $$1, 3, 5, 7, 9, \dots$$ always have one left over.

Both go up in steps of $$2$$, so they take turns along the number line. Here the even integers are
marked:

::number-line{from=-1 to=10 points="0, 2, 4, 6, 8, 10"}

"Split into pairs" means the number is $$2$$ times something, and "one left over" means one more
than that.

:::definition[Even and odd]{#even-odd}

An integer is **even** if it can be written as $$2n$$ for some integer $$n$$, and **odd** if it can
be written as $$2n + 1$$ for some integer $$n$$.

:::

For example, $$14 = 2 \cdot 7$$ and $$30 = 2 \cdot 15$$ are even, while $$1 = 2 \cdot 0 + 1$$,
$$15 = 2 \cdot 7 + 1$$ and $$31 = 2 \cdot 15 + 1$$ are odd. Odd integers can equally be written as
one _less_ than an even integer, $$2n - 1$$, so $$15 = 2 \cdot 8 - 1$$. Use whichever form is more
convenient.

The same definitions work for zero and the negative integers: $$0 = 2 \cdot 0$$ is even,
$$-6 = 2 \cdot (-3)$$ is even, and $$-5 = 2 \cdot (-3) + 1$$ is odd. Every integer is either even or
odd, and never both. The number line makes this look clear. The proof comes later, as
:ref{#even-or-odd}, which follows from [division with remainder](#division-with-remainder).

## Sums and products of even and odd integers

Whether a sum or product is even or odd depends only on whether its parts are. Think of each number
as a pile of objects split into pairs. An even pile has no object left over, and an odd pile has
one. Putting two piles together keeps all the pairs, so the only question is what happens to the
leftovers. One leftover stays on its own, so even plus odd is odd. Two leftovers form a new pair, so
odd plus odd is even: $$7 + 5$$ has pairs from each pile, and the spare $$1$$ from $$7$$ pairs up
with the spare $$1$$ from $$5$$.

For products, $$3 \cdot 5$$ means three piles of $$5$$. If any factor is even, the product is a
number of copies of an even pile, or an even number of copies of a pile, and either way it splits
into pairs. If both factors are odd, there is an odd number of leftovers, one from each odd pile, so
one is still left over at the end.

:::proposition[Adding even and odd integers]{#parity-sums}

| $$a$$ | $$b$$ | $$a + b$$ | Example        |
| ----- | ----- | --------- | -------------- |
| even  | even  | even      | $$8 + 6 = 14$$ |
| even  | odd   | odd       | $$8 + 5 = 13$$ |
| odd   | even  | odd       | $$7 + 6 = 13$$ |
| odd   | odd   | even      | $$7 + 5 = 12$$ |

:::

:::proof{source="https://www.mathsisfun.com/numbers/even-odd.html"}

Write the numbers in the forms from :ref{#even-odd}, add, and pull out a factor of $$2$$ with
distributivity. In each case $$n$$ and $$k$$ are integers, so $$n + k$$ and $$n + k + 1$$ are too.

If both are even, $$a = 2n$$ and $$b = 2k$$, then $$a + b = 2(n + k)$$, which is even.

If $$a = 2n$$ is even and $$b = 2k + 1$$ is odd, then

```math
a + b = 2n + 2k + 1 = 2(n + k) + 1
```

which is $$2$$ times an integer, plus $$1$$, so it is odd. The row with $$a$$ odd and $$b$$ even is
the same sum in the other order, since $$a + b = b + a$$.

If both are odd, $$a = 2n + 1$$ and $$b = 2k + 1$$, then the two leftover $$1$$s pair up with each
other:

```math
a + b = 2n + 1 + 2k + 1 = 2(n + k + 1)
```

which is even.

:::

:::proposition[Multiplying even and odd integers]{#parity-products}

An even integer times any integer is even, and an odd integer times an odd integer is odd.

:::

:::proof{source="https://math.libretexts.org/Bookshelves/Mathematical_Logic_and_Proof/Book%3A_Mathematical_Reasoning__Writing_and_Proof_(Sundstrom)/01%3A_Introduction_to_Writing_Proofs_in_Mathematics/1.02%3A_Constructing_Direct_Proofs"}

If $$a = 2n$$ is even and $$b$$ is any integer, then regrouping the product gives
$$ab = (2n)b = 2(nb)$$, which is even. Since $$ab = ba$$, it doesn't matter which side the even
factor is on.

If $$a = 2n + 1$$ and $$b = 2k + 1$$ are both odd, multiply out the brackets and pull out a $$2$$
from every term except the last:

```math
ab = (2n + 1)(2k + 1) = 4nk + 2n + 2k + 1 = 2(2nk + n + k) + 1
```

which is odd.

:::

So a product is odd exactly when **every** factor is odd. For example, $$3 \cdot 5 \cdot 7 = 105$$
is odd, but $$3 \cdot 5 \cdot 7 \cdot 2 = 210$$ is even.

## Squares

A square has the same kind as the number being squared. This is what the rule for products predicts,
since a square is a number times itself: an even number times anything is even, and an odd number
times an odd number is odd. So $$6^2$$ must be even and $$9^2$$ must be odd, without working either
out.

:::proposition[Squares of even and odd integers]{#squares-parity}

The square of an even integer is even, and the square of an odd integer is odd.

:::

:::proof{source="https://proofwiki.org/wiki/Parity_of_Integer_equals_Parity_of_its_Square"}

Write $$a$$ in one of the forms from :ref{#even-odd}, and check that the square has the same form.

If $$a$$ is even, write $$a = 2n$$. Then $$a^2 = (2n)^2 = 4n^2 = 2(2n^2)$$ (:ref{#power-rules}),
which is $$2$$ times an integer, so it is even.

If $$a$$ is odd, write $$a = 2n + 1$$. Expanding with the square of a sum (:ref{#square-formulas}),

```math
a^2 = (2n + 1)^2 = 4n^2 + 4n + 1 = 2(2n^2 + 2n) + 1
```

The first two terms both contain a factor of $$2$$, so you can pull it out, leaving $$1$$ over. That
is the form of an odd integer.

:::

For example, $$6^2 = 36$$ is even and $$9^2 = 81$$ is odd. This also works backwards.

:::corollary[Numbers with even or odd squares]{#squares-parity-converse}

If $$a^2$$ is even, then $$a$$ is even. If $$a^2$$ is odd, then $$a$$ is odd.

:::

:::proof{source="https://en.wikipedia.org/wiki/Mathematical_proof#Proof_by_contraposition"}

This uses :ref{#even-or-odd}, which also says that no integer is both. That fact is proved further
down the page, using only division with remainder, so it is safe to use here. Because $$a$$ has to
be one of the two, it is enough to rule out the wrong one.

Suppose $$a^2$$ is even. If $$a$$ were odd, then by :ref{#squares-parity} its square would be odd.
But $$a^2$$ is even, and no integer is both even and odd, so this can't happen. So $$a$$ must be
even. The same reasoning with "even" and "odd" swapped proves the second statement.

:::

This is an example of proving the contrapositive (:ref{#basic-proofs/contrapositive}): "if $$a$$ is
odd then $$a^2$$ is odd" says the same as "if $$a^2$$ is not odd then $$a$$ is not odd". So, for
example, if $$a^2 = 144$$ then without working out $$a$$ you already know it is even.

The same splitting into even and odd settles powers of $$-1$$. If $$n = 2k$$ is even, then
$$(-1)^n = ((-1)^2)^k = 1^k = 1$$. If $$n = 2k + 1$$ is odd, then
$$(-1)^n = (-1)^{2k} \cdot (-1) = -1$$. So $$(-1)^n$$ is $$1$$ when $$n$$ is even and $$-1$$ when
$$n$$ is odd.

## Divisibility

Being even means being a multiple of $$2$$. The same idea works with any number in place of $$2$$.
Saying that $$4$$ divides $$28$$ means $$28$$ objects can be put into rows of $$4$$ with none left
over. Here there are $$7$$ rows. On the number line, it means you can get from $$0$$ to $$28$$ in
equal steps of $$4$$. The definition says this with a multiplication: $$28$$ is $$4$$ times a whole
number.

<RowsOfDots n={28} d={4} />

:::definition[Divisibility]{#divides}

An integer $$d$$ **divides** an integer $$n$$, or $$n$$ is **divisible** by $$d$$, if

```math
n = dk \qquad \text{for some integer } k
```

This is written $$d \mid n$$, and $$d$$ is called a **divisor** of $$n$$.

:::

For example:

- $$4 \mid 28$$, because $$28 = 4 \cdot 7$$.
- $$6 \mid -42$$, because $$-42 = 6 \cdot (-7)$$.
- $$5$$ does **not** divide $$12$$, because no integer $$k$$ gives $$5k = 12$$. This is written
  $$5 \nmid 12$$.

So "even" is the same as "divisible by $$2$$". A few things are always true:

- Every integer is divisible by $$1$$, because $$n = 1 \cdot n$$.
- Every integer is divisible by itself, because $$n = n \cdot 1$$.
- $$0$$ is divisible by every integer, because $$0 = d \cdot 0$$.

A common question is how many times a number can be divided by $$2$$ (or $$3$$, or anything else).
Splitting $$48$$ into factors of $$2$$ until an odd number is left gives

```math
\begin{aligned}
48 &= 2 \cdot 24 = 2 \cdot 2 \cdot 12 = 2 \cdot 2 \cdot 2 \cdot 6 \\
&= 2 \cdot 2 \cdot 2 \cdot 2 \cdot 3 = 2^4 \cdot 3
\end{aligned}
```

so $$2^4 = 16$$ divides $$48$$, but $$2^5 = 32$$ does not. In the same way $$54 = 2 \cdot 3^3$$, so
$$3^3 = 27$$ is the largest power of $$3$$ that divides $$54$$.

## Combining multiples

If two numbers are both multiples of $$d$$, then so is anything built from them by adding,
subtracting or multiplying. Think of rows of $$7$$: $$21$$ is three rows and $$35$$ is five rows.
Put them together and you have eight rows, which is $$56$$. Take three rows away from five rows and
two rows are left, so the difference is a multiple of $$7$$ too. And four copies of three rows is
twelve rows. Nothing ever breaks a row, so the answer is always a whole number of rows.

:::lemma[Combining multiples]{#multiples}

Let $$d$$, $$m$$ and $$n$$ be integers with $$d \mid m$$ and $$d \mid n$$. Then $$d \mid m + n$$,
$$d \mid m - n$$, and $$d \mid mc$$ for any integer $$c$$.

:::

:::proof{source="https://math.libretexts.org/Bookshelves/Combinatorics_and_Discrete_Mathematics/Elementary_Number_Theory_(Raji)/01%3A_Introduction/1.03%3A_Divisibility_and_the_Division_Algorithm"}

The statement is about multiples of $$d$$, so the natural first step is to unpack the definition of
divisibility and write each number you know about as $$d$$ times something. Since $$d \mid m$$ and
$$d \mid n$$, there are integers $$k$$ and $$l$$ with

```math
m = dk \qquad \text{and} \qquad n = dl
```

To show that a number is divisible by $$d$$, write it as $$d$$ times an integer. So in each case,
substitute and then pull out the common factor $$d$$ using distributivity:

```math
\begin{aligned}
m + n &= dk + dl = d(k + l) \\
m - n &= dk - dl = d(k - l) \\
mc &= (dk)c = d(kc)
\end{aligned}
```

The last line uses associativity to regroup the product. Because sums, differences and products of
integers are integers, $$k + l$$, $$k - l$$ and $$kc$$ are all integers. So each of $$m + n$$,
$$m - n$$ and $$mc$$ has been written as $$d$$ times an integer, which is exactly what $$d$$
dividing it means.

:::

For example, $$7 \mid 21$$ and $$7 \mid 35$$, so $$7$$ also divides $$21 + 35 = 56$$,
$$21 - 35 = -14$$ and $$21 \cdot 4 = 84$$. This lemma is used again and again on the
[Congruence](./congruence.mdx) page.

## Division with remainder

Most numbers aren't divisible by a given $$d$$, but they always land somewhere between two multiples
of it. Picture the multiples of $$5$$ on the number line. They cut it into stretches $$5$$ steps
long, and $$17$$ lands in the stretch that starts at $$15$$, two steps in:

::number-line{from=0 to=20 unit=30 points="0, 5, 10, 15, 20" jumps="15>17: + 2"}

So $$17 = 5 \cdot 3 + 2$$: three whole fives, and $$2$$ left over.

:::theorem[Division with remainder]{#division-remainder}

Let $$n$$ and $$d$$ be integers with $$d > 0$$. Then there are integers $$q$$ and $$r$$ with

```math
n = dq + r \qquad \text{and} \qquad 0 \le r < d
```

and there is only one such pair. The number $$q$$ is called the **quotient** and $$r$$ the
**remainder** when $$n$$ is divided by $$d$$.

:::

The theorem says two things: a quotient and remainder **exist**, and there is **only one** such
pair. Both come from one idea. Each guess for the quotient $$q$$ leaves a leftover of $$n - dq$$,
and raising the guess by $$1$$ takes another $$d$$ off the leftover. For $$n = 17$$ and $$d = 5$$:

| Quotient $$q$$       | $$0$$  | $$1$$  | $$2$$ | $$3$$ | $$4$$  | $$5$$  |
| -------------------- | ------ | ------ | ----- | ----- | ------ | ------ |
| Leftover $$17 - 5q$$ | $$17$$ | $$12$$ | $$7$$ | $$2$$ | $$-3$$ | $$-8$$ |

The leftovers go down in steps of $$5$$. The allowed remainders $$0, 1, 2, 3, 4$$ form a window of
exactly $$5$$ integers in a row, shaded here, with the leftovers marked as points:

::number-line{from=-8 to=17 points="-8, -3, 2, 7, 12, 17" intervals="[0, 5)"}

Steps of $$5$$ can't jump over a window $$5$$ wide, so one leftover lands inside it. The next step
takes away another $$5$$ and leaves the window below $$0$$, so no second leftover lands inside. The
same happens for any $$n$$ and $$d$$, with steps of $$d$$ and a window of $$d$$ integers. The proof
turns each half of this into algebra.

:::proof{source="https://en.wikipedia.org/wiki/Euclidean_division#Proof"}

**Part 1: there is such a pair.** Choose $$q$$ to be the **largest** quotient whose leftover
$$n - dq$$ is still $$0$$ or more. In the table this is $$q = 3$$, the last column before the
leftovers turn negative. In terms of multiples, $$dq$$ is the largest multiple of $$d$$ that is not
bigger than $$n$$.

Such a largest $$q$$ always exists, because the leftovers run down in steps of $$d$$ from as large
as you like to as negative as you like. So there is a last one that is $$0$$ or more. This is clear
from the picture, and it is taken as a basic fact about the integers rather than proved, in the same
way as induction (:ref{#basic-proofs/induction}).

Now call that leftover $$r$$, so $$r = n - dq$$. Adding $$dq$$ to both sides gives $$n = dq + r$$,
and it remains to check that $$r$$ is an allowed remainder:

First, $$r$$ is $$0$$ or more, because $$q$$ was chosen so that its leftover is $$0$$ or more.

Second, $$r$$ is less than $$d$$. The next quotient $$q + 1$$ is too large, so its leftover is
negative, and that leftover is $$d$$ less than $$r$$:

```math
n - d(q + 1) = n - dq - d = r - d
```

So $$r - d < 0$$, and adding $$d$$ to both sides gives $$r < d$$ (:ref{#order-rules}).

For $$n = 17$$ and $$d = 5$$, this gives $$q = 3$$ and $$r = 2$$. The next leftover is
$$2 - 5 = -3$$, which is negative, and that is what shows $$2 < 5$$.

**Part 2: there is only one pair.** In words: two different quotients differ by at least $$1$$, so
their leftovers differ by at least $$d$$. But two numbers in the window from $$0$$ to $$d - 1$$ are
less than $$d$$ apart, so they can't both be allowed remainders.

To write this out, suppose $$n = dq + r$$ and $$n = dq' + r'$$, where both remainders are $$0$$ or
more and less than $$d$$. The dash marks the second pair. Name the pairs so that $$q$$ is the larger
quotient, or they are equal, so $$q \ge q'$$. We'll suppose $$q > q'$$ and reach something
impossible (:ref{#basic-proofs/contradiction}).

**Step 1: compare the two pairs.** Both right sides equal $$n$$, so they equal each other. Subtract
$$dq'$$ and $$r$$ from both sides, and take out the common factor $$d$$ with distributivity:

```math
\begin{aligned}
dq + r &= dq' + r' \\
dq - dq' &= r' - r \\
d(q - q') &= r' - r
\end{aligned}
```

So the remainders differ by $$d$$ times the difference of the quotients.

**Step 2: that difference is at least $$d$$.** Since $$q > q'$$, the integer $$q - q'$$ is at least
$$1$$, because no integer lies strictly between $$0$$ and $$1$$. If $$q - q' = 1$$, then
$$d(q - q') = d$$. If $$q - q' > 1$$, then multiplying by the positive number $$d$$ keeps the order
(:ref{#order-multiply}), so $$d(q - q') > d$$. Either way, Step 1 gives

```math
r' - r \ge d
```

**Step 3: so $$r'$$ is too big.** Adding $$r$$ to both sides gives $$r' \ge d + r$$, and $$d + r$$
is at least $$d$$ because $$r$$ is $$0$$ or more. So $$r' \ge d$$, but $$r'$$ was supposed to be
less than $$d$$. This is impossible, so $$q > q'$$ is false, and $$q = q'$$. For example, with
$$n = 17$$ and $$d = 5$$, the quotients $$q = 3$$ and $$q' = 2$$ give $$r = 2$$ and
$$r' = 2 + 5 = 7$$, which is too big to be a remainder.

**Step 4: the remainders match too.** Each remainder is what is left of $$n$$ after taking away
$$d$$ times its quotient, and the quotients are equal, so $$r = n - dq = n - dq' = r'$$. So there is
only one pair.

:::

For a negative number the remainder is still between $$0$$ and $$d - 1$$:
$$-17 = 5 \cdot (-4) + 3$$, so the remainder is $$3$$, not $$-2$$. And $$d \mid n$$ says exactly
that the remainder is $$0$$.

Dividing by $$2$$ settles the claim from [Even and odd](#even-and-odd) that every integer is one or
the other.

:::corollary[Every integer is even or odd]{#even-or-odd}

Every integer is either even or odd, and not both.

:::

:::proof{source="https://proofwiki.org/wiki/Equivalence_of_Definitions_of_Odd_Integer"}

Take :ref{#division-remainder} with $$d = 2$$. The remainder is between $$0$$ and $$1$$, so every
integer $$n$$ can be written as

```math
n = 2q + 0 \qquad \text{or} \qquad n = 2q + 1
```

The first form says $$n$$ is even and the second says $$n$$ is odd (:ref{#even-odd}), so $$n$$ is at
least one of them.

It can't be both. If $$n = 2k$$ and also $$n = 2m + 1$$, then $$n$$ would have two different
remainders, $$0$$ and $$1$$, when divided by $$2$$. The theorem says there is only one.

:::

In the same way, dividing by $$3$$ sorts every integer into exactly one of three kinds,

```math
3k, \qquad 3k + 1 \qquad \text{or} \qquad 3k + 2
```

and splitting into these cases is a common way to prove things about multiples of $$3$$.

## Common divisors

Two numbers can share divisors. For example, $$36$$ and $$60$$ are both multiples of $$12$$: one is
$$3$$ twelves and the other is $$5$$ twelves. A common divisor is a step size that reaches both
numbers exactly from $$0$$. The greatest one is the biggest step size that does this. It is the
largest factor that can be taken out of both at once, which is what is needed to simplify a fraction
like $$\tfrac{36}{60}$$ all the way down to $$\tfrac{3}{5}$$ in one go.

:::definition[Common divisors]{#gcd}

A **common divisor** of two integers is an integer that divides both of them. For positive integers
$$m$$ and $$n$$, the largest of their common divisors is their **greatest common divisor**.

:::

For example, the positive divisors of $$36$$ are $$1, 2, 3, 4, 6, 9, 12, 18, 36$$, and those of
$$60$$ are $$1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60$$. The common ones are $$1, 2, 3, 4, 6, 12$$,
so the greatest common divisor of $$36$$ and $$60$$ is $$12$$.

There always is a greatest one. A positive divisor $$d$$ of a positive integer $$m$$ is never bigger
than $$m$$, because $$m = dk$$ with $$k \ge 1$$, so $$m \ge d$$. That leaves only finitely many
candidates, and $$1$$ is always one of them. When the greatest common divisor is $$1$$, the two
numbers share no factor worth cancelling; that is what lowest form means for fractions, on the
[Rational numbers](./rational-numbers.mdx) page.

## Exercises

:::::accordion[Exercises on divisibility, with solutions]

::::exercise{#ex-divisibility-forms}

Write each number as $$2n$$ or $$2n + 1$$ for an integer $$n$$, and say whether it is even or odd:
$$46$$, $$-9$$, $$0$$ and $$101$$.

:::solution

Using :ref{#even-odd}:

- $$46 = 2 \cdot 23$$, so it is even.
- $$-9 = 2 \cdot (-5) + 1$$, so it is odd.
- $$0 = 2 \cdot 0$$, so it is even.
- $$101 = 2 \cdot 50 + 1$$, so it is odd.

For $$-9$$, note that $$n = -5$$ rather than $$-4$$: $$2 \cdot (-4) + 1 = -7$$.

:::

::::

::::exercise{#ex-divisibility-true-false}

True or false? Use :ref{#divides} each time.

1. $$7 \mid 91$$
2. $$6 \mid -54$$
3. $$8 \mid 100$$
4. $$5 \mid 0$$
5. $$0 \mid 5$$

:::solution

1. True: $$91 = 7 \cdot 13$$.
2. True: $$-54 = 6 \cdot (-9)$$.
3. False: $$8 \cdot 12 = 96$$ and $$8 \cdot 13 = 104$$, so no integer $$k$$ gives $$8k = 100$$.
4. True: $$0 = 5 \cdot 0$$.
5. False: $$0 \cdot k = 0$$ for every integer $$k$$, so $$0 \cdot k$$ is never $$5$$.

Parts 4 and 5 show that the order matters: $$d \mid n$$ and $$n \mid d$$ say different things.

:::

::::

::::exercise{#ex-divisibility-quotients}

Find the quotient and remainder when:

1. $$47$$ is divided by $$6$$
2. $$-23$$ is divided by $$4$$
3. $$30$$ is divided by $$10$$

:::solution

In each case find the largest multiple of the divisor that is not bigger than the number
(:ref{#division-remainder}).

1. $$6 \cdot 7 = 42$$ and $$6 \cdot 8 = 48$$ is too big, so $$47 = 6 \cdot 7 + 5$$: quotient $$7$$,
   remainder $$5$$.
2. The multiples of $$4$$ near $$-23$$ are $$-24$$ and $$-20$$, and $$-24$$ is the largest one that
   is not bigger than $$-23$$. So $$-23 = 4 \cdot (-6) + 1$$: quotient $$-6$$, remainder $$1$$. The
   remainder can't be $$-3$$, because it has to be between $$0$$ and $$3$$.
3. $$30 = 10 \cdot 3 + 0$$: quotient $$3$$, remainder $$0$$, since $$10 \mid 30$$.

:::

::::

::::exercise{#ex-divisibility-even-square-four}

Prove that the square of an even integer is divisible by $$4$$.

:::solution

Write the even integer as $$a = 2n$$ (:ref{#even-odd}). By :ref{#power-rules},

```math
a^2 = (2n)^2 = 2^2 n^2 = 4n^2
```

and $$n^2$$ is an integer. So $$a^2$$ is $$4$$ times an integer, which means $$4 \mid a^2$$.

:::

::::

::::exercise{#ex-divisibility-take-away}

Prove that if $$d \mid a$$ and $$d \mid a + b$$, then $$d \mid b$$.

:::solution

In terms of rows of $$d$$: $$a + b$$ is a whole number of rows, and so is $$a$$. Taking the rows of
$$a$$ away from the rows of $$a + b$$ leaves $$b$$, so $$b$$ is a whole number of rows too. For
example, $$7 \mid 14$$ and $$7 \mid 14 + 21$$, and the $$21$$ left over is $$3$$ rows of $$7$$.

To write this out, unpack both facts with :ref{#divides}. There are integers $$k$$ and $$l$$ with

```math
a = dk \qquad \text{and} \qquad a + b = dl
```

The goal is to write $$b$$ as $$d$$ times an integer. Subtract $$a$$ from both sides of the second
equation, replace $$a$$ with $$dk$$, and take out the common factor $$d$$ with distributivity:

```math
\begin{aligned}
b &= dl - a \\
&= dl - dk \\
&= d(l - k)
\end{aligned}
```

Since $$l$$ and $$k$$ are integers, so is $$l - k$$. So $$b$$ is $$d$$ times an integer, which means
$$d \mid b$$.

There is also a shorter proof that uses :ref{#multiples}. That lemma says: if $$d$$ divides two
numbers $$m$$ and $$n$$, then $$d$$ divides their difference $$m - n$$. So look for two numbers you
already know $$d$$ divides, whose difference is $$b$$. The two you know about are $$a + b$$ and
$$a$$, and taking one from the other leaves $$b$$:

```math
(a + b) - a = b
```

So use the lemma with $$m = a + b$$ and $$n = a$$. Both are divisible by $$d$$, so their difference
$$b$$ is divisible by $$d$$. This isn't a different argument. The lemma's proof does the same
subtraction, $$dl - dk = d(l - k)$$, for any two multiples of $$d$$, so quoting the lemma saves
writing it out again.

:::

It is false. Take $$d = 6$$, $$a = 2$$ and $$b = 3$$. Then $$ab = 6$$, so $$6 \mid ab$$. But
$$6 \nmid 2$$ and $$6 \nmid 3$$.

The factors of $$d$$ can be split between $$a$$ and $$b$$: here the $$2$$ in $$6$$ comes from $$a$$
and the $$3$$ comes from $$b$$.

::::exercise{#ex-divisibility-common-divisors}

Find the greatest common divisor of $$42$$ and $$56$$, and of $$15$$ and $$28$$.

:::solution

List the positive divisors and pick out the common ones (:ref{#gcd}):

- $$42$$: $$1, 2, 3, 6, 7, 14, 21, 42$$
- $$56$$: $$1, 2, 4, 7, 8, 14, 28, 56$$

The common divisors are $$1, 2, 7, 14$$, so the greatest common divisor of $$42$$ and $$56$$ is
$$14$$.

The positive divisors of $$15$$ are $$1, 3, 5, 15$$ and those of $$28$$ are $$1, 2, 4, 7, 14, 28$$.
The only common one is $$1$$, so the greatest common divisor is $$1$$.

:::

::::exercise{#ex-divisibility-always-odd}

Prove that $$n^2 + n + 1$$ is odd for every integer $$n$$.

:::solution

By :ref{#even-or-odd}, $$n$$ is even or odd, so check both cases with the tables for sums and
products (:ref{#parity-sums}, :ref{#parity-products}).

- If $$n$$ is even, then $$n^2$$ is even, so $$n^2 + n$$ is even plus even, which is even.
- If $$n$$ is odd, then $$n^2$$ is odd (:ref{#squares-parity}), so $$n^2 + n$$ is odd plus odd,
  which is even.

Either way $$n^2 + n$$ is even, say $$2k$$. Then $$n^2 + n + 1 = 2k + 1$$, which is odd.

:::
