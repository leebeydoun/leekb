Suppose today is a Monday and you want to know the day of the week $$100$$ days from now. You don't
need to count them. $$100$$ days is $$14$$ whole weeks and $$2$$ days more, and whole weeks don't
change the day, so it'll be a Wednesday.

Only the remainder after dividing by $$7$$ mattered there, and plenty of questions about numbers
work like this. The last digit of $$3^{20}$$, for example, depends only on its remainder when
divided by $$10$$. In this guide we'll learn to calculate with remainders directly, treating two
numbers as "the same" when they leave the same remainder, so the huge numbers never need working
out.

## Same remainder, same place on the clock

On a clock, $$15$$ o'clock is the same as $$3$$ o'clock: the two times differ by a whole number of
turns of $$12$$ hours. Dividing by $$12$$, both leave remainder $$3$$. Congruence makes this idea
work for any positive whole number $$d$$ in place of $$12$$.

Try it: pick a number to see where it lands, or add hours to send the hand round.

<ClockArithmetic hours={12} value={15} step={5} />

:::definition[Congruence]{#congruence}

Let $$d$$ be a positive integer. Two integers $$a$$ and $$b$$ are **congruent modulo $$d$$** if
their difference is a multiple of $$d$$:

```math
a \equiv b \pmod{d} \qquad \text{means} \qquad d \mid a - b
```

:::

For example:

- $$17 \equiv 2 \pmod{5}$$, because $$17 - 2 = 15 = 5 \cdot 3$$.
- $$-3 \equiv 2 \pmod{5}$$, because $$-3 - 2 = -5 = 5 \cdot (-1)$$.
- $$15 \equiv 3 \pmod{12}$$, which is the clock example.
- $$9 \not\equiv 4 \pmod{3}$$, because $$9 - 4 = 5$$ is not a multiple of $$3$$.

On the number line, the integers congruent to $$2$$ modulo $$5$$ are spaced $$5$$ apart, in both
directions:

::number-line{from=-4 to=13 points="-3, 2, 7, 12"}

These are exactly the integers that leave remainder $$2$$ when divided by $$5$$. That is no
coincidence.

:::proposition[Congruent means same remainder]{#same-remainder}

Let $$d$$ be a positive integer. Two integers are congruent modulo $$d$$ exactly when they leave the
same remainder when divided by $$d$$.

:::

:::proof{source="https://math.libretexts.org/Courses/Mount_Royal_University/Abstract_Algebra_I/Chapter_1:_Integers/1.4:_Integers_modulo_n"}

There are two directions to prove (:ref{#basic-proofs/exactly-when}).

**Same remainder gives congruent.** If $$a$$ and $$b$$ leave the same remainder $$r$$, write
$$a = dq + r$$ and $$b = dq' + r$$. Subtracting, the two $$r$$s cancel:

```math
a - b = (dq + r) - (dq' + r) = dq - dq' = d(q - q')
```

This is a multiple of $$d$$, so $$a \equiv b \pmod{d}$$.

**Congruent gives same remainder.** Suppose $$a \equiv b$$, so $$a - b = dk$$ for some integer
$$k$$, which rearranges to $$a = b + dk$$ (:ref{#rearranging}). Divide $$b$$ by $$d$$
(:ref{#division-remainder}) to get $$b = dq + r$$ with $$0 \le r < d$$. Then

```math
a = b + dk = dq + r + dk = d(q + k) + r
```

This writes $$a$$ as $$d$$ times an integer plus the same $$r$$, which is still between $$0$$ and
$$d - 1$$. By :ref{#division-remainder} a number has only one such remainder, so the remainder of
$$a$$ is $$r$$ too.

For example, $$17 \equiv 2 \pmod{5}$$ with $$17 - 2 = 5 \cdot 3$$. Since $$2 = 5 \cdot 0 + 2$$, the
second step gives $$17 = 5 \cdot (0 + 3) + 2$$, and both leave remainder $$2$$.

:::

So every integer is congruent modulo $$d$$ to exactly one of $$0, 1, \dots, d - 1$$, namely its
remainder. Working modulo $$d$$ means keeping track of nothing but that remainder.

Two special cases are worth noticing:

- $$n \equiv 0 \pmod{d}$$ exactly when $$d \mid n$$, since $$n - 0 = n$$. So "divisible by $$d$$"
  and "congruent to $$0$$" say the same thing.
- Modulo $$2$$, every even integer is $$\equiv 0$$ and every odd integer is $$\equiv 1$$. The rules
  for adding and multiplying even and odd integers are rules about congruence modulo $$2$$.

## Congruence behaves like equality

Congruence is meant to say that two numbers are "the same" as far as remainders go, so it should
behave like being equal. Thinking of congruent numbers as the same place on a clock, the basic facts
are clear. Every number is at its own place. If $$15$$ o'clock is where $$3$$ o'clock is, then $$3$$
o'clock is where $$15$$ o'clock is. And if $$27$$ is where $$15$$ is, and $$15$$ is where $$3$$ is,
then $$27$$ is where $$3$$ is.

Congruence modulo a fixed $$d$$ has the three properties that make equality useful in calculations.
They have names:

- **reflexive**: every number is congruent to itself
- **symmetric**: a congruence can be read either way round
- **transitive**: congruences can be chained

:::proposition[Congruence behaves like equality]{#congruence-equality}

Let $$d$$ be a positive integer and $$a$$, $$b$$, $$c$$ integers.

1. **Reflexive:** $$a \equiv a \pmod{d}$$.
2. **Symmetric:** if $$a \equiv b \pmod{d}$$, then $$b \equiv a \pmod{d}$$.
3. **Transitive:** if $$a \equiv b$$ and $$b \equiv c \pmod{d}$$, then $$a \equiv c \pmod{d}$$.

:::

:::proof{source="https://proofwiki.org/wiki/Congruence_Modulo_Integer_is_Equivalence_Relation"}

Each part is a statement about congruence, and congruence is defined in terms of divisibility. So in
each case, translate "$$\equiv$$" into a statement about a difference being a multiple of $$d$$, and
check that.

1. To show $$a \equiv a$$, you need $$d \mid a - a$$. But $$a - a = 0$$, and $$0 = d \cdot 0$$ is a
   multiple of $$d$$ (zero is divisible by everything).
2. You are told $$d \mid a - b$$, so $$a - b = dk$$ for some integer $$k$$. You want
   $$d \mid b - a$$. The key observation is that $$b - a$$ is the opposite of $$a - b$$, so

   ```math
   b - a = -(a - b) = -(dk) = d(-k)
   ```

   Since $$-k$$ is an integer, $$b - a$$ is a multiple of $$d$$. In words: if two numbers differ by
   a multiple of $$d$$, it doesn't matter which one you subtract from the other.

3. You are told that $$a - b$$ and $$b - c$$ are both multiples of $$d$$, and you want $$a - c$$ to
   be one too. The trick is to notice that the two known differences add up to the one you want,
   because the $$b$$s cancel:

   ```math
   (a - b) + (b - c) = a - b + b - c = a - c
   ```

   By :ref{#multiples} the sum of two multiples of $$d$$ is a multiple of $$d$$, so
   $$d \mid a - c$$. On the number line: if it takes a whole number of steps of size $$d$$ to get
   from $$a$$ to $$b$$, and from $$b$$ to $$c$$, then it takes a whole number of steps to get from
   $$a$$ to $$c$$.

:::

For example, $$23 \equiv 8$$ and $$8 \equiv -7 \pmod{5}$$, so $$23 \equiv -7 \pmod{5}$$. Check:
$$23 - (-7) = 30$$.

## Arithmetic with congruences

Congruences can be added, subtracted and multiplied in the same way as equations. On the clock, it
makes no difference whether you call the time $$15$$ o'clock or $$3$$ o'clock: five hours later you
are at the same place either way. In the same way, the remainder of a sum or product depends only on
the remainders of its parts. A familiar case is the last digit, which is the remainder on dividing
by $$10$$. The product $$13 \cdot 17$$ ends in $$1$$ because $$3 \cdot 7 = 21$$ ends in $$1$$, and
nothing else about $$13$$ and $$17$$ matters. Indeed $$13 \cdot 17 = 221$$.

So you can swap a number for any other with the same remainder, do the sum with the smaller one, and
get the right remainder at the end.

:::theorem[Arithmetic with congruences]{#congruence-arithmetic}

Let $$d$$ be a positive integer, and suppose

```math
a \equiv b \pmod{d} \qquad \text{and} \qquad x \equiv y \pmod{d}
```

Then

1. $$a + x \equiv b + y \pmod{d}$$,
2. $$a - x \equiv b - y \pmod{d}$$,
3. $$ax \equiv by \pmod{d}$$.

:::

:::proof{source="https://math.libretexts.org/Bookshelves/Combinatorics_and_Discrete_Mathematics/Elementary_Number_Theory_(Raji)/03%3A_Congruences/3.01%3A_Introduction_to_Congruences"}

Throughout, the definition of congruence turns what you know into statements about divisibility. You
are told that

```math
d \mid a - b \qquad \text{and} \qquad d \mid x - y
```

In each part, the goal is to show that $$d$$ divides the difference of the two sides. The strategy
is the same every time: rewrite that difference so that it is built out of $$a - b$$ and $$x - y$$
by adding, subtracting or multiplying, and then apply :ref{#multiples}, which says that anything
built from multiples of $$d$$ in this way is again a multiple of $$d$$.

1. For $$a + x \equiv b + y$$ you need $$d \mid (a + x) - (b + y)$$. Removing the brackets and
   regrouping, which is allowed because the order and grouping of a sum don't matter, pairs up $$a$$
   with $$b$$ and $$x$$ with $$y$$:

   ```math
   (a + x) - (b + y) = a + x - b - y = (a - b) + (x - y)
   ```

   This is a sum of two multiples of $$d$$, so it is a multiple of $$d$$.

2. For $$a - x \equiv b - y$$ the same regrouping gives

   ```math
   (a - x) - (b - y) = a - x - b + y = (a - b) - (x - y)
   ```

   which is a difference of two multiples of $$d$$, so again a multiple of $$d$$.

3. For $$ax \equiv by$$ you need $$d \mid ax - by$$, and here the regrouping is harder to see,
   because $$ax - by$$ doesn't split directly into $$a - b$$ and $$x - y$$. The idea is to go from
   $$ax$$ to $$by$$ in two steps, changing one letter at a time: first change $$a$$ to $$b$$, giving
   $$bx$$, and then change $$x$$ to $$y$$. In symbols, subtract and add the "halfway" term $$bx$$,
   which changes nothing because $$-bx + bx = 0$$:

   ```math
   \begin{aligned}
   ax - by &= ax - bx + bx - by \\
   &= (a - b)x + b(x - y)
   \end{aligned}
   ```

   The second line factors $$x$$ out of the first two terms and $$b$$ out of the last two. Now
   $$(a - b)x$$ is a multiple of $$a - b$$, so it is a multiple of $$d$$, and likewise $$b(x - y)$$
   is a multiple of $$d$$. Their sum is therefore a multiple of $$d$$.

:::

:::corollary[The same number on both sides of a congruence]{#congruence-constant}

If $$a \equiv b \pmod{d}$$, then for any integer $$c$$,

```math
a + c \equiv b + c \pmod{d} \qquad \text{and} \qquad ca \equiv cb \pmod{d}
```

:::

:::proof{source="https://math.libretexts.org/Bookshelves/Combinatorics_and_Discrete_Mathematics/Elementary_Number_Theory_(Raji)/03%3A_Congruences/3.01%3A_Introduction_to_Congruences"}

The idea is that $$c$$ is congruent to itself, so you can use the pair $$c \equiv c$$ as the second
congruence in :ref{#congruence-arithmetic}. By :ref{#congruence-equality}, $$c \equiv c \pmod{d}$$.
Taking $$x = y = c$$ in the theorem, the adding part gives $$a + c \equiv b + c$$, and the
multiplying part gives $$ac \equiv bc$$, which is the same as $$ca \equiv cb$$ because the order of
a product doesn't matter.

:::

:::proposition[Powers of congruences]{#congruence-powers}

If $$a \equiv b \pmod{d}$$, then $$a^n \equiv b^n \pmod{d}$$ for every positive integer $$n$$.

:::

:::proof{source="https://proofwiki.org/wiki/Congruence_of_Powers"}

A power is a repeated product, and :ref{#congruence-arithmetic} already says that congruences can be
multiplied. So the proof builds up the powers one at a time.

For $$n = 1$$ there is nothing to prove: $$a^1 = a$$ and $$b^1 = b$$.

Now suppose you already know $$a^k \equiv b^k \pmod{d}$$ for some power $$k$$. Multiplying this
congruence by $$a \equiv b$$, using part 3 of the theorem with $$a^k, b^k$$ in place of $$a, b$$ and
$$a, b$$ in place of $$x, y$$, gives

```math
a^k \cdot a \equiv b^k \cdot b \pmod{d}
\qquad \text{that is} \qquad
a^{k+1} \equiv b^{k+1} \pmod{d}
```

The second form uses $$a^k a^1 = a^{k+1}$$ from :ref{#power-rules}, and the same for $$b$$.

So whenever the statement holds for one power, it also holds for the next. Starting from $$n = 1$$,
it therefore holds for $$n = 2$$, then for $$n = 3$$, and so on, reaching every positive integer
$$n$$. This is a proof by induction (:ref{#basic-proofs/induction}).

:::

The practical upshot is that **any number in a sum, difference or product can be swapped for a
congruent one** without changing the answer modulo $$d$$. For example, to find
$$38 \cdot 47 \pmod{5}$$, replace $$38$$ by $$3$$ and $$47$$ by $$2$$:

```math
38 \cdot 47 \equiv 3 \cdot 2 = 6 \equiv 1 \pmod{5}
```

Indeed $$38 \cdot 47 = 1786 = 5 \cdot 357 + 1$$.

:::remark[No cancelling in congruences]{#no-cancel}

Division is the exception: a common factor **cannot** always be cancelled. For example,
$$2 \cdot 3 \equiv 2 \cdot 8 \pmod{10}$$, since $$6$$ and $$16$$ differ by $$10$$, but
$$3 \not\equiv 8 \pmod{10}$$.

:::

## Using congruences

The rules above mean you can make numbers small before doing anything with them. Instead of working
out a huge number and then dividing it, replace each part by its remainder straight away, and keep
replacing as you go. The numbers never get large, and the remainder at the end is still right.

**Large powers.** Take the remainder when $$7^{100}$$ is divided by $$5$$. The number $$7^{100}$$
has $$85$$ digits, so working it out and then dividing is out of the question. Congruences find the
remainder while every number stays small.

The first step makes the base smaller. Since $$7 = 5 + 2$$, you have $$7 \equiv 2 \pmod{5}$$. By
:ref{#congruence-powers} you can raise both sides to the same power, so $$7^{100}$$ leaves the same
remainder as $$2^{100}$$.

The number $$2^{100}$$ is still far too large, so the next step looks for a power of $$2$$ that is
congruent to $$1$$. That power is useful because every power of $$1$$ is $$1$$. Here are the first
few powers of $$2$$, modulo $$5$$:

| Power        | $$2^1$$ | $$2^2$$ | $$2^3$$ | $$2^4$$ |
| ------------ | ------- | ------- | ------- | ------- |
| Value        | $$2$$   | $$4$$   | $$8$$   | $$16$$  |
| Modulo $$5$$ | $$2$$   | $$4$$   | $$3$$   | $$1$$   |

So $$2^4 \equiv 1 \pmod{5}$$. Since $$100 = 4 \cdot 25$$, the rule for a power of a power
(:ref{#power-rules}) writes $$2^{100}$$ as $$(2^4)^{25}$$. Raising $$2^4 \equiv 1$$ to the power
$$25$$ then gives the whole chain:

```math
7^{100} \equiv 2^{100} = (2^4)^{25} \equiv 1^{25} = 1 \pmod{5}
```

So $$7^{100}$$ leaves remainder $$1$$ when divided by $$5$$. The largest number in the working was
$$16$$.

**Squares divisible by 3.** The rule :ref{#squares-parity-converse} says that if $$a^2$$ is even,
then so is $$a$$. It has a version with $$3$$ in place of $$2$$.

:::proposition[Squares divisible by 3]{#squares-three}

If $$a$$ is an integer and $$3 \mid a^2$$, then $$3 \mid a$$.

:::

:::proof{source="https://proofwiki.org/wiki/Square_Modulo_3"}

The proof goes through the contrapositive (:ref{#basic-proofs/contrapositive}). Instead of showing
"if $$3 \mid a^2$$ then $$3 \mid a$$", it shows that if $$a$$ is **not** a multiple of $$3$$, then
$$a^2$$ is **not** a multiple of $$3$$ either. By :ref{#basic-proofs/contrapositive-equivalent} the
two say the same thing.

Dividing by $$3$$ (:ref{#division-remainder}), every integer has remainder $$0$$, $$1$$ or $$2$$, so
by :ref{#same-remainder} it is congruent to one of $$0$$, $$1$$ and $$2$$ modulo $$3$$.

If $$a$$ is not a multiple of $$3$$, it is in one of the last two cases. Rather than squaring
$$3k + 1$$ or $$3k + 2$$ directly, :ref{#congruence-powers} lets you square the small number it is
congruent to instead:

| $$a \pmod{3}$$ | $$a^2 \pmod{3}$$     |
| -------------- | -------------------- |
| $$0$$          | $$0^2 = 0$$          |
| $$1$$          | $$1^2 = 1$$          |
| $$2$$          | $$2^2 = 4 \equiv 1$$ |

The last row uses $$4 \equiv 1$$, because $$4 - 1 = 3$$, and then chains $$a^2 \equiv 4$$ with
$$4 \equiv 1$$ (transitivity, :ref{#congruence-equality}). So in both of the cases that matter,
$$a^2 \equiv 1 \pmod{3}$$, which by :ref{#same-remainder} means $$a^2$$ leaves remainder $$1$$ when
divided by $$3$$. A multiple of $$3$$ leaves remainder $$0$$, and a number has only one remainder
(:ref{#division-remainder}), so $$a^2$$ is not divisible by $$3$$. This proves the contrapositive,
and so proves the proposition.

:::

The same proof can be done without congruences, using the square of a sum. For $$a = 3k + 1$$ and
$$a = 3k + 2$$,

```math
\begin{aligned}
(3k + 1)^2 &= 9k^2 + 6k + 1 = 3(3k^2 + 2k) + 1 \\
(3k + 2)^2 &= 9k^2 + 12k + 4 = 3(3k^2 + 4k + 1) + 1
\end{aligned}
```

and both leave a remainder of $$1$$.

## Divisibility tests

A well-known shortcut says that a number is divisible by $$9$$ exactly when the sum of its digits
is. Congruence explains why it works, and why the same goes for $$3$$.

The key is that $$10$$ is one more than $$9$$. So $$10$$ is a nine with $$1$$ left over, $$100$$ is
$$99$$ with $$1$$ left over, and $$1000$$ is $$999$$ with $$1$$ left over. In $$4725$$, the four
thousands leave $$4$$ over once the nines are taken out, the seven hundreds leave $$7$$, the two
tens leave $$2$$, and the $$5$$ units are $$5$$. So $$4725$$ leaves the same remainder on division
by $$9$$ as $$4 + 7 + 2 + 5$$, its digit sum.

:::proposition[Digit sum test for 3 and 9]{#digit-sum-test}

Every positive integer is congruent to the sum of its digits, both modulo $$9$$ and modulo $$3$$. So
it is divisible by $$9$$ exactly when its digit sum is, and the same for $$3$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Divisibility_rule#Case_where_all_digits_are_summed"}

The plan is to write the number using its digits and powers of $$10$$, and then swap every power of
$$10$$ for $$1$$.

**Step 1: every power of $$10$$ is congruent to $$1$$.** First, $$10 \equiv 1 \pmod{9}$$, since
$$10 - 1 = 9$$. By :ref{#congruence-powers}, $$10^k \equiv 1^k = 1 \pmod{9}$$ for every positive
integer $$k$$.

**Step 2: swap them out.** A number is its digits times powers of $$10$$, added up. For example,

```math
4725 = 4 \cdot 10^3 + 7 \cdot 10^2 + 2 \cdot 10 + 5
```

By :ref{#congruence-constant}, multiplying $$10^k \equiv 1$$ by a digit keeps it true, so
$$4 \cdot 10^3 \equiv 4$$, $$7 \cdot 10^2 \equiv 7$$ and $$2 \cdot 10 \equiv 2$$. Adding these
congruences (:ref{#congruence-arithmetic}), together with $$5 \equiv 5$$, gives

```math
4725 \equiv 4 + 7 + 2 + 5 = 18 \pmod{9}
```

The same steps work for any number, however many digits it has: each digit times its power of $$10$$
is congruent to the digit alone, so the whole number is congruent to its digit sum.

**Step 3: modulo $$3$$.** Since $$10 - 1 = 9 = 3 \cdot 3$$, also $$10 \equiv 1 \pmod{3}$$, and Steps
1 and 2 work in exactly the same way modulo $$3$$.

**Step 4: divisibility.** By :ref{#same-remainder}, a number and its digit sum leave the same
remainder. So one leaves remainder $$0$$, that is, is divisible, exactly when the other does.

:::

So $$4725$$ is divisible by $$9$$, because $$18$$ is: indeed $$4725 = 9 \cdot 525$$. And
$$1{,}000{,}001$$ is not divisible by $$3$$, because its digits add up to $$2$$. The digit sum can
be taken again if it is still large: $$987654321$$ has digit sum $$45$$, which has digit sum $$9$$,
so $$987654321$$ is divisible by $$9$$.

## Exercises

:::::accordion[Exercises on congruence, with solutions]

::::exercise{#ex-congruence-sort}

Find the remainder of each number on division by $$4$$, and use the remainders to sort the numbers
into groups that are congruent modulo $$4$$:

```math
13, \qquad -3, \qquad 22, \qquad 41, \qquad -10
```

:::solution

Dividing by $$4$$ (:ref{#division-remainder}):

- $$13 = 4 \cdot 3 + 1$$, remainder $$1$$
- $$-3 = 4 \cdot (-1) + 1$$, remainder $$1$$
- $$22 = 4 \cdot 5 + 2$$, remainder $$2$$
- $$41 = 4 \cdot 10 + 1$$, remainder $$1$$
- $$-10 = 4 \cdot (-3) + 2$$, remainder $$2$$

By :ref{#same-remainder}, numbers are congruent exactly when they leave the same remainder. So the
groups are $$13, -3, 41$$ and $$22, -10$$. As a check, $$13 - (-3) = 16$$ and $$22 - (-10) = 32$$
are both multiples of $$4$$.

:::

::::

::::exercise{#ex-congruence-sum-remainder}

Find the remainder when $$2024 + 3175 + 46$$ is divided by $$6$$, without adding the numbers first.

:::solution

Replace each number by its remainder (:ref{#congruence-arithmetic}):

- $$2024 = 6 \cdot 337 + 2$$, so $$2024 \equiv 2 \pmod{6}$$
- $$3175 = 6 \cdot 529 + 1$$, so $$3175 \equiv 1 \pmod{6}$$
- $$46 = 6 \cdot 7 + 4$$, so $$46 \equiv 4 \pmod{6}$$

Adding, the sum is congruent to $$2 + 1 + 4 = 7 \equiv 1 \pmod{6}$$. So the remainder is $$1$$.
Indeed $$2024 + 3175 + 46 = 5245 = 6 \cdot 874 + 1$$.

:::

::::

::::exercise{#ex-congruence-minus-one}

Show that $$99 \equiv -1 \pmod{10}$$, and use it to find the last digit of $$99^7$$.

:::solution

$$99 - (-1) = 100 = 10 \cdot 10$$, so $$99 \equiv -1 \pmod{10}$$ (:ref{#congruence}).

By :ref{#congruence-powers}, $$99^7 \equiv (-1)^7 = -1 \pmod{10}$$. The remainder has to be between
$$0$$ and $$9$$, and $$-1 \equiv 9 \pmod{10}$$, so $$99^7$$ leaves remainder $$9$$ on division by
$$10$$. Its last digit is $$9$$.

:::

::::

::::exercise{#ex-congruence-many-answers}

Find every $$x$$ among $$0, 1, \dots, 11$$ with $$4x \equiv 8 \pmod{12}$$. Why would cancelling the
$$4$$ give the wrong answer?

:::solution

You need $$12 \mid 4x - 8$$. Checking each value, $$4x - 8$$ is a multiple of $$12$$ for:

- $$x = 2$$: $$4x - 8 = 0$$
- $$x = 5$$: $$4x - 8 = 12$$
- $$x = 8$$: $$4x - 8 = 24$$
- $$x = 11$$: $$4x - 8 = 36$$

So there are four answers: $$2$$, $$5$$, $$8$$ and $$11$$.

Cancelling the $$4$$ from both sides would give $$x \equiv 2 \pmod{12}$$, which finds only
$$x = 2$$. Common factors can't always be cancelled in a congruence (:ref{#no-cancel}), and this is
a case where cancelling loses solutions.

:::

::::

::::exercise{#ex-congruence-square-plus-one}

Prove that $$n^2 + 1$$ is never divisible by $$3$$.

:::solution

Every integer $$n$$ is congruent to $$0$$, $$1$$ or $$2$$ modulo $$3$$ (:ref{#same-remainder}).
Square each case with :ref{#congruence-powers}, then add $$1$$ with :ref{#congruence-constant}:

| $$n \pmod{3}$$ | $$n^2 \pmod{3}$$ | $$n^2 + 1 \pmod{3}$$ |
| -------------- | ---------------- | -------------------- |
| $$0$$          | $$0$$            | $$1$$                |
| $$1$$          | $$1$$            | $$2$$                |
| $$2$$          | $$4 \equiv 1$$   | $$2$$                |

So $$n^2 + 1$$ is always congruent to $$1$$ or $$2$$, never to $$0$$. A number divisible by $$3$$ is
congruent to $$0$$, so $$n^2 + 1$$ never is.

:::

::::

::::exercise{#ex-congruence-weekdays}

Today is a Wednesday. What day of the week will it be in $$100$$ days, and in $$1000$$ days?

:::solution

The days repeat every $$7$$, so only the remainder on division by $$7$$ matters.

$$100 = 7 \cdot 14 + 2$$, so $$100 \equiv 2 \pmod{7}$$. Two days after Wednesday is Friday.

$$1000 = 7 \cdot 142 + 6$$, so $$1000 \equiv 6 \pmod{7}$$. Six days after Wednesday is Tuesday.

:::

::::

::::exercise{#ex-congruence-two-thirty}

Find the remainder when $$2^{30}$$ is divided by $$9$$.

:::solution

Look for a small power of $$2$$ that is congruent to $$1$$ or $$-1$$. Here $$2^3 = 8$$, and
$$8 - (-1) = 9$$, so $$2^3 \equiv -1 \pmod{9}$$.

Since $$30 = 3 \cdot 10$$, :ref{#power-rules} gives $$2^{30} = (2^3)^{10}$$, and by
:ref{#congruence-powers}

```math
2^{30} = (2^3)^{10} \equiv (-1)^{10} = 1 \pmod{9}
```

So the remainder is $$1$$.

:::

::::

::::exercise{#ex-congruence-digit-test-practice}

Is $$7{,}452{,}183$$ divisible by $$3$$? By $$9$$? Then find the digit $$x$$ that makes the
four-digit number $$52x4$$ divisible by $$9$$.

:::solution

The digit sum is $$7 + 4 + 5 + 2 + 1 + 8 + 3 = 30$$. By :ref{#digit-sum-test}, the number is
congruent to $$30$$ modulo $$9$$ and modulo $$3$$. Since $$3 \mid 30$$ but $$9 \nmid 30$$, the
number is divisible by $$3$$ but not by $$9$$.

The digit sum of $$52x4$$ is $$5 + 2 + x + 4 = 11 + x$$. For $$9$$ to divide it, with $$x$$ between
$$0$$ and $$9$$, you need $$11 + x = 18$$, so $$x = 7$$. Indeed $$5274 = 9 \cdot 586$$.
