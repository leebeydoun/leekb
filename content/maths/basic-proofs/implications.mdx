title: If, then and exactly when

Suppose a friend tells you, "If it rains, the match is off." Later you hear that the match was
called off. It might have rained, but the referee could have been ill instead, because your friend
only said what happens when it rains.

Statements of the form "if this, then that" run all through mathematics, and mixing one up with the
statement that runs the other way is a common slip. In this guide we'll see which versions of an
"if, then" say the same thing, and how to handle statements that work in both directions.

## If, then, and turning statements around

An "if, then" statement is a promise. "If you score over $$90$$, you get an A" promises an A to
anyone scoring over $$90$$. It doesn't promise anything to someone scoring $$85$$: they might still
get an A, or they might not, and the promise isn't broken either way. The only way to break it is a
score over $$90$$ without an A.

Many statements have the form "**if** $$P$$, **then** $$Q$$". Here $$P$$ is called the
**hypothesis** (what you assume) and $$Q$$ the **conclusion** (what follows from it). Such a
statement promises only one thing: whenever $$P$$ is true, $$Q$$ is true too. It says nothing about
what happens when $$P$$ is false.

Two other statements are built from the same parts, and it is important to keep them apart. The
converse swaps the two parts round. The contrapositive swaps them and also denies both: if the
promise is "score over $$90$$ means an A", the contrapositive is "no A means you didn't score over
$$90$$", which is the same promise looked at from the other end.

:::definition[Converse and contrapositive]{#contrapositive}

For a statement "if $$P$$, then $$Q$$":

- its **converse** is "if $$Q$$, then $$P$$"
- its **contrapositive** is "if not $$Q$$, then not $$P$$"

:::

Take the true statement "if $$n$$ is a multiple of $$4$$, then $$n$$ is even".

| Version        | Statement                                                   | True? |
| -------------- | ----------------------------------------------------------- | ----- |
| Original       | if $$n$$ is a multiple of $$4$$, then $$n$$ is even         | yes   |
| Converse       | if $$n$$ is even, then $$n$$ is a multiple of $$4$$         | no    |
| Contrapositive | if $$n$$ is not even, then $$n$$ is not a multiple of $$4$$ | yes   |

The converse fails, with $$6$$ as a counterexample: it is even but not a multiple of $$4$$. A
statement and its converse are genuinely different claims, and one can be true while the other is
false. "If it is raining, the ground is wet" is true, but "if the ground is wet, it is raining" is
not: someone might have watered the garden.

Mathematics has plenty of these too. For every number $$x$$, "if $$x > 2$$, then $$x^2 > 4$$" is
true. Its converse, "if $$x^2 > 4$$, then $$x > 2$$", is false: $$x = -3$$ has $$x^2 = 9 > 4$$ but
is not greater than $$2$$. So knowing a statement is true tells you nothing about its converse; the
converse needs its own proof, or its own counterexample.

The contrapositive, on the other hand, is always true or false along with the original.

:::proposition[A statement agrees with its contrapositive]{#contrapositive-equivalent}

A statement "if $$P$$, then $$Q$$" and its contrapositive "if not $$Q$$, then not $$P$$" are either
both true or both false.

:::

:::proof{source="https://en.wikipedia.org/wiki/Contraposition#Simple_proof_by_contradiction"}

There are two things to show: if the original is true then so is the contrapositive, and the other
way round.

**If the original is true, so is the contrapositive.** Suppose "if $$P$$, then $$Q$$" is true, and
suppose $$Q$$ fails. If $$P$$ held, the original statement would make $$Q$$ hold too, but $$Q$$
fails. So $$P$$ doesn't hold. The argument started from "not $$Q$$" and reached "not $$P$$", which
is exactly what the contrapositive says.

**If the contrapositive is true, so is the original.** Take the contrapositive of the
contrapositive. The contrapositive of "if not $$Q$$, then not $$P$$" is "if not not $$P$$, then not
not $$Q$$", and since saying "not" twice cancels out, that is "if $$P$$, then $$Q$$": the original.
Now apply the first half, with the contrapositive playing the part of the original: if the
contrapositive is true, so is its own contrapositive, which is the original statement.

:::

This gives a second way to prove an "if, then" statement: prove its contrapositive instead. It is
worth doing whenever "not $$Q$$" is easier to start from than $$P$$.

:::example[Proving the contrapositive]

**Claim.** If $$3n + 2$$ is odd, then $$n$$ is odd.

Trying this directly is awkward: knowing $$3n + 2 = 2k + 1$$ gives $$3n = 2k - 1$$, and there is no
clear route from there to $$n$$. The contrapositive takes one line.

**Contrapositive.** If $$n$$ is **not** odd, then $$3n + 2$$ is **not** odd. In other words: if
$$n$$ is even, then $$3n + 2$$ is even.

**Proof of the contrapositive.** Write $$n = 2k$$. Then

```math
3n + 2 = 6k + 2 = 2(3k + 1)
```

which is even. By :ref{#contrapositive-equivalent}, the original claim is true too.

:::

The Numbers chapter uses this method to show that if $$3$$ divides $$a^2$$ then $$3$$ divides $$a$$
(:ref{#numbers/squares-three}): it is much easier to start from a number that is **not** a multiple
of $$3$$ and look at its square.

## "Only if"

There is one more way of writing "if $$P$$, then $$Q$$", and it is the one most often misread:
"$$P$$ **only if** $$Q$$". It says that $$P$$ can't happen without $$Q$$. "You can vote only if you
are registered" means that anyone voting is registered, that is, "if you vote, then you are
registered". It does **not** say that everyone registered votes.

The trouble is that the word "if" sits next to $$Q$$, so it is tempting to read "$$P$$ only if
$$Q$$" as "if $$Q$$, then $$P$$", which is the converse, a different claim. Take a number $$n$$:
"$$n$$ is a multiple of $$4$$ only if $$n$$ is even" is true, because every multiple of $$4$$ is
even. Read the wrong way round, it would say that every even number is a multiple of $$4$$, which is
false.

| Written                    | Means                |
| -------------------------- | -------------------- |
| if $$P$$, then $$Q$$       | if $$P$$, then $$Q$$ |
| $$P$$ only if $$Q$$        | if $$P$$, then $$Q$$ |
| $$P$$ if $$Q$$             | if $$Q$$, then $$P$$ |
| $$P$$ if and only if $$Q$$ | both directions      |

To avoid the confusion, these notes never use "only if" on its own. It appears only inside "if and
only if", which is the subject of the next section.

## "Exactly when"

Some tests work in both directions. A whole number is even when its last digit is $$0$$, $$2$$,
$$4$$, $$6$$ or $$8$$, and a number whose last digit is one of those is even. Each fact gives you
the other, so the two descriptions pick out exactly the same numbers. That is a much stronger link
than a one-way "if, then".

When a statement and its converse are both true, one phrase says both at once.

:::definition[Exactly when]{#exactly-when}

"$$P$$ **exactly when** $$Q$$" (also written "$$P$$ if and only if $$Q$$") means both "if $$P$$,
then $$Q$$" and "if $$Q$$, then $$P$$".

:::

So $$P$$ and $$Q$$ are true in exactly the same situations: they are two ways of saying the same
thing. Proving an "exactly when" statement therefore takes **two** proofs, one in each direction,
and a proof that only does one of them is only half finished. It helps to label the two halves
clearly.

:::example[Two directions]

**Claim.** An integer $$n$$ is even exactly when $$n + 1$$ is odd.

**If $$n$$ is even, then $$n + 1$$ is odd.** Write $$n = 2k$$. Then $$n + 1 = 2k + 1$$, which is
odd.

**If $$n + 1$$ is odd, then $$n$$ is even.** Write $$n + 1 = 2k + 1$$. Subtracting $$1$$ from both
sides gives $$n = 2k$$, which is even.

:::

Either direction can be proved by any method: one half might be direct and the other by
contrapositive.

## Exercises

:::::accordion[Exercises on if, then and exactly when, with solutions]

::::exercise{#ex-implications-broken-promise}

Take the statement "if $$n > 5$$, then $$n^2 > 20$$", about integers $$n$$. For each of $$n = 7$$,
$$n = 3$$ and $$n = -6$$, say whether the hypothesis and the conclusion hold, and whether that value
breaks the statement. Then decide whether the statement is true.

:::solution

The hypothesis is $$n > 5$$ and the conclusion is $$n^2 > 20$$. Only a value with a true hypothesis
and a false conclusion breaks the statement.

- **$$n = 7$$:** both hold, since $$49 > 20$$. Not broken.
- **$$n = 3$$:** neither holds, since $$9 < 20$$. The statement promises nothing when the hypothesis
  fails, so this is not broken.
- **$$n = -6$$:** the hypothesis fails but the conclusion holds, since $$36 > 20$$. Again, not
  broken.

The statement is true. An integer with $$n > 5$$ has $$n \ge 6$$, so $$n^2 \ge 36 > 20$$.

:::

::::

::::exercise{#ex-implications-three-versions}

For each statement, write its converse and its contrapositive, and say which of the three are true.

1. For a real number $$x$$: if $$x = 2$$, then $$x^2 = 2x$$.
2. For an integer $$n$$: if $$n$$ is odd, then $$n + 4$$ is odd.

:::solution

Using :ref{#contrapositive}:

1. - Converse: if $$x^2 = 2x$$, then $$x = 2$$. False: $$x = 0$$ gives $$0 = 0$$.
   - Contrapositive: if $$x^2 \neq 2x$$, then $$x \neq 2$$. True, like the original, since
     $$2^2 = 4 = 2 \cdot 2$$.

2. - Converse: if $$n + 4$$ is odd, then $$n$$ is odd. True: if $$n + 4 = 2k + 1$$, then
     $$n = 2(k - 2) + 1$$.
   - Contrapositive: if $$n + 4$$ is even, then $$n$$ is even. True, like the original.

   All three are true here, so "$$n$$ is odd exactly when $$n + 4$$ is odd".

In both parts the contrapositive agrees with the original (:ref{#contrapositive-equivalent}). The
converse is true in the second part and false in the first.

:::

::::

::::exercise{#ex-implications-odd-sum}

Prove that if $$n^2 + 2n$$ is odd, then $$n$$ is odd. (Hint: a direct proof is awkward.)

:::solution

Prove the contrapositive: if $$n$$ is even, then $$n^2 + 2n$$ is even. Write $$n = 2k$$. Then

```math
n^2 + 2n = 4k^2 + 4k = 2(2k^2 + 2k),
```

which is even. A statement and its contrapositive are both true or both false
(:ref{#contrapositive-equivalent}), so the original is true.

:::

::::

::::exercise{#ex-implications-odd-product}

Prove that if $$ab$$ is odd, then $$a$$ and $$b$$ are both odd, for integers $$a$$ and $$b$$.

:::solution

The opposite of "$$a$$ and $$b$$ are both odd" is "at least one of $$a$$ and $$b$$ is even". So the
contrapositive is: if at least one of $$a$$ and $$b$$ is even, then $$ab$$ is even.

Suppose $$a$$ is even, say $$a = 2k$$. Then $$ab = 2(kb)$$, which is even. If instead $$b$$ is even,
say $$b = 2l$$, then $$ab = 2(al)$$, which is even. So the contrapositive is true, and so is the
original (:ref{#contrapositive-equivalent}).

:::

::::exercise{#ex-implications-only-if-rule}

A sign says "you may enter only if you have a ticket".

1. Write the rule in the form "if …, then …".
2. Which of these people break the rule: someone with a ticket who stays outside, someone without a
   ticket who goes in, someone with a ticket who goes in?
3. For a real number $$x$$, rewrite "$$x > 0$$ if $$x^2 > 0$$" in the form "if …, then …" and say
   whether it is true.

:::solution

1. "If you enter, then you have a ticket." "$$P$$ only if $$Q$$" means "if $$P$$, then $$Q$$".
2. Only the person without a ticket who goes in breaks it. The rule promises nothing about people
   who stay outside, and someone with a ticket who goes in keeps it.
3. "$$P$$ if $$Q$$" means "if $$Q$$, then $$P$$", so this says "if $$x^2 > 0$$, then $$x > 0$$". It
   is false: $$x = -1$$ has $$x^2 = 1 > 0$$ but is not positive.

:::

::::

::::exercise{#ex-implications-both-ways}

Prove that for an integer $$n$$, the number $$5n + 3$$ is even exactly when $$n$$ is odd.

:::solution

There are two directions (:ref{#exactly-when}).

**If $$n$$ is odd, then $$5n + 3$$ is even.** Write $$n = 2k + 1$$. Then
$$5n + 3 = 10k + 8 = 2(5k + 4)$$, which is even.

**If $$5n + 3$$ is even, then $$n$$ is odd.** Prove the contrapositive: if $$n$$ is even, then
$$5n + 3$$ is odd. Write $$n = 2k$$. Then $$5n + 3 = 10k + 3 = 2(5k + 1) + 1$$, which is odd.

:::

::::

::::exercise{#ex-implications-half-proof}

A student claims "an integer $$n$$ is a multiple of $$4$$ exactly when $$n^2$$ is a multiple of
$$16$$", and proves it like this: "if $$n = 4k$$, then $$n^2 = 16k^2$$." What is missing? Supply it.

:::solution

The student proved one direction only. An "exactly when" statement also needs the converse: if
$$n^2$$ is a multiple of $$16$$, then $$n$$ is a multiple of $$4$$ (:ref{#exactly-when}).

Prove it by contrapositive: if $$n$$ is not a multiple of $$4$$, then $$n^2$$ is not a multiple of
$$16$$. Dividing by $$4$$ (:ref{#numbers/division-remainder}), such an $$n$$ is $$4k + 1$$,
$$4k + 2$$ or $$4k + 3$$:

- **$$n = 4k + 1$$ or $$4k + 3$$:** $$n$$ is odd, say $$n = 2m + 1$$. Then
  $$n^2 = 2(2m^2 + 2m) + 1$$ is odd, and an odd number is not a multiple of $$16$$.
- **$$n = 4k + 2$$:** $$n^2 = 16k^2 + 16k + 4 = 16(k^2 + k) + 4$$, which leaves remainder $$4$$ when
  divided by $$16$$.

In every case $$n^2$$ is not a multiple of $$16$$, so both directions hold and the claim is true.

:::
