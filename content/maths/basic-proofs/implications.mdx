title: If, then and exactly when

A great many statements in mathematics have the shape "if this, then that". If a number is a
multiple of $$4$$, then it is even. If $$x > 2$$, then $$x^2 > 4$$. Reading such a statement
correctly, and not mixing it up with the statement that runs the other way, is half the work of
proving it. This page shows the three statements that can be built from one "if, then", which of
them say the same thing, and how to handle statements that work in both directions.

## If, then, and turning statements around

An "if, then" statement is a promise. "If you score over $$90$$, you get an A" promises an A to
anyone scoring over $$90$$. It doesn't promise anything to someone scoring $$85$$: they might still
get an A, or they might not, and the promise isn't broken either way. The only way to break it is a
score over $$90$$ without an A.

Many statements have the form "**if** $$P$$, **then** $$Q$$". Here $$P$$ is called the
**hypothesis** (what we assume) and $$Q$$ the **conclusion** (what we then get). Such a statement
promises only one thing: whenever $$P$$ is true, $$Q$$ is true too. It says nothing about what
happens when $$P$$ is false.

Two other statements are built from the same parts, and it is important to keep them apart. The
converse swaps the two parts round. The contrapositive swaps them and also denies both: if the
promise is "score over $$90$$ means an A", the contrapositive is "no A means you didn't score over
$$90$$", which is just the same promise looked at from the other end.

:::definition[Converse and contrapositive]{#contrapositive}

For a statement "if $$P$$, then $$Q$$":

- its **converse** is "if $$Q$$, then $$P$$";
- its **contrapositive** is "if not $$Q$$, then not $$P$$".

:::

Take the true statement "if $$n$$ is a multiple of $$4$$, then $$n$$ is even".

| Version        | Statement                                                   | True? |
| -------------- | ----------------------------------------------------------- | ----- |
| Original       | if $$n$$ is a multiple of $$4$$, then $$n$$ is even         | yes   |
| Converse       | if $$n$$ is even, then $$n$$ is a multiple of $$4$$         | no    |
| Contrapositive | if $$n$$ is not even, then $$n$$ is not a multiple of $$4$$ | yes   |

The converse fails, with $$6$$ as a counterexample: it is even but not a multiple of $$4$$. A
statement and its converse are genuinely different claims, and one can be true while the other is
false. "If it is raining, the ground is wet" is true, but "if the ground is wet, it is raining" is
not: someone might have watered the garden.

Mathematics has plenty of these too. For every number $$x$$, "if $$x > 2$$, then $$x^2 > 4$$" is
true. Its converse, "if $$x^2 > 4$$, then $$x > 2$$", is false: $$x = -3$$ has $$x^2 = 9 > 4$$ but
is not greater than $$2$$. So knowing a statement is true tells you nothing about its converse; the
converse needs its own proof, or its own counterexample.

The contrapositive, on the other hand, is always true or false along with the original.

:::proposition[A statement agrees with its contrapositive]{#contrapositive-equivalent}

A statement "if $$P$$, then $$Q$$" and its contrapositive "if not $$Q$$, then not $$P$$" are either
both true or both false.

:::

:::proof{source="https://en.wikipedia.org/wiki/Contraposition#Simple_proof_by_contradiction"}

There are two things to show: if the original is true then so is the contrapositive, and the other
way round.

**If the original is true, so is the contrapositive.** Suppose "if $$P$$, then $$Q$$" is true, and
suppose $$Q$$ fails. Could $$P$$ hold? If it did, the original statement would make $$Q$$ hold too,
but $$Q$$ fails. So $$P$$ doesn't hold. We started from "not $$Q$$" and reached "not $$P$$", which
is exactly what the contrapositive says.

**If the contrapositive is true, so is the original.** Take the contrapositive of the
contrapositive. The contrapositive of "if not $$Q$$, then not $$P$$" is "if not not $$P$$, then not
not $$Q$$", and since saying "not" twice cancels out, that is just "if $$P$$, then $$Q$$": the
original. Now apply the first half, with the contrapositive playing the part of the original: if the
contrapositive is true, so is its own contrapositive, which is the original statement.

:::

This gives a second way to prove an "if, then" statement: prove its contrapositive instead. It is
worth doing whenever "not $$Q$$" is easier to start from than $$P$$.

:::example[Proving the contrapositive]

**Claim.** If $$3n + 2$$ is odd, then $$n$$ is odd.

Trying this directly is awkward: knowing $$3n + 2 = 2k + 1$$ tells us $$3n = 2k - 1$$, and it is not
obvious how to get from there to $$n$$. The contrapositive is much easier.

**Contrapositive.** If $$n$$ is **not** odd, then $$3n + 2$$ is **not** odd. In other words: if
$$n$$ is even, then $$3n + 2$$ is even.

**Proof of the contrapositive.** Write $$n = 2k$$. Then

```math
3n + 2 = 6k + 2 = 2(3k + 1)
```

which is even. By :ref{#contrapositive-equivalent}, the original claim is true too.

:::

The Numbers guide uses this method to show that if $$3$$ divides $$a^2$$ then $$3$$ divides $$a$$
(:ref{#numbers/squares-three}): it is much easier to start from a number that is **not** a multiple
of $$3$$ and look at its square.

## "Only if"

There is one more way of writing "if $$P$$, then $$Q$$", and it is the easiest to misread: "$$P$$
**only if** $$Q$$". It says that $$P$$ can't happen without $$Q$$. "You can vote only if you are
registered" means that anyone voting is registered, that is, "if you vote, then you are registered".
It does **not** say that everyone registered votes.

The trouble is that the word "if" sits next to $$Q$$, so it is tempting to read "$$P$$ only if
$$Q$$" as "if $$Q$$, then $$P$$", which is the converse, a different claim. Take a number $$n$$:
"$$n$$ is a multiple of $$4$$ only if $$n$$ is even" is true, because every multiple of $$4$$ is
even. Read the wrong way round, it would say that every even number is a multiple of $$4$$, which is
false.

| Written                    | Means                |
| -------------------------- | -------------------- |
| if $$P$$, then $$Q$$       | if $$P$$, then $$Q$$ |
| $$P$$ only if $$Q$$        | if $$P$$, then $$Q$$ |
| $$P$$ if $$Q$$             | if $$Q$$, then $$P$$ |
| $$P$$ if and only if $$Q$$ | both directions      |

To avoid the confusion, these notes never use "only if" on its own. It appears only inside "if and
only if", which is the subject of the next section.

## "Exactly when"

Some tests work in both directions. A whole number is even when its last digit is $$0$$, $$2$$,
$$4$$, $$6$$ or $$8$$, and a number whose last digit is one of those is even. Each fact gives you
the other, so the two descriptions pick out exactly the same numbers. That is a much stronger link
than a one-way "if, then".

So sometimes a statement and its converse are both true, and we want to say so in one go.

:::definition[Exactly when]{#exactly-when}

"$$P$$ **exactly when** $$Q$$" (also written "$$P$$ if and only if $$Q$$") means both "if $$P$$,
then $$Q$$" and "if $$Q$$, then $$P$$".

:::

So $$P$$ and $$Q$$ are true in exactly the same situations: they are two ways of saying the same
thing. Proving an "exactly when" statement therefore takes **two** proofs, one in each direction,
and a proof that only does one of them is only half finished. It helps to label the two halves
clearly.

:::example[Two directions]

**Claim.** An integer $$n$$ is even exactly when $$n + 1$$ is odd.

**If $$n$$ is even, then $$n + 1$$ is odd.** Write $$n = 2k$$. Then $$n + 1 = 2k + 1$$, which is
odd.

**If $$n + 1$$ is odd, then $$n$$ is even.** Write $$n + 1 = 2k + 1$$. Subtracting $$1$$ from both
sides gives $$n = 2k$$, which is even.

:::

Either direction can be proved by any method: one half might be direct and the other by
contrapositive.
