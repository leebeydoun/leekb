This page is about statements: the sentences in mathematics that make a claim you can check. It
covers what makes a sentence a statement, the words "for every" and "there is", how to state the
opposite of a claim, and the difference between equal and equivalent.

Think of a statement as a claim you could bet on. "It will rain in Paris tomorrow" is one: nobody
knows the answer yet, but tomorrow will settle the bet. "Close the window" is not, because there is
nothing to win or lose. Mathematics deals in claims of the first kind, and a proof settles the bet
for certain.

A bet only works if both sides agree on what was claimed. In everyday speech, a loose sentence is
usually fine, because the listener fills in what you meant. In mathematics, one missing word can
change who wins. "The square of a number is positive" is false, because $$0^2 = 0$$, but "the square
of a non-zero number is positive" is true.

## What a statement is

Mathematical statements work like bets, except that reasoning settles them instead of waiting to
see. "$$7$$ is bigger than $$4$$" is a true statement, and "$$7$$ is even" is a false one. Each is a
statement before you check it, because it makes a definite claim.

Letters are the usual reason a sentence makes no claim yet. You can't bet on $$x + 3 = 7$$ on its
own, because it doesn't say what $$x$$ is. It is true when $$x$$ is $$4$$ and false otherwise, so
something still has to be said about $$x$$ before it becomes a statement.

:::definition[Statement]{#statement}

A **statement** is a sentence that is either true or false. A sentence containing a letter whose
meaning hasn't been fixed, like $$x + 3 = 7$$ on its own, is not yet a statement.

:::

:::example[Statements and non-statements]

- "$$12$$ is a multiple of $$4$$" is a true statement.
- "$$15$$ is a multiple of $$4$$" is a false statement.
- "Every whole number is even" is a false statement, because $$3$$ is not even.
- "Is $$15$$ a multiple of $$4$$?" is a question, not a statement.
- "$$n$$ is a multiple of $$4$$" is not yet a statement, because $$n$$ hasn't been given a meaning.

:::

## For every, there is and there is no

Three phrases turn a sentence with a letter into a statement: "for every", "there is" and "there is
no". "For every number $$x$$, $$x + 0 = x$$" claims something about all values of $$x$$. "There is a
number $$x$$ with $$x + 3 = 7$$" claims that at least one value works.

These two claims need different evidence. A "for every" claim must hold in every case, so one
failure makes it false. A "there is" claim needs only one success, so a single example proves it.
"There is no" is the opposite of "there is": "there is no whole number $$n$$ with $$n^2 = 10$$" says
that every whole number fails.

The phrase in front decides whether the same sentence becomes true or false. Take "$$n$$ is a
multiple of $$3$$", about whole numbers $$n$$:

- "There is a whole number $$n$$ that is a multiple of $$3$$" is true, since $$6$$ is one.
- "Every whole number $$n$$ is a multiple of $$3$$" is false, since $$4$$ isn't.
- "There is no whole number $$n$$ that is a multiple of $$3$$" is false, since $$6$$ is one.

:::definition[For every and there is]{#quantifiers}

Let $$P(x)$$ be a sentence about $$x$$.

- "**For every** $$x$$, $$P(x)$$" means that $$P(x)$$ is true whatever $$x$$ is. It is also written
  "for all $$x$$" or $$\forall x$$.
- "**There is** an $$x$$ with $$P(x)$$" means that $$P(x)$$ is true for at least one $$x$$. It is
  also written "there exists", "for some $$x$$" or $$\exists x$$.
- "**There is no** $$x$$ with $$P(x)$$" means that $$P(x)$$ is false for every $$x$$.

These phrases are called **quantifiers**, because they say how many values the claim is about.

:::

## The opposite of a statement

To state the opposite of a "for every" or "there is" claim, you swap the quantifier. The opposite of
"every student passed" is "some student failed", not "every student failed". The opposite of "there
is a student who passed" is "every student failed".

This rule is why counterexamples work (:ref{#counterexample}). To show that a "for every" claim is
false, you only need one case where it fails.

:::remark[The opposite of a quantified statement]{#statement-negation}

- The opposite of "for every $$x$$, $$P(x)$$" is "there is an $$x$$ for which $$P(x)$$ is false".
- The opposite of "there is an $$x$$ with $$P(x)$$" is "for every $$x$$, $$P(x)$$ is false", that
  is, "there is no $$x$$ with $$P(x)$$".

::see-also{src="https://en.wikipedia.org/wiki/Quantifier_(logic)#Equivalent_expressions"}

:::

"And" needs the same care. "$$m$$ and $$n$$ are both even" is false as soon as either one is odd. So
its opposite is "at least one of $$m$$ and $$n$$ is odd", not "both are odd". In general, the
opposite of "$$P$$ and $$Q$$" is "not $$P$$, or not $$Q$$".

:ref{#contradiction} starts by supposing that a statement is false. So it works exactly when you
state the opposite correctly.

## Saying which numbers are allowed

Whether a claim about "a number $$x$$" is true can depend on which numbers are allowed. "There is a
number $$x$$ with $$3x = 4$$" is false if only whole numbers count. It is true if fractions are
allowed, since $$x = \frac{4}{3}$$ works.

The same happens with $$x^2 = 3$$. "There is a fraction $$x$$ with $$x^2 = 3$$" is false
(:ref{#numbers/sqrt-three}), but "there is a real number $$x$$ with $$x^2 = 3$$" is true, since
$$\sqrt{3}$$ works. The equation is the same in both claims, and only the kind of number differs.

So a careful statement says what kind of thing each letter is, as in "let $$n$$ be a whole number"
or "for every real number $$x$$". You can leave this out when the surrounding text makes it clear.
When there is any doubt, say it.

## Writing maths in full sentences

Because a bare equation isn't a statement, mathematics is written in complete sentences, with the
symbols as part of them. Compare these two lines:

```math
x^2 = 9 \qquad x = 3
```

The reader can't tell how the second equation relates to the first. It might follow from the first,
be an assumption, or be one possibility among several. The sentence "if $$x^2 = 9$$, then $$x = 3$$
or $$x = -3$$" says exactly what is claimed, and it is true.

The two equations alone also hide a mistake. "If $$x^2 = 9$$, then $$x = 3$$" is false, because
$$x = -3$$ also works. Linking words like "so", "if … then", "for every" and "there is" turn a list
of symbols into an argument that a reader can check.

Instructions need the same care. "Solve $$x^2 = 9$$" means: find every number $$x$$ for which
$$x^2 = 9$$ is true. Finding $$3$$ is not enough. A full answer is "$$x = 3$$ or $$x = -3$$",
together with a reason why there are no others.

## Equal and equivalent

"Equal" and "equivalent" sound alike, but they compare different kinds of thing. Equal compares two
numbers. Equivalent compares two statements.

### Equal means the same number

The sign $$=$$ says that two expressions name the same number. $$4 \cdot 3 = 20 - 8$$ is true
because both sides work out to $$12$$. The two sides look nothing alike, and that doesn't matter:
equality is about the value, not the way it is written. In the same way, $$0.5 = \frac{1}{2}$$.

### Equivalent means true at the same times

A statement isn't a number, so it can't be equal to another statement. The useful question is
whether two statements are always true or false together. Try "$$x + 3 = 7$$" and "$$x = 4$$" for
different values of $$x$$. When $$x$$ is $$4$$, both are true, and for every other value, both are
false.

In the language of bets, equivalent statements always win or lose together. They can say quite
different things in words, but you can never find a value that makes one true and the other false.

:::definition[Equivalent statements]{#equivalent-statements}

Two statements are **equivalent** if each is true exactly when the other is: whenever one is true,
so is the other, and whenever one is false, so is the other. This is the same as saying "the first
is true exactly when the second is" (:ref{#exactly-when}).

:::

Solving an equation depends on this idea. Each step replaces the equation with an equivalent one
that is shorter, so no solution is lost and none is added along the way.

:::example[Equivalent and not equivalent]

For a real number $$x$$:

- "$$3x - 1 = 8$$" and "$$x = 3$$" are equivalent. Adding $$1$$ and dividing by $$3$$ gets from the
  first to the second, and multiplying by $$3$$ and taking away $$1$$ gets back.
- "$$x = 5$$" and "$$x^2 = 25$$" are not equivalent. The first leads to the second, but not the
  other way: $$x = -5$$ makes the second true and the first false.

:::

An equation contains an equals sign, which makes the two ideas easy to mix up. Saying that
"$$x + 3 = 7$$" is equivalent to "$$x = 4$$" doesn't claim that any two numbers are equal. It claims
that the two equations are true for exactly the same values of $$x$$. The table puts the two side by
side:

|          | Equal                                | Equivalent                                   |
| -------- | ------------------------------------ | -------------------------------------------- |
| Compares | Two numbers, or expressions for them | Two statements                               |
| Means    | They have the same value             | They are true for exactly the same values    |
| Written  | $$=$$                                | "exactly when", or "is equivalent to"        |
| Example  | $$4 \cdot 3 = 20 - 8$$               | "$$x + 3 = 7$$" is equivalent to "$$x = 4$$" |

## Different letters can name the same number

A statement that begins "let $$x$$ and $$y$$ be numbers" allows $$x$$ and $$y$$ to be equal.
Different letters are different names, and two names can belong to the same number. So a rule proved
for any numbers $$x$$ and $$y$$ also covers the case $$x = y$$. For example, $$xy = yx$$ holds for
any $$x$$ and $$y$$, including when both are $$7$$.

To rule out that case, the statement has to say so: "let $$x$$ and $$y$$ be distinct numbers", or
"let $$x$$ and $$y$$ be numbers with $$x \neq y$$". This matters whenever an argument divides by
$$x - y$$, because $$x - y$$ is $$0$$ when $$x = y$$.

:::example[Why "distinct" matters]

The statement "for any numbers $$x$$ and $$y$$, $$\frac{x^2 - y^2}{x - y} = x + y$$" is false. When
$$x = y$$, the left side divides by $$0$$ and has no value.

The statement "for any distinct numbers $$x$$ and $$y$$, $$\frac{x^2 - y^2}{x - y} = x + y$$" is
true. The top factors as $$x^2 - y^2 = (x - y)(x + y)$$, and $$x - y$$ is not $$0$$, so it cancels.

:::

## Exercises

:::::accordion[Exercises on statements, with solutions]

::::exercise{#ex-statements-which-claim}

Which of these are statements? For each one that is, say whether it is true or false.

1. $$17$$ is a prime number.
2. $$x^2 - 4 = 0$$.
3. For every real number $$x$$, $$x^2 - 4 = 0$$.
4. There is a real number $$x$$ with $$x^2 - 4 = 0$$.
5. Let $$n$$ be an even number.

:::solution

1. A statement, and true: the only positive divisors of $$17$$ are $$1$$ and $$17$$.
2. Not yet a statement, because $$x$$ hasn't been given a meaning (:ref{#statement}). It is true for
   some values of $$x$$ and false for others.
3. A statement, and false: $$x = 0$$ gives $$0 - 4 = -4$$, which is not $$0$$.
4. A statement, and true: $$x = 2$$ gives $$4 - 4 = 0$$.
5. Not a statement. It introduces the letter $$n$$ and says what kind of number it is, but it claims
   nothing that could be true or false.

Parts 2, 3 and 4 use the same equation. The words in front of it are what turn it into a claim, and
they decide whether the claim is true (:ref{#quantifiers}).

:::

::::

::::exercise{#ex-statements-three-phrases}

For each sentence about an integer $$n$$, say which of "for every integer $$n$$", "there is an
integer $$n$$ with" and "there is no integer $$n$$ with" make it a true statement. More than one may
work.

1. $$n^2 = n$$
2. $$n^2 + 1 > 0$$
3. $$2n = 5$$

:::solution

1. Only "there is" works. $$n = 0$$ and $$n = 1$$ both satisfy $$n^2 = n$$, so "there is no" is
   false. $$n = 2$$ gives $$4 \neq 2$$, so "for every" is false.
2. "For every" and "there is" both work. A square is never negative, so $$n^2 + 1 \ge 1 > 0$$ for
   every $$n$$, and in particular for at least one. "There is no" is false.
3. Only "there is no" works. $$2n$$ is even, and $$5$$ is odd, so no integer has $$2n = 5$$.

When a "for every" claim is true, the matching "there is" claim is true as well, provided there is
at least one integer to check. The reverse fails, as the first sentence shows.

:::

::::

::::exercise{#ex-statements-opposites}

Write down the opposite of each statement without starting with "it is not true that". Then say
which of the two is true.

1. Every student in the class owns a phone and a laptop.
2. There is a prime number that is even.
3. For every real number $$x$$, $$x^2 \ge x$$.

:::solution

By :ref{#statement-negation}, "every" turns into "some … fails", and "there is" turns into "there is
no".

1. Opposite: "some student in the class doesn't own a phone, or doesn't own a laptop". The opposite
   of "$$P$$ and $$Q$$" is "not $$P$$, or not $$Q$$", so one missing item is enough. Which is true
   depends on the class.
2. Opposite: "no prime number is even", that is, "every prime number is odd". The original is true,
   since $$2$$ is prime and even.
3. Opposite: "there is a real number $$x$$ with $$x^2 < x$$". The opposite is true:
   $$x = \frac{1}{2}$$ gives $$x^2 = \frac{1}{4}$$, which is less than $$\frac{1}{2}$$.

For integers, the third statement would be true instead, since an integer squared is never smaller
than the integer. Which numbers are allowed is part of the claim.

:::

::::

::::exercise{#ex-statements-which-numbers}

Say whether each statement is true when $$x$$ must be a whole number $$0, 1, 2, \dots$$, when $$x$$
may be any integer, and when $$x$$ may be any fraction.

1. There is an $$x$$ with $$x + 5 = 2$$.
2. There is an $$x$$ with $$4x^2 = 9$$.

:::solution

1. Whole numbers: false, since $$x + 5 \ge 5$$ when $$x \ge 0$$. Integers: true, since $$x = -3$$
   works. Fractions: true, since $$-3 = \frac{-3}{1}$$ is a fraction.
2. Whole numbers and integers: false. $$4 \cdot 1^2 = 4$$ and $$4 \cdot 2^2 = 16$$, so no integer
   gives $$9$$, and a negative integer gives the same value as its positive partner. Fractions:
   true, since $$x = \frac{3}{2}$$ gives $$4 \cdot \frac{9}{4} = 9$$.

The equations stay the same in every case. Only the kind of number allowed changes, and with it the
answer.

:::

::::

::::exercise{#ex-statements-lost-solution}

A student solves $$x(x - 2) = 3x$$ like this: "Divide both sides by $$x$$ to get $$x - 2 = 3$$, so
$$x = 5$$." What has gone wrong, and what is the full answer?

:::solution

Dividing by $$x$$ is allowed exactly when $$x \neq 0$$, and the student never checked that case.
Here $$x = 0$$ is a solution: both sides are $$0$$. So the step lost a solution, and the two
equations are not equivalent (:ref{#equivalent-statements}).

To solve it properly, take $$3x$$ from both sides: $$x(x - 2) - 3x = 0$$, which is $$x(x - 5) = 0$$.
A product is $$0$$ exactly when one of its factors is (:ref{#numbers/zero-product}), so the full
answer is "$$x = 0$$ or $$x = 5$$". "Solve" asks for every solution, not only one.

:::

::::

::::exercise{#ex-statements-equal-or-equivalent}

Fill each gap with "equal" or "equivalent", or say that neither fits. Here $$x$$ is a real number.

1. The numbers $$\frac{2}{4}$$ and $$0.5$$ are \_\_\_.
2. The statements "$$x - 1 = 4$$" and "$$x = 5$$" are \_\_\_.
3. For every $$x$$, the numbers $$(x + 1)^2$$ and $$x^2 + 2x + 1$$ are \_\_\_.
4. The statements "$$x^2 = 1$$" and "$$x = 1$$" are \_\_\_.

:::solution

1. Equal: both name the number one half.
2. Equivalent: each is true exactly when the other is, since adding $$1$$ or taking it away moves
   between them (:ref{#equivalent-statements}).
3. Equal: multiplying out gives the same number whatever $$x$$ is. These are numbers, not
   statements, so "equivalent" doesn't apply.
4. Neither. They are statements, so they can't be equal, and $$x = -1$$ makes the first true and the
   second false, so they aren't equivalent.

:::

::::

::::exercise{#ex-statements-distinct-cubes}

Is "for any numbers $$a$$ and $$b$$, $$\frac{a^3 - b^3}{a - b} = a^2 + ab + b^2$$" true? If not,
change it into a true statement and prove that.

:::solution

It is false. Different letters may name the same number, and when $$a = b$$ the left side divides by
$$0$$ and has no value.

The statement "for any distinct numbers $$a$$ and $$b$$,
$$\frac{a^3 - b^3}{a - b} = a^2 + ab + b^2$$" is true. Multiplying out,

```math
(a - b)(a^2 + ab + b^2) = a^3 + a^2 b + ab^2 - a^2 b - ab^2 - b^3 = a^3 - b^3.
```

Since $$a \neq b$$, the number $$a - b$$ is not $$0$$, so dividing both sides by it gives the
formula.

:::
