Think of the guest list for a party. One person might write it as "everyone in my class" and another
as a list of names, and both could mean exactly the same people. Mathematics talks about collections
like this all the time, such as all the integers or all the solutions of an equation. A **set** is a
name for such a collection.

In this guide we'll learn a few symbols that make statements about sets short and exact, and a
standard way to check whether two descriptions give the same set.

## Sets and elements

Think of a set as a bag of things. All that matters about a bag is what is in it: there is no first
or last item, and putting the same thing in twice doesn't give two of it. For any object, the one
thing to ask is whether it is in the bag, and the answer is yes or no.

:::definition[Sets and elements]{#set}

A **set** is a collection of objects, called its **elements**. The symbol $$x \in S$$ means "$$x$$
is an element of $$S$$", read "$$x$$ is in $$S$$". The symbol $$x \notin S$$ means "$$x$$ is not an
element of $$S$$".

Two sets are **equal** when they have exactly the same elements.

:::

:::example[Membership]

Let $$S = \{2, 3, 5, 7\}$$, the set of primes below $$10$$. Then $$5 \in S$$ and $$4 \notin S$$.

The sets $$\{7, 5, 3, 2\}$$ and $$\{2, 2, 3, 5, 7\}$$ are both equal to $$S$$: they have the same
elements, and neither order nor repeats count.

:::

## Describing a set

A small set can be written out in full, between curly brackets: $$\{1, 2, 3\}$$. When there is a
clear pattern, dots continue it, as in $$\{2, 4, 6, 8, \dots\}$$ for the positive even numbers.

Most sets in mathematics are too big to list, or have no clear pattern. So instead the set is given
by a **test** that decides membership. The set

```math
\{x : x^2 = 9\}
```

is read "the set of all $$x$$ such that $$x^2 = 9$$". Its elements are exactly the objects that pass
the test, which are $$3$$ and $$-3$$, so it equals $$\{-3, 3\}$$. The letter is only a placeholder:
$$\{t : t^2 = 9\}$$ is the same set.

The test should also say what kind of object is allowed in, because that can change the answer.
Writing $$\mathbb{Z}$$ for the integers and $$\mathbb{R}$$ for the real numbers,

```math
\{x \in \mathbb{Z} : 0 < x < 4\} = \{1, 2, 3\},
```

while $$\{x \in \mathbb{R} : 0 < x < 4\}$$ holds every real number strictly between $$0$$ and $$4$$,
the interval $$(0, 4)$$ (:ref{#real-numbers/interval}).

A test like this also says clearly what solving means. The **solution set** of an equation or
inequality is the set of numbers that make it true, and solving is the job of describing that set
plainly. For example, $$\{x \in \mathbb{R} : x^2 - 5x + 6 = 0\} = \{2, 3\}$$, and
$$\{x \in \mathbb{R} : 2x - 1 > 5\}$$ is the interval $$(3, \infty)$$.

## The number systems as sets

The kinds of number built in the later chapters each form a set, with a standard name:

| Set            | Elements                                                                               |
| -------------- | -------------------------------------------------------------------------------------- |
| $$\mathbb{Z}$$ | the [integers](../numbers/integers.mdx): $$\dots, -2, -1, 0, 1, 2, \dots$$             |
| $$\mathbb{Q}$$ | the [rational numbers](../numbers/rational-numbers.mdx), the fractions $$\frac{m}{n}$$ |
| $$\mathbb{R}$$ | the [real numbers](../real-numbers/real-line.mdx), every point of the number line      |

So $$-3 \in \mathbb{Z}$$ but $$\frac{1}{2} \notin \mathbb{Z}$$, while
$$\frac{1}{2} \in \mathbb{Q}$$. And $$\sqrt{2} \in \mathbb{R}$$, but $$\sqrt{2} \notin \mathbb{Q}$$,
since no fraction squares to $$2$$ (:ref{#numbers/sqrt-two}). The counting numbers
$$1, 2, 3, \dots$$ are sometimes written $$\mathbb{N}$$, but books disagree about whether $$0$$
belongs, so these notes write them out instead.

## Subsets

One bag can sit inside another: if everything in the small bag is also in the big one, the small
bag's contents are part of the big bag's. Sets work the same way. Every integer is a fraction, and
every fraction is a real number, so the integers sit inside the rational numbers, which sit inside
the real numbers.

:::definition[Subset]{#subset}

A set $$A$$ is a **subset** of a set $$B$$, written $$A \subseteq B$$, when every element of $$A$$
is also an element of $$B$$.

:::

So $$\mathbb{Z} \subseteq \mathbb{Q} \subseteq \mathbb{R}$$. The definition doesn't ask for $$B$$ to
have anything extra, so every set is a subset of itself: $$A \subseteq A$$.

"Every element of $$A$$ is in $$B$$" is a statement about every element at once, so it is proved in
the usual way: take an element of $$A$$ that could be **any** element, and show it is in $$B$$. To
show that $$A$$ is **not** a subset of $$B$$, one element of $$A$$ outside $$B$$ is enough. It is a
counterexample (:ref{#counterexample}).

:::example[Proving a subset, and disproving one]

Let $$A = \{x \in \mathbb{R} : x > 5\}$$ and $$B = \{x \in \mathbb{R} : x > 2\}$$.

**$$A \subseteq B$$.** Take any $$x \in A$$. Then $$x > 5$$, and $$5 > 2$$, so $$x > 2$$. That means
$$x \in B$$.

**$$B$$ is not a subset of $$A$$.** The number $$3$$ is in $$B$$, since $$3 > 2$$, but not in $$A$$,
since $$3$$ is not bigger than $$5$$.

:::

Keep "element of" and "subset of" apart. The number $$2$$ is an **element** of $$\{1, 2, 3\}$$,
while the set $$\{2\}$$, a bag holding only $$2$$, is a **subset** of it. So $$2 \in \{1, 2, 3\}$$
and $$\{2\} \subseteq \{1, 2, 3\}$$, but $$2$$ is not a subset of anything, since it is a number,
not a set.

## The empty set

Sometimes a test is one that nothing passes: no real number squares to $$-1$$, and no whole number
lies strictly between $$3$$ and $$4$$. The collection of things passing such a test is still a
perfectly good set. It has nothing in it, like an empty bag. This is useful, because it lets "this
equation has no solutions" be said as "its solution set is empty".

:::definition[The empty set]{#empty-set}

The **empty set**, written $$\varnothing$$, is the set with no elements.

:::

For example,

```math
\{x \in \mathbb{R} : x^2 = -1\} = \varnothing \quad\text{and}\quad \{x \in \mathbb{Z} : 2x = 7\} = \varnothing.
```

These are the same set, even though the tests look nothing alike. Two sets with no elements have
exactly the same elements, namely none, so they are equal. That is why you can say **the** empty
set.

The empty set is not the same as $$\{0\}$$. The set $$\{0\}$$ has one element, the number $$0$$; the
empty set has none.

The empty set is a subset of $$\{1, 2, 3\}$$. To fail to be one, it would need an element that is
not in $$\{1, 2, 3\}$$, and it has no elements at all. So there is nothing that could go wrong.

:::proposition[The empty set is a subset of every set]{#set-empty-subset}

For every set $$A$$, $$\varnothing \subseteq A$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Set_(mathematics)#Properties_of_containment"}

Suppose $$\varnothing$$ were not a subset of $$A$$. Then some element of $$\varnothing$$ would not
be in $$A$$. But $$\varnothing$$ has no elements, so this is impossible (:ref{#contradiction}).
Hence $$\varnothing \subseteq A$$.

:::

## Proving two sets are equal

A set can be described in different ways: by a list, by a test, or by two tests that look quite
different. When two descriptions might give the same set, the way to check is to compare contents in
both directions. Everything in the first bag must be in the second, **and** everything in the second
must be in the first. Either check alone is not enough, since a small bag fits inside a big one
without the two being the same.

:::proposition[Equal sets are subsets of each other]{#set-equality}

For sets $$A$$ and $$B$$, $$A = B$$ exactly when $$A \subseteq B$$ and $$B \subseteq A$$.

:::

:::proof{source="https://en.wikipedia.org/wiki/Set_(mathematics)#Properties_of_containment"}

This is an "exactly when" statement, so there are two directions to prove (:ref{#exactly-when}).

**If $$A = B$$, then $$A \subseteq B$$ and $$B \subseteq A$$.** Equal sets have the same elements
(:ref{#set}). So every element of $$A$$ is an element of $$B$$, which is $$A \subseteq B$$, and
every element of $$B$$ is an element of $$A$$, which is $$B \subseteq A$$.

**If $$A \subseteq B$$ and $$B \subseteq A$$, then $$A = B$$.** By the first, every element of $$A$$
is in $$B$$. By the second, every element of $$B$$ is in $$A$$. So an object is in $$A$$ exactly
when it is in $$B$$: the two sets have the same elements, and so they are equal.

:::

:::example[A set described two ways]

Let $$A = \{n \in \mathbb{Z} : n^2 = n\}$$ and $$B = \{0, 1\}$$. Here is a proof that $$A = B$$.

**$$A \subseteq B$$.** Take any $$n \in A$$, so $$n^2 = n$$. Then $$n^2 - n = 0$$, that is,
$$n(n - 1) = 0$$. If a product is $$0$$, one of its factors is (:ref{#numbers/zero-product}), so
$$n = 0$$ or $$n - 1 = 0$$. Either way $$n \in B$$.

**$$B \subseteq A$$.** Both elements of $$B$$ pass the test: $$0^2 = 0$$ and $$1^2 = 1$$.

So $$A = B$$ by :ref{#set-equality}.

:::

This example shows the two halves of solving an equation. Working from the equation to a list of
candidates, as in the first half, shows that every solution is on the list: the solution set is a
**subset** of the list. Checking each candidate in the equation, as in the second half, shows that
every candidate is a solution. Only both together show that the list is exactly the solution set.
The check matters because some steps, like squaring both sides, can add candidates that are not
solutions.

## Union and intersection

Two sets can be put together in two ways: everything in either one, or only what they share. A class
trip lists the pupils who chose the museum and the pupils who chose the zoo. The pupils on at least
one list form one set, and the pupils on both lists form another.

:::definition[Union and intersection]{#union-intersection}

Let $$A$$ and $$B$$ be sets. Their **union** $$A \cup B$$ is the set of elements in $$A$$ or in
$$B$$ (or in both). Their **intersection** $$A \cap B$$ is the set of elements in both $$A$$ and
$$B$$.

:::

For example, $$\{1, 2, 3\} \cup \{3, 4\} = \{1, 2, 3, 4\}$$ and
$$\{1, 2, 3\} \cap \{3, 4\} = \{3\}$$. Two sets with no element in common, such as $$\{1, 2\}$$ and
$$\{5\}$$, have the empty set as their intersection. Unions come up whenever an answer is made of
separate pieces: the [Solving inequalities](../real-numbers/inequalities.mdx) guide writes the
numbers less than $$-1$$ or greater than $$2$$ as $$(-\infty, -1) \cup (2, \infty)$$.

The word "or" in the definition includes the elements in both sets, as it does in a statement "$$P$$
or $$Q$$", which is true when at least one of them is. So $$A \cap B$$ is always a subset of
$$A \cup B$$.

## Exercises

:::::accordion[Exercises on sets, with solutions]

::::exercise{#ex-sets-list}

Write out each set by listing its elements.

1. $$\{n \in \mathbb{Z} : -2 \le n < 3\}$$
2. $$\{x \in \mathbb{R} : x^2 = 4x\}$$
3. $$\{n \in \mathbb{Z} : n^2 = 2\}$$
4. The set of positive integers that divide $$12$$

:::solution

1. $$\{-2, -1, 0, 1, 2\}$$. The test includes $$-2$$ but not $$3$$.
2. $$\{0, 4\}$$. The equation is $$x^2 - 4x = 0$$, that is, $$x(x - 4) = 0$$, so $$x = 0$$ or
   $$x = 4$$ (:ref{#numbers/zero-product}), and both pass the test.
3. $$\varnothing$$. $$1^2 = 1$$ and $$2^2 = 4$$, so no integer squares to $$2$$ (:ref{#empty-set}).
4. $$\{1, 2, 3, 4, 6, 12\}$$.

:::

::::exercise{#ex-sets-same-or-not}

Which of these pairs are equal sets?

1. $$\{1, 2, 3\}$$ and $$\{3, 1, 2, 1\}$$
2. $$\{0\}$$ and $$\varnothing$$
3. $$\{x \in \mathbb{R} : x^2 = 1\}$$ and $$\{-1, 1\}$$
4. $$\{x \in \mathbb{Z} : 0 < x < 1\}$$ and $$\{x \in \mathbb{Z} : x^2 < 0\}$$

:::solution

Two sets are equal when they have the same elements (:ref{#set}).

1. Equal. Order and repeats don't count, and both have the elements $$1$$, $$2$$ and $$3$$.
2. Not equal. $$\{0\}$$ has one element, the number $$0$$, and $$\varnothing$$ has none.
3. Equal. The real numbers that square to $$1$$ are exactly $$-1$$ and $$1$$.
4. Equal. No integer lies strictly between $$0$$ and $$1$$, and no integer has a negative square, so
   both are $$\varnothing$$.

:::

::::

::::exercise{#ex-sets-in-or-inside}

Let $$A = \{1, \{2\}, 3\}$$. This set has three elements, and one of them is itself a set. Which of
these are true?

1. $$1 \in A$$
2. $$2 \in A$$
3. $$\{2\} \in A$$
4. $$\{1\} \subseteq A$$
5. $$\{2\} \subseteq A$$
6. $$\{\{2\}\} \subseteq A$$

:::solution

1. True: $$1$$ is listed.
2. False: the number $$2$$ is not one of the three elements. The set $$\{2\}$$ is.
3. True: $$\{2\}$$ is listed as an element.
4. True: the only element of $$\{1\}$$ is $$1$$, which is in $$A$$ (:ref{#subset}).
5. False: the only element of $$\{2\}$$ is the number $$2$$, which is not in $$A$$.
6. True: the only element of $$\{\{2\}\}$$ is the set $$\{2\}$$, which is in $$A$$.

"Is in" asks whether an object is one of the elements. "Is a subset of" asks whether every element
of one set is an element of the other.

:::

::::

::::exercise{#ex-sets-subset-squares}

Let $$A = \{x \in \mathbb{R} : x > 3\}$$ and $$B = \{x \in \mathbb{R} : x^2 > 9\}$$. Prove that
$$A \subseteq B$$, and show that $$B$$ is not a subset of $$A$$.

:::solution

**$$A \subseteq B$$.** Take any $$x \in A$$, so $$x > 3$$. Multiplying $$x > 3$$ by the positive
number $$x$$ gives $$x^2 > 3x$$, and multiplying $$x > 3$$ by $$3$$ gives $$3x > 9$$ (part 4 of
:ref{#real-numbers/inequality-rules}). Chaining these, $$x^2 > 9$$, so $$x \in B$$.

**$$B$$ is not a subset of $$A$$.** The number $$-4$$ has $$(-4)^2 = 16 > 9$$, so $$-4 \in B$$, but
$$-4$$ is not bigger than $$3$$, so $$-4 \notin A$$. One element of $$B$$ outside $$A$$ is a
counterexample (:ref{#counterexample}).

:::

::::

::::exercise{#ex-sets-all-subsets}

List every subset of $$\{1, 2\}$$. How many are there?

:::solution

There are four:

```math
\varnothing, \quad \{1\}, \quad \{2\}, \quad \{1, 2\}.
```

The empty set counts, because it is a subset of every set (:ref{#set-empty-subset}). The set
$$\{1, 2\}$$ itself counts, because every set is a subset of itself. Each subset is fixed by
answering two yes or no questions, "is $$1$$ in it?" and "is $$2$$ in it?", which gives
$$2 \cdot 2 = 4$$ choices.

:::

::::

::::exercise{#ex-sets-solution-set}

Prove that $$\{x \in \mathbb{R} : x(x - 2) = 3\} = \{-1, 3\}$$.

:::solution

Call the first set $$A$$ and the second $$B$$. By :ref{#set-equality}, show each is a subset of the
other.

**$$A \subseteq B$$.** Take any $$x \in A$$, so $$x(x - 2) = 3$$. Then $$x^2 - 2x - 3 = 0$$, which
factors as $$(x - 3)(x + 1) = 0$$. A product is $$0$$ exactly when one of its factors is
(:ref{#numbers/zero-product}), so $$x = 3$$ or $$x = -1$$. Either way $$x \in B$$.

**$$B \subseteq A$$.** Check both elements: $$(-1)(-1 - 2) = (-1)(-3) = 3$$ and
$$3 \cdot (3 - 2) = 3$$.

So $$A = B$$. The first half shows every solution is on the list, and the second shows every number
on the list is a solution.

:::

::::

::::exercise{#ex-sets-two-tests}

Let $$A$$ be the set of integers that are multiples of $$4$$, and
$$B = \{n \in \mathbb{Z} : n^2 \text{ is a multiple of } 8\}$$. Prove that $$A = B$$. You may use
the fact, shown in the proof by contradiction section of [What a proof is](./proofs.mdx), that if
$$m^2$$ is even then $$m$$ is even.

:::solution

By :ref{#set-equality}, show each is a subset of the other.

**$$A \subseteq B$$.** Take any $$n \in A$$, so $$n = 4k$$. Then $$n^2 = 16k^2 = 8(2k^2)$$, a
multiple of $$8$$, so $$n \in B$$.

**$$B \subseteq A$$.** Take any $$n \in B$$, so $$n^2 = 8j$$ for some integer $$j$$. Then $$n^2$$ is
even, so $$n$$ is even: $$n = 2m$$. Now $$4m^2 = 8j$$, so $$m^2 = 2j$$ is even, and so $$m$$ is even
too: $$m = 2l$$. That makes $$n = 4l$$, a multiple of $$4$$, so $$n \in A$$.

So $$A = B$$, although the two tests look quite different.

:::

::::

::::exercise{#ex-sets-union}

Let $$A = \{n \in \mathbb{Z} : 1 \le n \le 6\}$$ and let $$B$$ be the set of even integers. List the
elements of $$A \cap B$$, and explain why $$A \cup B$$ can't be written out in full.

:::solution

$$A = \{1, 2, 3, 4, 5, 6\}$$, and its even elements are $$2$$, $$4$$ and $$6$$, so
$$A \cap B = \{2, 4, 6\}$$ (:ref{#union-intersection}). The union $$A \cup B$$ contains every even
integer, and there are infinitely many of those, so no finite list holds them all. It can still be
described: $$A \cup B = \{1, 3, 5\} \cup B$$, the even integers together with $$1$$, $$3$$ and
$$5$$.

:::
