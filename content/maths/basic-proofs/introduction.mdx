Suppose someone tells you that two odd numbers always add up to an even number. You try $$3 + 5$$
and $$7 + 11$$, and both work, but a few examples can't tell you it works for every pair. A
**proof** can, because it's an argument that settles the claim for every case at once.

Before you can prove something, though, you need to say exactly what is claimed. A precise
**statement** is either **true** or **false**, with no room to argue about what it meant.

Every later chapter is built on these two tools. This chapter is not a list of proof tricks to
memorise. It is a route through four skills:

1. **Read the claim:** identify the allowed objects, the words "every" or "there is", and exactly
   what is being claimed.
2. **Find its shape:** decide whether it is a direct claim, an if–then statement, an equality of
   sets, or a claim indexed by whole numbers.
3. **Plan the proof:** write what is given, what must be shown, and the definition or earlier fact
   that could bridge the gap.
4. **Audit the argument:** check every case, every letter and every reason.

Reading a proof and writing one are different skills. The guides first show how a proof works, then
give increasingly independent practice in constructing one.

## Guides in this chapter

Follow the guides in this order. Each one supplies language or a method used by the next:

1. [Statements](./statements.mdx): identify the domain, quantifier and property in a precise claim
2. [If, then and exactly when](./implications.mdx): identify hypotheses and conclusions, then keep
   converses and contrapositives apart
3. [What a proof is](./proofs.mdx): plan direct proofs with **Given → Want → Bridge**, then meet
   counterexamples, contradiction and cases
4. [Sets](./sets.mdx): use membership, subsets and two-direction proofs to compare collections
5. [Notation](./notation.mdx): read subscripts, sequences and sums, and keep track of each letter's
   role
6. [Proof by induction](./induction.mdx): prove a statement for every whole number, one linked case
   at a time
7. [Exercises](./exercises.mdx): progress from translation and proof repair to independent mixed
   proofs
8. [Concept check](./test-yourself.mdx): diagnose which concepts to revisit; this quiz checks
   recognition, while the exercises check proof writing

Do not try to memorise the summary below before starting. It is a return-later reference for looking
up a term after you have met it in a guide.

:::accordion[Summary of definitions and rules]

**Definitions**

| Term                                  | Meaning                                                                                          |
| ------------------------------------- | ------------------------------------------------------------------------------------------------ |
| :ref{#statement}                      | A sentence that is either true or false                                                          |
| :ref{#quantifiers}                    | "For every $$x$$" claims something for all $$x$$; "there is an $$x$$" claims it for at least one |
| :ref{#equivalent-statements}          | Each is true exactly when the other is                                                           |
| :ref{#counterexample}                 | One case where a "for every" statement fails                                                     |
| :ref[Converse]{#contrapositive}       | Of "if $$P$$ then $$Q$$": "if $$Q$$ then $$P$$"                                                  |
| :ref[Contrapositive]{#contrapositive} | Of "if $$P$$ then $$Q$$": "if not $$Q$$ then not $$P$$"                                          |
| :ref{#exactly-when}                   | Both "if $$P$$ then $$Q$$" and "if $$Q$$ then $$P$$"                                             |
| :ref{#set}                            | A collection of elements, where $$x \in S$$ means $$x$$ is in $$S$$                              |
| :ref{#subset}                         | $$A \subseteq B$$ when every element of $$A$$ is in $$B$$                                        |
| :ref{#empty-set}                      | $$\varnothing$$, the set with no elements                                                        |
| :ref{#union-intersection}             | $$A \cup B$$: in $$A$$ or $$B$$. $$A \cap B$$: in both                                           |
| :ref{#sequence}                       | A list $$x_1, \dots, x_n$$ in order, where $$i$$ in $$x_i$$ is the index                         |
| :ref{#sum-notation}                   | $$\sum_{i=m}^{n} x_i = x_m + \dots + x_n$$                                                       |

**What a proof is**

| Rule                 | Statement                                                     |

**If, then and exactly when**

| Rule                             | Statement                                                      |

**Proof by induction**

| Rule             | Statement                                                                                     |
| ---------------- | --------------------------------------------------------------------------------------------- |
| :ref{#induction} | If a statement holds for $$1$$, and each case implies the next, then it holds for every $$n$$ |

**Sets**

| Rule                    | Statement                                                      |
| ----------------------- | -------------------------------------------------------------- |
| :ref{#set-empty-subset} | $$\varnothing \subseteq A$$ for every set $$A$$                |
