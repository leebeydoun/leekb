Suppose someone tells you that two odd numbers always add up to an even number. You try $$3 + 5$$
and $$7 + 11$$, and both work, but a few examples can't tell you it works for every pair. A
**proof** can, because it's an argument that settles the claim for every case at once.

Before you can prove something, though, you need to say exactly what is claimed. A precise
**statement** is either **true** or **false**, with no room to argue about what it meant.

Every later chapter is built on these two tools, proving each new rule from ones that came before.
So in this chapter we'll learn to read a statement carefully, and to follow and write the standard
kinds of proof.

## Guides in this chapter

The chapter has eight guides:

1. [Statements](./statements.mdx): what makes a sentence true or false, what "for every" and "there
   is" mean, and the difference between equal and equivalent
2. [What a proof is](./proofs.mdx): direct proofs, counterexamples, proof by contradiction and proof
   by cases
3. [If, then and exactly when](./implications.mdx): converses, contrapositives, and statements that
   work in both directions
4. [Proof by induction](./induction.mdx): proving a statement for every whole number, one step at a
   time
5. [Sets](./sets.mdx): sets, elements and subsets, and how to prove that two sets are equal
6. [Notation](./notation.mdx): subscripts, sequences, sums written with $$\Sigma$$, and which
   letters usually stand for what
7. [Test yourself](./test-yourself.mdx): a multiple choice quiz on the ideas in the chapter
8. [Exercises](./exercises.mdx): exercises on the whole chapter, with worked solutions

**Definitions**

| Term                                  | Meaning                                                                                          |
| ------------------------------------- | ------------------------------------------------------------------------------------------------ |
| :ref{#statement}                      | A sentence that is either true or false                                                          |
| :ref{#quantifiers}                    | "For every $$x$$" claims something for all $$x$$; "there is an $$x$$" claims it for at least one |
| :ref{#equivalent-statements}          | Each is true exactly when the other is                                                           |
| :ref{#counterexample}                 | One case where a "for every" statement fails                                                     |
| :ref[Converse]{#contrapositive}       | Of "if $$P$$ then $$Q$$": "if $$Q$$ then $$P$$"                                                  |
| :ref[Contrapositive]{#contrapositive} | Of "if $$P$$ then $$Q$$": "if not $$Q$$ then not $$P$$"                                          |
| :ref{#exactly-when}                   | Both "if $$P$$ then $$Q$$" and "if $$Q$$ then $$P$$"                                             |
| :ref{#set}                            | A collection of elements, where $$x \in S$$ means $$x$$ is in $$S$$                              |
| :ref{#subset}                         | $$A \subseteq B$$ when every element of $$A$$ is in $$B$$                                        |
| :ref{#empty-set}                      | $$\varnothing$$, the set with no elements                                                        |
| :ref{#sequence}                       | A list $$x_1, \dots, x_n$$ in order, where $$i$$ in $$x_i$$ is the index                         |
| :ref{#sum-notation}                   | $$\sum_{i=m}^{n} x_i = x_m + \dots + x_n$$                                                       |
