The other guides don't just state rules; they show why each one has to hold. That needs two things
this guide sets out first: a careful way of **saying** things, so that every statement is clearly
true or false, and a handful of ways of **proving** things, so that a statement can be settled for
every case at once rather than checked on a few examples.

None of it needs more than everyday arithmetic. The examples use whole numbers, even and odd numbers
and simple equations, and link to the [Numbers](../numbers/introduction.mdx) guide where a fact from
there is used. You don't have to master every page before moving on: the later guides link back here
whenever a pattern of proof is used, so this is also a guide to come back to.

## The guide

1. [Statements](./statements.mdx): what makes a sentence true or false, "for every" and "there is",
   and what equal and equivalent mean.
2. [What a proof is](./proofs.mdx): direct proofs, counterexamples, proof by contradiction and
   splitting into cases.
3. [If, then and exactly when](./implications.mdx): implications, converses, contrapositives, and
   statements that go both ways.
4. [Proof by induction](./induction.mdx): proving a statement for every whole number by climbing one
   step at a time.
5. [Sets](./sets.mdx): sets, elements and subsets, and how to prove two sets are equal.
6. [Notation](./notation.mdx): subscripts, sequences, sums written with $$\Sigma$$, and which letter
   usually means what.
7. [Test yourself](./test-yourself.mdx): a multiple choice quiz on the ideas in the guide.
8. [Exercises](./exercises.mdx): exercises on the whole guide, with worked solutions.

**Definitions**

| Term                                                | Meaning                                                                                     |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| :ref[Statement]{#statement}                         | A sentence that is either true or false                                                     |
| :ref[For every, there is]{#quantifiers}             | "For every $$x$$": true whatever $$x$$ is; "there is an $$x$$": true for at least one $$x$$ |
| :ref[Equivalent statements]{#equivalent-statements} | Each is true exactly when the other is                                                      |
| :ref[Counterexample]{#counterexample}               | One case where a "for every" statement fails                                                |
| :ref[Converse]{#contrapositive}                     | Of "if $$P$$ then $$Q$$": "if $$Q$$ then $$P$$"                                             |
| :ref[Contrapositive]{#contrapositive}               | Of "if $$P$$ then $$Q$$": "if not $$Q$$ then not $$P$$"                                     |
| :ref[Exactly when]{#exactly-when}                   | Both "if $$P$$ then $$Q$$" and "if $$Q$$ then $$P$$"                                        |
| :ref[Set]{#set}                                     | A collection of elements; $$x \in S$$ means $$x$$ is in $$S$$                               |
| :ref[Subset]{#subset}                               | $$A \subseteq B$$ when every element of $$A$$ is in $$B$$                                   |
| :ref[Empty set]{#empty-set}                         | $$\varnothing$$, the set with no elements                                                   |
| :ref[Sequence]{#sequence}                           | A list $$x_1, \dots, x_n$$ in order; $$i$$ in $$x_i$$ is the index                          |
| :ref[Sum notation]{#sum-notation}                   | $$\sum_{i=m}^{n} x_i = x_m + \dots + x_n$$                                                  |

**What a proof is**

| Rule                                         | Statement                                                     |

**If, then and exactly when**

**Proof by induction**

**Sets**
