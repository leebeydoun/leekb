At the heart of mathematics are statements: precise claims that are either true or false. This guide
covers two tools for working with them, and every later guide relies on both:

- A precise way to state a mathematical claim
- The standard ways to prove one

In mathematics, stating a rule is not enough. You also have to show why it must hold. A precise
statement tells you exactly what is being claimed, so it is either **true** or **false**. A proof
then settles the statement for every case at once, which no number of examples can do.

Each new statement builds on ones already proved, so they form the foundation for everything that
follows. Reading a statement carefully, and following how it is proved, is the key to understanding
the material in these guides and in any other mathematics you read.

**Definitions**

| Term                                                | Meaning                                                                                          |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| :ref[Statement]{#statement}                         | A sentence that is either true or false                                                          |
| :ref[For every, there is]{#quantifiers}             | "For every $$x$$" claims something for all $$x$$; "there is an $$x$$" claims it for at least one |
| :ref[Equivalent statements]{#equivalent-statements} | Each is true exactly when the other is                                                           |
| :ref[Counterexample]{#counterexample}               | One case where a "for every" statement fails                                                     |
| :ref[Converse]{#contrapositive}                     | Of "if $$P$$ then $$Q$$": "if $$Q$$ then $$P$$"                                                  |
| :ref[Contrapositive]{#contrapositive}               | Of "if $$P$$ then $$Q$$": "if not $$Q$$ then not $$P$$"                                          |
| :ref[Exactly when]{#exactly-when}                   | Both "if $$P$$ then $$Q$$" and "if $$Q$$ then $$P$$"                                             |
| :ref[Set]{#set}                                     | A collection of elements, where $$x \in S$$ means $$x$$ is in $$S$$                              |
| :ref[Subset]{#subset}                               | $$A \subseteq B$$ when every element of $$A$$ is in $$B$$                                        |
| :ref[Empty set]{#empty-set}                         | $$\varnothing$$, the set with no elements                                                        |
| :ref[Sequence]{#sequence}                           | A list $$x_1, \dots, x_n$$ in order, where $$i$$ in $$x_i$$ is the index                         |
| :ref[Sum notation]{#sum-notation}                   | $$\sum_{i=m}^{n} x_i = x_m + \dots + x_n$$                                                       |
