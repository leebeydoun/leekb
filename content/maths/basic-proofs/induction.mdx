---
title: Proof by induction
description: Proving a statement for every whole number by climbing one step at a time.
---

Some statements are really an endless list of statements, one for each positive integer. For
example, "for every positive integer $$n$$, $$1 + 2 + \cdots + n = \frac{n(n + 1)}{2}$$" says

```math
1 = \frac{1 \cdot 2}{2}, \qquad 1 + 2 = \frac{2 \cdot 3}{2}, \qquad 1 + 2 + 3 = \frac{3 \cdot 4}{2},
\qquad \dots
```

and so on forever. We can check any one of these by hand, but never all of them. Induction is a way
to prove the whole endless list with just two arguments.

## The idea

Picture an endless row of dominoes standing on their ends. You want to be sure that every single one
falls over. You don't need to watch each one; it is enough to know two things:

1. **The first domino falls.** Someone pushes it.
2. **Each domino knocks over the next.** They are spaced so that whenever one falls, the one after
   it falls too.

Then the first falls, so the second falls, so the third falls, and so on: every domino falls,
however far along the row it is. Notice that the second fact on its own proves nothing; a row of
perfectly spaced dominoes that nobody pushes stays standing. And the first fact on its own only
knocks over one domino. It is the two together that do the work.

Induction is exactly this, with statements in place of dominoes.

:::remark[Induction]{#induction}

Suppose that for each positive integer $$n$$ there is a statement, which we call $$P(n)$$. To prove
that $$P(n)$$ is true for every positive integer $$n$$, it is enough to show two things:

1. **The base case:** $$P(1)$$ is true.
2. **The inductive step:** for every positive integer $$k$$, **if** $$P(k)$$ is true, **then**
   $$P(k + 1)$$ is true.

We take this as a basic fact about the positive integers: starting from $$1$$ and adding $$1$$ over
and over reaches every one of them, so nothing gets missed.

:::

## The confusing part: assuming $$P(k)$$

The inductive step says "suppose $$P(k)$$ is true; show that $$P(k + 1)$$ is true". This often feels
like cheating. Aren't we assuming exactly what we are trying to prove?

We aren't. The inductive step doesn't claim that $$P(k)$$ **is** true. It proves an "if, then"
statement: **if** $$P(k)$$ happens to be true, **then** so is $$P(k + 1)$$. That is the domino
spacing: it says nothing about whether domino $$k$$ actually falls, only what happens to domino
$$k + 1$$ if it does. Whether it falls is settled by the chain reaction from the base case.

So in the inductive step, $$k$$ is any positive integer, and $$P(k)$$ is something we are allowed to
use, called the **inductive hypothesis**. The job is to get from $$P(k)$$ to $$P(k + 1)$$. In
practice that means:

1. Write out exactly what $$P(k)$$ says. This is what you know.
2. Write out exactly what $$P(k + 1)$$ says. This is what you want.
3. Find $$P(k)$$ hiding inside $$P(k + 1)$$, and use it.

Step 3 is the heart of every induction proof. The case $$k + 1$$ is usually the case $$k$$ plus one
more piece, and the trick is to spot the case $$k$$ inside it.

## A first example, slowly

Before proving the formula, here is one reason to expect it. To add $$1$$ to $$100$$, pair the
numbers from the two ends: $$1 + 100$$, $$2 + 99$$, $$3 + 98$$ and so on. Every pair adds to
$$101$$, and there are $$50$$ pairs, so the total is $$50 \cdot 101 = 5050$$. The formula says the
same thing for any $$n$$: the numbers make half of $$n$$ pairs, each adding to $$n + 1$$. When $$n$$
is odd the middle number has no partner, which makes the pairing argument fiddly. Induction gives a
proof that doesn't have to worry about this.

:::example[Adding up 1 to n]

**Claim.** For every positive integer $$n$$,

```math
1 + 2 + \cdots + n = \frac{n(n + 1)}{2}
```

It is worth checking a few cases first, both to believe the claim and to see what $$P(n)$$ means:

| $$n$$ | $$1 + \cdots + n$$ | $$\frac{n(n + 1)}{2}$$       |
| ----- | ------------------ | ---------------------------- |
| $$1$$ | $$1$$              | $$\frac{1 \cdot 2}{2} = 1$$  |
| $$2$$ | $$3$$              | $$\frac{2 \cdot 3}{2} = 3$$  |
| $$3$$ | $$6$$              | $$\frac{3 \cdot 4}{2} = 6$$  |
| $$4$$ | $$10$$             | $$\frac{4 \cdot 5}{2} = 10$$ |

Here $$P(n)$$ is the statement "$$1 + 2 + \cdots + n = \frac{n(n + 1)}{2}$$".

**Base case.** $$P(1)$$ says $$1 = \frac{1 \cdot 2}{2}$$, which is true.

**Inductive step.** Let $$k$$ be a positive integer and suppose $$P(k)$$ is true.

- **Know:** $$1 + 2 + \cdots + k = \frac{k(k + 1)}{2}$$.
- **Want:** $$1 + 2 + \cdots + k + (k + 1) = \frac{(k + 1)(k + 2)}{2}$$, which is $$P(k + 1)$$: the
  same statement with $$k + 1$$ in place of $$n$$.

The sum we want is the sum we know, plus one more number. So we replace the first $$k$$ terms using
what we know, then simplify:

```math
\begin{aligned}
1 + 2 + \cdots + k + (k + 1) &= \frac{k(k + 1)}{2} + (k + 1) \\
&= \frac{k(k + 1)}{2} + \frac{2(k + 1)}{2} \\
&= \frac{(k + 1)(k + 2)}{2}
\end{aligned}
```

The last step takes out the common factor $$k + 1$$. That is exactly $$P(k + 1)$$.

**Conclusion.** By induction, $$P(n)$$ is true for every positive integer $$n$$.

:::

So, for example, the numbers from $$1$$ to $$100$$ add up to $$\frac{100 \cdot 101}{2} = 5050$$,
without adding a single one of them.

## A second example: divisibility

The same shape works for statements about divisibility. The trick of finding $$P(k)$$ inside
$$P(k + 1)$$ just looks different.

:::example[Powers of 4]

**Claim.** For every positive integer $$n$$, $$3$$ divides $$4^n - 1$$.

**Base case.** $$4^1 - 1 = 3$$, which $$3$$ divides.

**Inductive step.** Suppose $$3 \mid 4^k - 1$$.

- **Know:** $$4^k - 1 = 3m$$ for some integer $$m$$.
- **Want:** $$4^{k + 1} - 1 = 3 \times (\text{some integer})$$.

To find $$4^k - 1$$ inside $$4^{k + 1} - 1$$, write $$4^{k + 1}$$ as $$4 \cdot 4^k$$ and then
rearrange so that $$4^k - 1$$ appears:

```math
4^{k + 1} - 1 = 4 \cdot 4^k - 1 = 4(4^k - 1) + 4 - 1 = 4(4^k - 1) + 3
```

Now use what we know: $$4(4^k - 1) + 3 = 4 \cdot 3m + 3 = 3(4m + 1)$$, which is a multiple of $$3$$.

**Conclusion.** By induction, $$3 \mid 4^n - 1$$ for every positive integer $$n$$.

:::

Writing $$-1$$ as $$-4 + 3$$ in the middle is the kind of move that looks like magic the first time.
It came from asking: "I have $$4 \cdot 4^k - 1$$, and I want $$4^k - 1$$ to appear. What do I need?"
Answering that question is most of the work in an inductive step.

## Starting somewhere else

Some statements are false for the first few numbers and only become true from some point on. For
example, "$$2^n > n^2$$" fails for $$n = 2, 3, 4$$ but holds for every $$n$$ from $$5$$ onwards:

| $$n$$   | $$1$$ | $$2$$ | $$3$$ | $$4$$  | $$5$$  | $$6$$  | $$7$$   |
| ------- | ----- | ----- | ----- | ------ | ------ | ------ | ------- |
| $$2^n$$ | $$2$$ | $$4$$ | $$8$$ | $$16$$ | $$32$$ | $$64$$ | $$128$$ |
| $$n^2$$ | $$1$$ | $$4$$ | $$9$$ | $$16$$ | $$25$$ | $$36$$ | $$49$$  |
| True?   | yes   | no    | no    | no     | yes    | yes    | yes     |

So the claim to prove is "$$2^n > n^2$$ for every $$n \ge 5$$". Induction still works; the chain
reaction just starts further along.

Think of the dominoes again, but this time push domino number $$5$$ instead of domino number $$1$$.
Domino $$5$$ knocks over $$6$$, which knocks over $$7$$, and so on forever. Dominoes $$1$$ to $$4$$
stay standing, but that's fine: we never claimed anything about them.

This changes the two parts of the proof in two small ways.

1. **The base case is the starting number.** Here we check $$P(5)$$ instead of $$P(1)$$.
2. **The inductive step only has to work from the starting number on.** The chain reaction only ever
   uses the step to go from $$5$$ to $$6$$, from $$6$$ to $$7$$, and so on. It never goes from $$2$$
   to $$3$$. So in the step we may assume $$k \ge 5$$, and use that fact if it helps.

The second point is easy to miss, and it is often exactly what makes the step work, as the example
shows.

:::example[An inequality that starts late]

**Claim.** For every integer $$n \ge 5$$, $$2^n > n^2$$.

**Base case.** For $$n = 5$$: $$2^5 = 32$$ and $$5^2 = 25$$, and $$32 > 25$$.

**Inductive step.** Let $$k$$ be an integer with $$k \ge 5$$, and suppose $$P(k)$$ is true.

- **Know:** $$2^k > k^2$$.
- **Want:** $$2^{k + 1} > (k + 1)^2$$.

Going from $$2^k$$ to $$2^{k + 1}$$ means doubling, so double both sides of what we know
(:ref{#numbers/order-multiply}):

```math
2^{k + 1} = 2 \cdot 2^k > 2k^2
```

So $$2^{k + 1}$$ is bigger than $$2k^2$$. If $$2k^2$$ is in turn at least $$(k + 1)^2$$, we are
done, because then $$2^{k + 1} > 2k^2 \ge (k + 1)^2$$. That leaves one question: is doubling $$k^2$$
enough to get past $$(k + 1)^2$$? Not always:

| $$k$$         | $$1$$ | $$2$$ | $$3$$  | $$4$$  | $$5$$  |
| ------------- | ----- | ----- | ------ | ------ | ------ |
| $$2k^2$$      | $$2$$ | $$8$$ | $$18$$ | $$32$$ | $$50$$ |
| $$(k + 1)^2$$ | $$4$$ | $$9$$ | $$16$$ | $$25$$ | $$36$$ |

It fails for small $$k$$ but works once $$k$$ is a bit bigger. To show it works for every
$$k \ge 5$$, look at the difference:

```math
2k^2 - (k + 1)^2 = 2k^2 - (k^2 + 2k + 1) = k^2 - 2k - 1 = k(k - 2) - 1
```

This is where $$k \ge 5$$ gets used. It makes $$k - 2 \ge 3$$, so $$k(k - 2) \ge 5 \cdot 3 = 15$$,
and the difference is at least $$14$$, which is positive. So $$2k^2 > (k + 1)^2$$, and putting the
pieces together,

```math
2^{k + 1} > 2k^2 > (k + 1)^2
```

which is $$P(k + 1)$$.

**Conclusion.** By induction, $$2^n > n^2$$ for every $$n \ge 5$$.

:::

Why start at $$5$$ and not somewhere earlier? Two things have to hold at the starting number:

- **The base case must be true.** $$P(3)$$ and $$P(4)$$ are false ($$8 < 9$$ and $$16 = 16$$), so
  they can't be the base case.
- **The step must work from there on.** The tables show the step would also fail from $$k = 2$$,
  since $$2 \cdot 2^2 = 8$$ is not bigger than $$3^2 = 9$$.

The first starting number where both hold is $$5$$. A good habit with any "for every $$n \ge n_0$$"
claim is to check a table like the one above first. It tells you where the claim starts being true,
and so where to put the base case.

## Why both steps matter

Each half of an induction proof can be done without the other, and the result is nonsense.

- **A step without a base case.** Let $$P(n)$$ say "$$n = n + 1$$". If $$k = k + 1$$, then adding
  $$1$$ to both sides gives $$k + 1 = k + 2$$, so the inductive step works perfectly. But $$P(1)$$,
  which says $$1 = 2$$, is false, so nothing ever gets started. The dominoes are well spaced but
  nobody pushed the first one.
- **A base case without a step.** The $$n^2 + n + 11$$ example on [What a proof is](./proofs.mdx)
  was true for $$n = 1, \dots, 9$$ and then failed. Checking first cases, however many, is not
  induction.

## Writing an induction proof

Every induction proof can be laid out the same way:

1. **Say what $$P(n)$$ is**, in words or as a formula.
2. **Base case:** check $$P(1)$$ (or $$P(n_0)$$ if starting later).
3. **Inductive step:** "Suppose $$P(k)$$ is true for some $$k$$." Write out what you know and what
   you want. Find $$P(k)$$ inside $$P(k + 1)$$, use it, and reach $$P(k + 1)$$.
4. **Conclude:** "By induction, $$P(n)$$ is true for every $$n$$."

In the Numbers guide, induction proves that congruences can be raised to any power: if
$$a \equiv b$$, then $$a^n \equiv b^n$$ (:ref{#numbers/congruence-powers}). The base case is
$$n = 1$$, and the step multiplies the case $$k$$ by $$a \equiv b$$ to reach the case $$k + 1$$.
